# 午夜酒馆：佣兵经纪人（Midnight Tavern: Mercenary Broker）v1.0

面向 TapTap 的 2D 横屏暗夜紫金像素风模拟经营 H5 游戏，使用 Duelyst 开源像素单位动画素材。

## 启动方式

在项目目录下启动本地静态服务器即可试玩（无需构建或安装依赖）：

```bash
cd /Users/qingshi/Documents/ChatGPT/tap/午夜酒馆
python3 -m http.server 8091
```

随后在浏览器打开：<http://localhost:8091>

## 核心玩法与交互亮点

1. **活体横屏像素酒馆**：雨夜拱窗、摇曳壁炉与吊灯、浮尘光影；14 名 Duelyst 像素佣兵直接在酒桌间晃悠、干杯并冒出动态吐槽气泡。
2. **吧台拖酒「递酒套话」**：从左下角吧台拖起【烈焰朗姆】【迷雾苦艾】【圣泉麦酒】直接泼/递给指定佣兵（也支持点选酒水再点佣兵），触发飞溅粒子与战力/情报/砍价反馈。
3. **拎人入队 + 羁绊发光 + 黄铜胜率罗盘**：直接把酒馆里的 Duelyst 佣兵拎起来拖入右侧羊皮纸悬赏单卡槽，凑齐【圣光 / 暗影 / 贪财 / 狂暴 / 秘术】触发羁绊，胜率罗盘指针实时摆动。
4. **长按红蜡火漆印章派单**：按住火漆印章充能「啪」一声盖下，屏幕微震 + 蜡印爆裂，小队全员推开酒馆大门冲进雨夜。
5. **Duelyst 实况战报剧场 & 黑心抽成拉杆**：实机播放 Duelyst 攻击/受击动画与奇葩词条演出；归来砸开战利品麻袋，滑动 20%–80% 抽成拉杆实时观看佣兵反应，在金币、声望、忠诚与每 3 夜一次的酒馆租金之间极限博弈。
6. **7 夜经纪人档案 & 无尽模式**：第 7 夜结算生成可截图发 TapTap 的经纪人战绩卡，并支持继续无尽模式与 4 项可视化酒馆装潢升级。
