# 《午夜酒馆：佣兵经纪人》设计点菜本（持续迭代）

> **协作规则**：先放开点菜、把零散灵感持续融进菜单并梳理系统间化学反应；等准备「下单」开工 v4.0 时，再整体对照做减法，删去冗余菜品，让体验刚刚好。

## 0. 已共识的项目基线（不可违背的红线）

* **目标平台与形态**：TapTap 2D 横屏手机 H5 模拟经营 + 轻策略自走棋。
* **美术风格**：HD-2D 高级暗夜像素风（深邃黑曜石半透玻璃 + `1px` 青金发光细线 + 分段发光像素条 + 四角瞄准框 + 聚光灯暗影剪影），复用 Duelyst 开源动画单位素材。
* **手机端交互铁律**：
  * **纯点击 / 拖拽优先**，绝不依赖桌面端 `hover` 态。
  * **信息不爆炸**：单屏克制展示核心指标，不堆砌文字墙与密密麻麻的表格面板。
  * **零手操负担**：战斗前选人即布阵，不需要玩家手动微调站位格子。
* **当前可玩原型**：`v3.3`（本目录 `index.html`，支持 `file://` 直接双击运行）。

## 1. 已点主菜池（持续融合中）

### 主菜一：从 0 起步的渐进节奏 + 可左右横滑扩建的长卷酒馆 `[已点]`
* **从 0 循序渐进**：开局不再一次性塞满 6 人与全系统；佣兵伴随门铃声陆续推门进店，每夜逐步解锁新玩法。
* **三阶段横向空间扩建**（手指左右横滑巡视酒馆）：
  * **Lv.1 破落小馆（1 屏，不可拖）**：2 张木桌、最多容 3 人、签约上限 1 人；开局仅 2 名初始熟客 + 1 张新手单，30 秒跑通「选人 → 自动站位开打 → 分账」闭环。
  * **Lv.2 暗夜大厅（1.6 屏，可左右横滑）**：4 张酒桌、容 6 人、签约上限 3 人；解锁**黑市军火架**（装备资产）、**午夜拍卖台**与**双线派单**。
  * **Lv.3 紫金地下公会（2.2 屏大长卷）**：6 张酒桌、容 9 人、签约上限 5 人；解锁**暗影 VIP 包厢**（声望达标后吸引暗金传说佣兵入座）与**地下赌桌/擂台**。

### 主菜二：精细品级分层 + 动态玩梗标签 + 带脾气的花样签约 `[已点 · 已加料]`
* **6 色大档 × 精细评级（含 +/- 与 SSS 顶格）**：
  * 视觉上依然克制在 **6 种颜色**（灰/绿/蓝/紫/橙/绯红，手机端一眼分清大阶层），字母角标细分为 **D / C / B / B+ / A- / A / A+ / S- / S / S+ / SSS**：
    * **D（灰白 · 街边杂鱼）**：便宜凑数，无羁绊或弱羁绊。
    * **C（翠绿 · 江湖散客）**：1 羁绊 + 固有脾气，前期开荒主力。
    * **B / B+（冰蓝 · 老练佣兵）**：1 羁绊 + 3 格怒气大招，中期骨干。
    * **A- / A / A+（绛紫 · 业界名宿）**：**双羁绊**好混搭 + 触发花样签约门槛；`A+` 具备极高“淘金感”。
    * **S- / S / S+（鎏金橙 · 暗金传说）**：双羁绊 + 改写战局的专属机制；`S-` 常带缺陷/怪癖但性价比高，`S+` 为巅峰王牌。
    * **SSS（绯红青金 · 全城唯一传奇）**：通缉级冠名大佬，进店自带酒馆光环与专属事件线。
  * 品级固定代表江湖身价与机制上限（不做抽卡碎片升星）；局内成长仍靠出征升级（Lv.1 → Lv.5）与穿戴装备。
* **双层标签系统（固有脾气 × 每次进店随机生活状态，制造交互变数与黑色幽默）**：
  * **固有性格**（武器痴 / 贪财鬼 / 酒鬼 / 义气派）：决定花样签约的核心手段。
  * **每次进店动态标签**（同一佣兵每次推门都可能换新状态，直接影响抽成、定金、战斗表现与突发事件）：
    * *经济状况*：如**「刚生娃急需奶粉钱」**（0 定金敢接高危单、战斗拼命，但绝不接受黑心抽成）、**「欠了高利贷」**（底薪打骨折求签卖身契，但可能引来讨债人）、**「刚发横财」**（给钱不动心，只认稀有装备或声望）。
    * *心情状态*：如**「刚被甩」**（灌烈酒暴击翻倍，但容易在酒馆惹事）、**「宿醉未醒」**（出场费打 5 折，首回合发呆）、**「中了小奖」**（今天好说话，抽成多扣 10% 也不翻脸）。
    * *江湖境遇*：如**「刚被前东家坑过」**（对抽成极度敏感）、**「正在躲仇家」**（愿意低价躲店打工，但可能触发上门踢馆）。
* **散客 vs 签约常驻**：
  * **散客**：随机推门进店，过夜即走，只收单次出场定金。
  * **签约常驻**：长期留店培养、可穿戴高级装备，但每晚需发底薪；若长期黑心抽成或屡屡派去团灭，会**撕毁合约跑路**甚至卷走装备跳槽。
* **按脾气走花样签约（不止掏钱点确定）**：
  * **武器痴 / 装备控**（如格雷、白羽）：给钱不签，必须拿心仪的**蓝/紫/橙装备作为聘礼利诱**才肯签。
  * **贪财鬼**（如巴克、薇拉）：支持**「对赌签约」**（0 签字费，约定未来 2 晚带其赚够目标金币则自动转正，否则走人）；抽成过狠会当场掀桌。
  * **酒鬼 / 氛围党**（如老七、赤尾）：先请喝最爱特调灌至微醺 + 酒馆氛围达标，顺手在酒桌上按手印签约。
  * **义气 / 声望派**（如铁砧、阿莉娅）：看重酒馆声望（黑店名声太臭绝不签约），签约后底薪低且极度忠诚。

### 主菜三：装备硬通货资产系统（极简两槽 × 一物四用 × 10 秒拍卖） `[已点 · 已加料]`
* **极简两槽（武器 + 奇物/护具）**：不搞复杂多部位换装；每件实体像素装备只带 **1 条核心机制/属性词条**（如「火焰附魔」「开局护盾」「暴击偷钱」「斩杀回怒」），支持直接联动宝可梦属性克制。
* **资产归属**：副本掉落或黑市获得的装备全部属于玩家资产，陈列在酒馆军火架上，分灰/绿/蓝/紫/橙/绯红品级。
* **一物四用**：
  1. **摆柜出租**：出征前把装备拖给佣兵穿戴，**立刻先收一笔装备租金**（输赢都落袋）+ 拉高战力/补属性克制；若小队团灭，存在**损毁/遗失风险**。
  2. **10 秒快节奏午夜拍卖**：挂上拍卖台后，店里豪客与武器痴头顶实时冒气泡竞价抬价；玩家只需在价格飙红时点击**「拱一次火」**（搏更高溢价，拱过头流拍）或**「落槌成交」**，10 秒爽完不拖慢单夜节奏。
  3. **利诱签约**：作为「聘礼」送给高傲的 `A/S/SSS` 级武器痴大佬，强行拐进自家酒馆。
  4. **救急变现**：低价卖给行商，快速凑齐每 3 夜一次的地税保命。

### 主菜四：组队后的多元派遣玩法 `[已点]`
* **悬赏讨伐（主线战斗）**：挑战机制型敌人与 Boss，赚高额赏金、掉核心装备、涨声望。
* **暗夜踩点（侦察情报）**：低战损派刺客/游侠提前摸清次日高难 Boss 的技能机制与弱点，顺手摸点散财。
* **黑市护镖 / 劫镖（风险副业）**：护镖稳赚声望与金币；劫镖暴利但会推高**城卫通缉度**（触发查水表风险）。
* **对家踢馆 / 地下擂台（后期爽点）**：派签约王牌去踢对手酒馆的馆子，赢了抢走对方声望与稀缺客源。

### 主菜五：宝可梦式属性克制 × 回合制自走棋 × 像素战斗演出 `[已点 · 已加料]`
* **单位三维架构**：**职业（管站位与分工） × 属性（管宝可梦式克制与羁绊） × 标签（管固有脾气与进店随机状态）**，每名角色均有专属技能。
* **自动按职阶站位（透明铁律，无需手动调格）**：
  * 前排（护卫/重装）自动顶 1 号位抗伤；
  * 中排（战士/刺客）自动站 2 号位（刺客开局切敌方后排）；
  * 后排（远程/法师/支援）自动站 3 号位。
  * 若不选前排，脆皮会被顶到前排挨揍，规则一目了然。
* **宝可梦式直白属性克制（拒绝尴尬中二名，火就是火、冰就是冰）**：
  * **6 大直白属性双环**：
    * 元素环：**火** ➔ 克 **草（或毒）** ➔ 克 **冰** ➔ 克 **火**
    * 超凡环：**光** ➔ 克 **暗** ➔ 克 **雷（或奥）** ➔ 克 **光**
  * **高阶双属性**：`A / S / SSS` 级高品级佣兵可拥有**双属性**（如「火+暗」），命中双弱点触发 **×2.0 致命克制**，也存在双倍弱点风险，放大「暗夜踩点」侦察 Boss 属性的价值。
  * **派单拖拽富预览**：拖佣兵进悬赏单时，在原有**预计胜率罗盘**基础上，实时预览**属性克制/抵抗箭头（×1.5 / ×2.0 / ×0.7）**、**自动前后排站位**与**羁绊点亮效果**，零背表成本。
* **肉眼可见的质变羁绊**（2 人即亮，高阶双属性/双词条方便混搭）：
  * 属性羁绊 + 性格/职业特色羁绊（如光盾、暗影二连击、火系爆燃、贪财爆金币、雷/奥连锁清怪等）。
* **3 格怒气条大招 + 战斗演出重点优化**：
  * **属性克制炸屏反馈**：克制命中触发 **60ms 顿帧（Hitstop）+ 属性专属像素特效**（火柱 / 冰裂 / 紫影斩 / 圣光柱）+ 放大跳字 `克制!`；逆属性弹出弹刀火花 + 灰字 `抵抗`。
  * **满怒大招 Cut-in 横幅**：3 格怒气满时背景微暗，斜切暗夜紫金像素横幅（Duelyst 立绘特写 + 技能名 + 结合进店标签的玩梗台词，如刚生娃的战士大喊“为了奶粉钱！”），随后播放专属攻击帧与粒子爆发。
  * **轻运镜与终结感**：刺客带残影瞬移切后排；终结 Boss 触发 **0.15s 慢动作 + 聚光灯 + 战利品麻袋飞出**；支持 `1x / 2x` 变速，单场 12–20 秒爽快收尾。
* **机制型敌人与 Boss**：盾卫+毒弓（需切后/破甲）、亡灵召唤师（需清场）、4 层次数盾领主（需多段连击破盾）、切后排暗杀者（需反伤/护盾保后排）等，均带明确属性配置。

### 主菜六：单日三段节奏 × 吧台调酒 × 酒馆活人突发事件 `[已点 · 已加料]`
* **单日核心节奏（一轮一轮来人与事件 → 夜晚出征打架 → 凌晨分账）**：
  1. **营业筹备期**：门铃响起，佣兵带随机生活标签陆续进店落座，穿插活人突发事件；玩家自由调酒（含属性附魔）、花样签约、军火出租/拍卖、拖拽配队看富预览（胜率/属性克制/站位/羁绊）或开盘口下注。
  2. **午夜出征期**：长按红蜡火漆印章派单，全员推门入夜，播放 HD-2D 像素战斗演出（属性克制顿帧 + 满怒 Cut-in + 终结慢动作）。
  3. **凌晨分账期**：砸战利品麻袋、滑抽成拉杆看反应、收装备发底薪，每 3 夜结地税。
* **吧台调酒**：现有 3 款特调（烈焰朗姆 / 迷雾苦艾 / 圣泉麦酒）支持拖酒泼人或点选递酒；可扩展**「属性附魔特调」**（临时给佣兵附魔火/冰等属性硬克 Boss）。
* **4 类酒馆活人突发事件**（直接发生在酒馆场景里，推动玩家临场转型，而非文字小说弹窗）：
  1. **标签惹祸**：欠高利贷/躲仇家的佣兵引来讨债打手或仇家堵门（扛债白嫖卖身契 / 卖人换悬赏 / 拱火让他们在店里干架顺手开盘口）。
  2. **脏钱与潜规则**：神秘雇主塞黑钱让你带队演戏打假赛；城卫队长喝茶要茶水费或让你交出通缉标签佣兵顶缸。
  3. **店内人事冲突**：宿敌喝多干架（请麦酒劝和 / 递军火拱火）；对头酒馆猎头上门高薪挖墙脚（加薪送装 / 直接放话去踢馆）。
  4. **午夜稀客 / 黑市盲盒**：蒙面行商卖未鉴定装备（神装或通缉赃物）；豪客点名高价求购军火架上正在用的核心装备。

### 主菜七：加长版单局肉鸽 + 自由演化流派 + 「双向进阶」局外成长 `[已点 · 已加料]`
* **核心模式定调（单局肉鸽制为主，长线/沙盒模式留作后续扩展）**：
  * **单局进程**：比纯短局略长，建议 **14–16 夜（约 20–30 分钟，支持局内中途自动存档续玩）**，确保一局内能完整体验「Lv.1 破落小馆 → Lv.2 暗夜大厅 → Lv.3 紫金地下公会」三阶段扩建、军火拍卖与花样签约，同时保留高重开欲。
  * **开局白板、局内情景驱动自由演化（拒绝开局选老板身份给 buff 框死路线）**：
    * 开局没有预设老板职业或强绑定主线 buff；放贷剥削、军火倒卖拍卖、声望养精英、开盘口对赌、吧台属性附魔调酒**全部作为局内开放玩法**，允许玩家看每晚来客、随机标签、掉落与突发事件**自由融合混搭**（也可铁头硬走偏门）。
    * **终局行为算法评定头衔与结局**：结算时根据整局实际经营数据（平均抽成率、声望/通缉度、装备交易额、对赌胜率、调酒附魔次数、签约忠诚度等），由算法评定专属经纪人头衔与结局档案（含混搭奇葩头衔，如《血汗教父》《暗夜军火王》《王城传奇公会》《午夜赌神》《黑心慈善家》）。
  * **无尽模式 & 长期多存档沙盒**：均列为**后续版本扩展项**（初版不做，视玩家试玩反馈再决定是否追加）。
* **局外核心机制 1：「初始股」老熟人带入**：
  * 每局成功签约过的佣兵收入局外图鉴；解锁对应局外进度后，新开一局时可挑选 **1 名已签约过的英雄作为「初始股」** 开局直接坐镇酒馆，大幅缓解“养大被清零”的失落感。
  * *(待下单前细化平衡：高品级初始股可设计为开局从 Lv.1 起步，或带“老东家友情价”但需按酒馆等级解锁全额战力，避免前 3 夜完全无脑碾压。)*
* **局外核心机制 2：「双向进阶」难度阶梯（改良版杀戮尖塔进阶）**：
  * 拒绝传统肉鸽“只恶心玩家、不给爽感”的单向受苦难度；每升一阶难度，**敌我双向加码**：
    * **压力端变难**：地税/租金更高、Boss 追加新机制、城卫稽查与踢馆更频繁、佣兵谈判更刁钻。
    * **玩家端同步加强**：同步解锁更高品级池（`S+`、`SSS` 出现率提升）、开放更高阶「初始股」可选权限、解锁强力黑市特权、高阶属性特调与高阶双词条装备。
  * 目标体验：高难度不是“抠搜受苦”，而是**“高风险、高上限、更疯狂的爽局”**。

## 3. 下单前「删菜 / 做减法」对照区（v4.0 已敲定范围 · 经 GPT 逻辑审查修订）

* **v4.0 首版落地**：3 阶段横滑扩建（14–16 夜完整一局 + 中途自动存档）、6 色 × D~SSS 品级 + 随机生活标签 + 3 种花样签约（对赌/聘礼/灌酒）、6 属性双环（火/草/冰 + 光/暗/雷）+ 高阶双属性 + 拖拽富预览 + 像素战斗演出升级、两槽装备 + 先收租金/团灭损毁 + 10 秒拱火落槌拍卖、属性附魔调酒 + 8–10 个活人突发事件（隔夜穿插）、白板自由演化 + 终局行为算法评定头衔与图鉴数据底座。

* **节奏红线**：单夜不超过 2 个高光决策，控制在 60–90 秒内。
* **GPT 逻辑审查修订（已合入 v4.0 规则）**：
  1. **迷雾单信息隔离（保住踩点价值）**：高难/Boss 迷雾单在未踩点或未灌迷雾苦艾前，属性显示 `???`，拖拽预览**隐藏克制箭头，胜率罗盘仅显示模糊估算区间**，不泄露隐藏属性；侦察/套话揭晓后才显示精准胜率与克制金箭。
  2. **散客分账红线与口碑代价（保住抽成博弈）**：散客报酬为「出场定金 + 凌晨分账」，每人明示「抽成红线」（受贪婪度与生活标签影响）；拉杆超红线强榨虽能多拿现钱救急，但散客会**当场掀桌砸口碑（大扣酒馆声望、推高后续黑店溢价，甚至顺走装备）**；拉低于预期则涨声望并给签约折扣。
  3. **试玩观察点**：结算头衔页并列「再来一局」与「结束」，观察玩家是否主动重开并在下一局做出不同经营抉择。
