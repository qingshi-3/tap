# 《午夜酒馆：佣兵经纪人》设计点菜本（持续迭代）

> **协作规则**：先放开点菜、把零散灵感持续融进菜单并梳理系统间化学反应；等准备「下单」开工 v4.0 时，再整体对照做减法，删去冗余菜品，让体验刚刚好。

## 0. 已共识的项目基线（不可违背的红线）

* **目标平台与形态**：TapTap 2D 横屏手机 H5 模拟经营 + 轻策略自走棋。
* **美术风格**：HD-2D 高级暗夜像素风（深邃黑曜石半透玻璃 + `1px` 青金发光细线 + 分段发光像素条 + 四角瞄准框 + 聚光灯暗影剪影），复用 Duelyst 开源动画单位素材。
* **手机端交互铁律**：
  * **纯点击 / 拖拽优先**，绝不依赖桌面端 `hover` 态。
  * **信息不爆炸**：单屏克制展示核心指标，不堆砌文字墙与密密麻麻的表格面板。
  * **零手操负担**：战斗前选人即布阵，不需要玩家手动微调站位格子。
* **当前可玩原型**：`v3.3`（本目录 `index.html`，支持 `file://` 直接双击运行）。

## 1. 已点主菜池（持续融合中）

### 主菜一：从 0 起步的渐进节奏 + 可左右横滑扩建的长卷酒馆 `[已点]`
* **从 0 循序渐进**：开局不再一次性塞满 6 人与全系统；佣兵伴随门铃声陆续推门进店，每夜逐步解锁新玩法。
* **三阶段横向空间扩建**（手指左右横滑巡视酒馆）：
  * **Lv.1 破落小馆（1 屏，不可拖）**：2 张木桌、最多容 3 人、签约上限 1 人；开局仅 2 名初始熟客 + 1 张新手单，30 秒跑通「选人 → 自动站位开打 → 分账」闭环。
  * **Lv.2 暗夜大厅（1.6 屏，可左右横滑）**：4 张酒桌、容 6 人、签约上限 3 人；解锁**黑市军火架**（装备资产）、**午夜拍卖台**与**双线派单**。
  * **Lv.3 紫金地下公会（2.2 屏大长卷）**：6 张酒桌、容 9 人、签约上限 5 人；解锁**暗影 VIP 包厢**（声望达标后吸引暗金传说佣兵入座）与**地下赌桌/擂台**。

### 主菜二：佣兵品阶、升级成长与带脾气的花样签约 `[已点]`
* **4 档品阶**：黑铁（白）→ 白银（蓝）→ 黄金（紫）→ 暗金传说（橙），随酒馆等级与声望逐步解锁。
* **局内成长（Lv.1 → Lv.5）**：出征获胜涨经验升级，Lv.3 觉醒二阶专属被动。
* **散客 vs 签约常驻**：
  * **散客**：随机推门进店，过夜即走，只收单次出场定金。
  * **签约常驻**：长期留店培养、可穿戴高级装备，但每晚需发底薪；若长期黑心抽成或屡屡派去团灭，会**撕毁合约跑路**甚至卷走装备跳槽。
* **按脾气走花样签约（不止掏钱点确定）**：
  * **武器痴 / 装备控**（如格雷、白羽）：给钱不签，必须拿心仪的**蓝/紫/橙装备作为聘礼利诱**才肯签。
  * **贪财鬼**（如巴克、薇拉）：支持**「对赌签约」**（0 签字费，约定未来 2 晚带其赚够目标金币则自动转正，否则走人）；抽成过狠会当场掀桌。
  * **酒鬼 / 氛围党**（如老七、赤尾）：先请喝最爱特调灌至微醺 + 酒馆氛围达标，顺手在酒桌上按手印签约。
  * **义气 / 声望派**（如铁砧、阿莉娅）：看重酒馆声望（黑店名声太臭绝不签约），签约后底薪低且极度忠诚。

### 主菜三：装备硬通货资产系统（一物四用） `[已点]`
* **资产归属**：副本掉落或黑市获得的实体像素装备（武器 + 饰品/护具，分白/蓝/紫/橙）全部属于玩家资产，陈列在酒馆军火架上。
* **一物四用**：
  1. **摆柜出租**：出征前租给佣兵穿戴，立刻收一笔**装备租金** + 拉高小队战力；小队团灭时存在**损毁/遗失风险**。
  2. **午夜拍卖**：挂上酒馆拍卖台，由店里佣兵与黑市豪客**实时竞价红眼抬价**，高溢价变现冲酒馆扩建资金。
  3. **利诱签约**：作为「聘礼」送给高傲的黄金/暗金大佬，强行拐进自家酒馆。
  4. **救急变现**：低价卖给行商，快速凑齐地税/租金保命。

### 主菜四：组队后的多元派遣玩法 `[已点]`
* **悬赏讨伐（主线战斗）**：挑战机制型敌人与 Boss，赚高额赏金、掉核心装备、涨声望。
* **暗夜踩点（侦察情报）**：低战损派刺客/游侠提前摸清次日高难 Boss 的技能机制与弱点，顺手摸点散财。
* **黑市护镖 / 劫镖（风险副业）**：护镖稳赚声望与金币；劫镖暴利但会推高**城卫通缉度**（触发查水表风险）。
* **对家踢馆 / 地下擂台（后期爽点）**：派签约王牌去踢对手酒馆的馆子，赢了抢走对方声望与稀缺客源。

### 主菜五：有深度的回合制自走棋战斗 `[已点]`
* **自动按职阶站位（透明铁律，无需手动调格）**：
  * 前排（护卫/重装）自动顶 1 号位抗伤；
  * 中排（战士/刺客）自动站 2 号位（刺客开局切敌方后排）；
  * 后排（远程/秘术/奶妈）自动站 3 号位。
  * 若不选前排，脆皮会被顶到前排挨揍，规则一目了然。
* **三角属性克制**：圣光 ➔ 克制暗影/亡灵；暗影/秘术 ➔ 克制重甲/狂暴；狂暴/物理 ➔ 克制秘术/脆皮。
* **肉眼可见的质变羁绊**（2 人即亮，高阶双词条方便混搭）：
  * 【圣光×2】晨曦壁垒（开局全队金色护盾）
  * 【暗影×2】影袭双刃（普攻触发紫影二连击，专破次数盾）
  * 【狂暴×2】酒后拆家（残血狂怒、终结炸屏溅射）
  * 【贪财×2】顺手牵羊（暴击直接从 Boss 身上爆出像素金币）
  * 【秘术×2】奥术回响（每 2 回合全屏连锁清召唤小怪）
* **3 格怒气条大招 + 单位脾气彩蛋**：普攻/受击满 3 格放专属技能（微震 + 横幅 + Duelyst 爆发动画），叠加性格彩蛋（如老七爆破护甲、薇拉顺走 Boss 装备）。
* **机制型敌人与 Boss**：盾卫+毒弓（需切后/破甲）、亡灵召唤师（需清场）、4 层次数盾领主（需多段连击破盾）、切后排暗杀者（需反伤/护盾保后排）等。

### 主菜六：吧台调酒与酒馆突发事件 `[已有基础 · 待加料]`
