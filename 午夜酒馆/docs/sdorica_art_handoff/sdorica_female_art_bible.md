# 《万象物语》女性角色立绘风格拆解（Art DNA）

> [!NOTE]
> 基于 `https://www.sdorica.com/en/character/` 实看 **10 位不同种族与气质的女性角色**（Eclipse / Sunset / Mirage）整理：
> **Beyata（蓝鸟亚人）**、**Chiyuki（白貂兽人）**、**Fatima（黑豹兽人）**、**Yamitsuki（乌鸦羽族）**、**Sione（人类女骑士）**、**Angelia（人类王女）**、**Fredrica（妩媚女将）**、**Naya（女弓手）**、**Hestia（人鱼亚人）**、**Diana（沙漠精灵女王）**。

## 一、核心画风规律（为什么一眼就像《万象物语》）

### 1. 「弱线厚涂 + 局部微线」混合笔触（不是纯动漫勾线，也不是糊成一团的油画）
- **外轮廓几乎无黑线**：发梢、羽毛、兽毛、纱巾、飘带全部用**水粉/厚涂色块直接切出形体**，边缘在暗底中柔和羽化或自然衰减。
- **只在焦距核心区用极细暖褐/深紫微线**：眼睑、唇缝、鼻点、指尖、盔甲金纹雕花用细微暖色线锚定结构，让人物既有绘本厚涂的呼吸感，又有极高的五官精致度。

### 2. 极具辨识度的五官与眼神语言
- **面型与留白**：额头和面颊干净利落，鼻子极简（细小鼻影/点状鼻尖），嘴型严格服务性格（Sione/Yamitsuki 克制平直，Naya 自信露齿笑，Fredrica 微张慵懒，Beyata/Hestia 明媚展笑）。
- **宝石感瞳孔 + 上眼睑重压**：上睫毛/上眼线厚重清晰，虹膜呈通透宝石渐变并点一粒锐利白高光；眼周常带一层柔和的桃粉/玫红晕染（如 Beyata 的斜向腮红笔触、Fredrica 的下眼睑粉晕）。

### 3. 肤质与材质的「哑光高级感」
- **皮肤**：偏暖象牙桃色（Diana 为冷灰紫古铜深肤），用柔和的冷暖色块过渡代替生硬二分阴影，辅以克制的丝缎微光与暖色次表面腮红，绝不出现“塑料油光”。
- **织物与金属**：大量使用**哑光丝绒、薄透烟纱、羽绒毛皮**与**做旧古铜金/雕刻银甲**对比；金饰是温润的哑光古金配细小高光点，而不是刺眼的 3D 镀铬反光。

### 4. 非人女性角色的「真种族美学」（绝非简单戴兽耳发箍）
| 类型 | 代表角色 | 核心设计特征 |
| --- | --- | --- |
| **完全兽人（Furry / 兽吻）** | **Fatima（黑豹）**、**Chiyuki（白貂）** | 保留真实的猫科/鼬科吻部与鼻头结构，配合修长柔美的眼线、浓密飘逸的鬃发/大尾巴，用**高反差毛色块**（炭黑豹毛 vs 奶白长发、纯白貂毛 vs 烟墨薄纱）塑造形体，兼具野性与优雅。 |
| **羽族 / 禽类亚人** | **Yamitsuki（乌鸦）**、**Beyata（蓝鸟）** | 羽翼或直接从双臂自然过渡为层叠黑紫飞羽（Yamitsuki），或以耳羽/头羽/尾羽环绕构图（Beyata）；羽毛内层有金属蓝紫偏光，外缘融入暗背景。 |
| **水栖 / 精灵亚人** | **Hestia（人鱼）**、**Diana（沙漠精灵）** | 标志性的鳍状耳/水平尖耳 + 肤表高频出现的**浅白/青绿图腾纹身与回纹**（Yamitsuki、Fatima、Hestia 均有），瞬间拉满奇幻绘本世界观浓度。 |

### 5. 「大外轮廓包裹 + 3~4 色克制配色」
- **动态包裹剪影**：几乎每位女性都有一个大幅度延伸的“视觉框”——巨尾（Chiyuki）、双翼（Yamitsuki）、飘带（Sione）、巨型竖琴/长弓（Hestia/Naya）、宽大兜帽/皮草披肩（Fredrica），形成 S 形或大斜线张力。
- **配色纪律**：严格控制在 **1 个大面积中性主色（黑/白/深灰） + 1 个主题饱和色 + 做旧金/银饰 + 1 处高对比瞳色/图腾点睛**，配合顶部或侧后方暖白轮廓光，把人物从深暗羊皮纸底色中托出来。

## 二、反推到我们《午夜酒馆》英雄立绘的落地要点

1. **修正上一版 `hero_04`（GILDED QUEEN）残留的“二次元勾线感”**：
   - 后续重绘时**不要直接用旧动漫线稿图做强图生图垫底**，而是以这套《万象物语》Art DNA + 纯角色文字设定从零起稿，彻底去掉发丝和皮肤边缘的动漫轮廓线，把皮草披肩、丝绒黑裙、古金链条做成真正的色块厚涂与大飘带剪影（最接近 **Fredrica 的慵懒妩媚 + Sione 的暗底高光质感**）。
2. **给整套 10 位英雄立绘拉开种族与剪影差异**：
   - 如果后续整套都往《万象物语》方向统一，除了人类女角色，完全可以让部分主题英雄引入**豹人/羽族/亚人**特征（例如：**孤狼/换牌**做成黑豹/乌鸦羽族系，**挂毒/铭文**加入苍白图腾纹身与薄纱异域感，**经济女王 `hero_04`** 保持暗夜贵妇厚涂风），10 张立绘排开会非常有世界观辨识度。
