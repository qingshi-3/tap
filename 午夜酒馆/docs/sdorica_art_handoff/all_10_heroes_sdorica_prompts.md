# 《午夜酒馆》全 10 位英雄 + 6 位备用美少女《万象物语》风重置提示词总表

> **使用方式（切号后直接复用）**
> 1. 唯一画风参考图：`docs/sdorica_art_handoff/sdorica_ref_sione.jpg`（**不要**把旧版 `assets/heroes/hero_*_char.png` 当图生图输入，避免残留二次元黑线稿）。
> 2. 每张图拼接：**【通用画风前缀】 + 【对应角色主体提示词】 + 【通用画风后缀】**，画幅统一 `3:4`。
> 3. **克制配比**：10 位主力英雄为 **7 位纯人类美少女 + 3 位轻度亚人/羽翼美少女**（全部保持高颜值美少女面孔，不做重度兽吻）；另附 **6 位不同气质的高颜值备用美少女**（`backup_01` ~ `backup_06`）方便挑着换或留给后续新英雄。

## 通用画风前缀（Global Style Prefix — 每张必加）

```text
Vertical 3:4 fantasy bishoujo character portrait painted strictly in the exact Sdorica (Rayark) storybook gouache and matte-oil illustration style of the reference image. Painterly soft-edge plus micro-line hybrid: completely lineless outer silhouettes where hair tips, fur, feathers, and flowing sheer ribbons are sculpted by bold flat-brush gouache color blocks that softly dissolve into the dark backdrop; ultra-fine warm-brown micro-lines appear ONLY inside upper eyelids, lips, delicate fingers, and antique metallic filigree. ZERO black anime outlines, ZERO cel-shading, ZERO glossy plastic highlights. Exquisite, attractive Sdorica anime-storybook female face with luminous jewel-like eyes, refined proportions, warm ivory-peach matte-satin skin, directional warm top-down rim lighting, and subtle vintage canvas grain.
```

## 通用画风后缀（Global Style Suffix — 每张必加）

```text
Framed mid-thigh up (or three-quarter figure) with generous headroom, set against a dark muted warm-umber and olive-charcoal archival parchment backdrop with faint weathered geometric motifs so the glowing hair and silhouette pop dramatically. STRICT EXCLUSIONS: no chibi or pixel sprite in the corner, no text, no letters, no watermark, no signature, no frame, no UI border.
```
