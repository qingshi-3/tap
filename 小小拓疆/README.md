# 小小拓疆

手机横屏单机 H5 轻 RTS。以本地 `the-war` 的玩法为基线，首关按手机操作重新规划道路，改用即时招募、整队指挥、自动战斗与可拖动的大地图。本轮是 JavaScript 核心玩法改编，尚未移植原作全部系统。

## 运行与操作

在本目录执行 `npm run dev`，打开 <http://127.0.0.1:4177/>。现有预览服务保持运行。`dist/` 为无构建 HTML/CSS/JavaScript 产物，不依赖 CDN；Node 服务仅供本地预览，游戏无需自建后端。

- 单指拖动地图，双指调整视野；点击小地图快速跳转，房屋按钮回到主城。默认可见主城、青林镇和附近目标，短距离拖图查看其他战线；建筑和军团保留原显示尺度，不强行将全图塞进一屏。
- 点己方城堡 → 点兵种，立即扣费招募；点地图资源空位 → 点建筑，立即建造。
- 顶栏“编制”可打开存活编队列表，区分驻防/野外，点列表可定位并选队。编制按存活整队计算（攻城车2，其余1）；阵亡立即释放，尸体动画不占位。
- 按住己方驻军头像或野外编队，拖到据点/道路后松手，直接下令。拖动时显示头像和目标预览，停在屏幕边缘会慢速滚图；无效位置或界面控件上松手取消，双指缩放会取消当前拖令。可以行军中改派；近战接敌后不可立即撤离。
- “集结”选中当前视野内全部己方队伍；“增选”追加队伍。野外重叠的编队可连续点选切换。多选后拖其中一队会整组下令，拖未选军团只指挥该队。空白处起手拖动才移动地图。
- 拖到己方据点回防；“回防”按钮指向最近的己方据点。占城后已抵达的攻城队伍自动转为守军，头像可直接选择。
- 开局暂停部署，点“开战”开始。支持暂停、1×/2×、治疗旗、菜单与重开确认。切后台或旋转竖屏自动暂停，横屏后手动继续。

大尺寸鼠标浏览器以 852×393 手机画幅预览。适配触控，不要求滚轮、悬停或键盘。主要按钮至少44px。当前无战局存档，刷新或关闭会重置。

## 当前内容与规则

- 1840×1080的紧凑三方地图（重新规划主路、侧翼与守卫关口），17个道路/据点/宝箱/食人魔节点、19段道路折线、9个据点和15个固定资源位。道路中途也可设定目标；建筑位置固定，资源位贴近所属据点，不用黑色圆盘或连线表达归属。
- 城堡可招卫队、弓手、骑兵、攻城车；城镇可招卫队、弓手；法师塔可招卫队、法师。兵种有费用、编制、生命、伤害、射程、速度差异，出城以小编队显示。
- 资源位随宿主据点归属解锁，可建矿场（+2金/秒）、农场（+1编制）、魔能工坊（+1法力/秒）。据点自身也提供经济和编制，废墟暂停产出。占领后资源建筑清空，需要重新发展。
- 据点最多3级，升级提升城防与后续新兵生命/伤害。驻军自动出城迎敌，威胁消失回防；驻防恢复生命。非受威胁据点缓慢修复。
- 自动接战、攻破城防后驻留4秒占领，争夺中断占领。原地回防立即完成；道路点停留保持野外状态。
- 治疗旗消耗50法力，范围150世界像素，持续12秒，每秒恢复8生命。路上宝箱提供500金币，食人魔阻挡部分道路。
- 两个AI阵营遵守经济/编制限制，会招募、建设、出征和继续扩张。我方无存活据点时失败；消灭其他两方全部存活据点后胜利。

原作敕令、士气、完整阵营技能、逐兵碰撞/阵型模拟及飞行投射物未移植；当前远程伤害直接结算。AI采用基础目标选择，地图节奏与数值仍需试玩调整。未制作跨局养成、升星、广告奖励或云存档。

## 首关路线设计

- 开局在城门二选：青林镇向中央推进，或先拿法师塔获得法师招募能力。
- 两侧城镇经宽主路汇入中央王堡；中央是三方正面交锋和前线招募的位置。
- 北侧较窄道路经过法师塔、侧翼守卫和旧日城堡，能绕开中央，但需要更多行军与清怪投入。
- 南道由守卫把守，连接两侧城镇；清怪后可以绕开中央防线侧击。
- 两条细短支路只通向宝箱，不用多余小环路凑地图。所有道路相交处都对应真实连接。
- 拖拽预览沿实际寻路结果显示；要走指定侧路，先把军团拖到该路线的关口或途中位置。路径算法仍按距离选路，不自动判断哪条路线战斗风险更低。

## 文件职责

- `dist/level.js`：首关节点/道路/资源位、初始阵营与兵种/建筑数值。
- `dist/navigation.js`：道路投影、路径搜索、折线正反向截取。
- `dist/simulation.js`：指令校验、经济、招募、行军、战斗、驻防、占领、AI与胜负。
- `dist/terrain.js`：连续绘制草地/土路，复用 RPG 树石装饰；原道路拓扑决定可通行路线。
- `dist/battle-renderer.js`：局部镜头、像素编队动画、建筑/归属、血条与占领反馈。
- `dist/main.js`：手机手势、对象命中区、局部菜单、选择与指令、角落HUD、小地图、暂停。
- `dist/style.css` / `dist/index.html`：手机横屏布局、短屏适配、对话框与旋转提示。
- `dist/assets.js` / `dist/assets/SOURCES.md`：资源元数据和具体来源。
- `TASK.md`：当前任务、授权、验证证据与恢复入口。此前版本记录标为历史。

用户已确认本地 Duelyst 素材库全部可商用，本地 Godot 素材均可用于本项目。当前保留 the-war 的五兵种动画，首关使用重新设计的路网；建筑和树石装饰来自 `D:/godot/rpg/assets/`，草地/土路由 Canvas 连续绘制，不使用原地图图片或旋转草边拼图。食人魔使用 Duelyst 原始动画。具体裁片见 SOURCES；源 Godot 项目与素材库保持不变。
