实现分工：主 Agent 负责手机输入/镜头/HUD/集成与浏览器；执行 Agent 各自独占地图与资产、模拟与寻路、Canvas表现。共享契约如下，各方不得自行改名：

- level.js: LEVEL {name,world:{width,height},playerBaseId,startingGold:{player,enemy,rival},startingMana, nodes:[{id,name,x,y,kind:castle|town|tower|road|chest|ogre,owner:player|enemy|rival|neutral}],roads:[{id,a,b,points:[{x,y}]}],slots:[{id,hostId,x,y}],initialUnits:[{nodeId,owner,kind,count}]}。全部坐标为世界像素。UNIT_TYPES: guard/archer/cavalry/siege/magic 配置{name,cost,supply,hp,damage,range,speed,interval,soldiers}；BUILDINGS mine/farm/obelisk {name,cost,description}。
- Simulation.state: {time,gold,mana,nodes,slots,units,casualties,effects,winner,events}; nodes 增加 hp/maxHp/level/captureProgress/captureOwner，slots 增加 owner/building（null或{type}）。单位 {id,owner,kind,x,y,hp,maxHp,nodeId,garrisoned,visualAction,facing,route:[{x,y}],locked}；effects [{id,owner,x,y,radius,remaining,type}]。
- Simulation API: step(dt), command(action)->{ok,message}, population(owner)->{used,cap}, income(owner)->{gold,mana}, recruitQuote(nodeId,kind)->{ok,cost,supply,message}, upgradeCost(nodeId)->number|null, projectRoad(x,y)->{x,y,...}|null。
- Commands: recruit {nodeId,kind}; build {slotId,building}; upgrade {nodeId}; move {unitIds,target:{nodeId} 或 {x,y}}（路径可达的节点/道路，整批验证后执行，不瞬移）； heal {x,y}。所有玩家指令在模拟层校验归属、资源及状态；近战锁定不可改令，失败保留旧路线。没有自动生产/自动派兵。
- Renderer: loadArt(), artURL(key), drawBattle(ctx,w,h,state,selection,reducedMotion,camera)；selection={nodeId,slotId,unitIds:[],spellAim:false}；camera={x,y,zoom}为世界左上角和每世界像素的屏幕比例。绘制坐标为(world-camera)*zoom。UI与Canvas共享坐标。terrain.js按LEVEL真实道路绘制连续地面，装饰来自RPG图集；不再加载原Map图片。
