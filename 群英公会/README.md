# 群英公会

手机横屏 2D 像素奇幻**公会经营**沙盒。你是一家新公会的会长：招募人类、精灵、兽人、亡灵等各族冒险者，召唤贞德、项羽等历史英雄，派他们接委托、守城、讨伐首领，一步步从 F 级小公会成长为 S 级传奇公会。没有终局，按「下一天」推进。

## 玩法
- **委托板**：挑委托，派 1–3 人，看预估胜率。勾选「观战」可以亲自督战：首领蓄力时**打断**，危急时**鼓舞**，搭档默契满了放**合体技**。
- **成员**：等级、装备锻造、羁绊与忠诚。关系好的成员组队有加成，被冷落或除名会让同伴失落。
- **招募 / 召唤**：每天有冒险者上门。公会等级够了可以在祭坛召唤历史英雄。
- **设施**：宿舍（人数上限）、训练场、酒馆大厅、地窖、锻造坊、英灵祭坛，随公会等级逐步扩建。
- **公会**：设定抽成税率，查看声望排名，处理随机事件。守城委托没人应战时，城镇会遭到劫掠。

## 运行
- 直接玩：`npm run build` 后双击 `dist/群英公会.html`（单文件，素材已内联）。
- 开发：`npm run preview` → http://127.0.0.1:4199/
- 测试：`npm test`
- 素材：`npm run import-assets`。按 `js/data.js` 实际引用的单位、特效和图标，从 Duelyst H5 接入包裁剪导入到 `assets/duelyst/`。
- 美术与字体：`python3 tools/prepare-art.py <原图目录>`，把子场景背景图降采样量化为像素图（`assets/art/`），并按游戏内用字裁剪像素字体（`assets/fonts/pixel12.woff2`）。
- 操作：主界面左右拖动浏览公会建筑，点房间或成员查看；底部快捷栏进入各子场景，右下角按钮结束当天。

## 结构
`js/data.js` 内容与特效键登记 · `battle.js` 确定性战斗引擎 · `sim.js` 公会逻辑 · `kit.js` 精灵/特效层 · `hallView.js` 公会大厅 · `battleView.js` 观战 · `main.js` UI 与存档。
