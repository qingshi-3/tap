# 王城守线

手机横屏普通 H5 塔防。当前试玩为「林心守望」开阔林地：玩家在波次之间规划兵与塔的位置，战斗由部队自动执行。

## 当前内容（0.4.0）

- 一张九波试玩图，西、北、南三个入口；树木、岩石和塔楼影响绕行，不能封死敌军通路。
- 12 种可招募角色：盾卫、哨卫、狂战士、弓手、游侠、神射手、法师、烈焰术士、寒霜术士、风暴术士、林地医师、唤灵师。四种建筑：箭塔、法师塔、火炮塔、兵营。
- 近战自动在驻地附近迎敌、攻击、归位；医师自动治疗，唤灵师自动召唤，阵亡士兵自动补员。脱战两秒后恢复生命。士兵与塔共同防守，无需逐个移动下令。
- 波次之间可招募、建塔、免费调整士兵驻地、升级塔楼或退款；战斗中锁定这些操作，只保留可选火雨救场。塔升级沿用完整建筑外观与星级。
- 点空地后选兵种直接部署；「布防」入口先选兵种再点位置。按近战、远程、支援、塔楼分组，远程目录可左右滑动。
- 双指缩放 1～2.5 倍，放大后单指拖动；横屏左右至少 72px 安全区、顶部避开宿主胶囊，触控按钮至少 44px。支持暂停、1×/1.6×、音效开关、竖屏及后台暂停。
- 自有 Duelyst 单位动画、命中特效和音效。当前使用 21 个唯一单位图集；源库有数百素材，不代表全部已接入。
- 林地通关采用独立本地存档 `castle-ward-h5.openfield.v1`，记录最佳星级、成功次数和完成波次。无法识别的数据保留原件并禁写；旧道路战役存档保持原样。

## 数值与适配

基础塔的费用、伤害、攻速和常见敌人基于已查证的 KR1 初代移动/Steam 普通战役、无星级天赋资料。寒霜借用 Elora 一级冰箭，闪电借用 Tesla 基础连锁；来源与映射见 [参考记录](docs/kingdom-rush-reference.json)。

单兵聚合三名兵营士兵、招募成本映射、单位耐久、开放地图坐标、波次编排、确定性中值伤害与即时命中均是本地适配，不能宣称原作精确平衡。只塔楼可升级，高级兵种直接招募。本轮交付一张完整试玩图；旧道路三关的战役解锁不等于新林地已有完整成长系统。
