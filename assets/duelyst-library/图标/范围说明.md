# Duelyst 图标目录原型

`index.json` 按独立运行时图像计数。每个 `source` 是 `duelyst-main.zip` 内的完整 PNG 路径；每个 `preview` 从本目录解析。多个卡牌共用图像时只收一条，名称和 `note` 列出对应分支。

| 分组 | 图像数 | 归类依据 |
| --- | ---: | --- |
| 法术 | 286 | 卡牌工厂中的法术分支显式引用对应待机资源 |
| 将领招牌技能 | 25 | 法术分支另有 `card.signatureCardData` 引用；包含 Boss |
| 神器 | 60 | 卡牌工厂中的神器分支显式引用对应待机资源 |
| 能力与状态提示 | 15 | `app/resources/modifiers/` 的独立状态提示图；`note` 列出资源注册键 |
| 图标素材（待核对用途） | 2 | 有图集和帧坐标；本次未找到卡牌待机引用。展示名取自素材标识 |

**来源链。** 在 ZIP 的 `duelyst-main/app/` 下，从 `sdk/cards/factory/**/*.coffee` 的 `identifier` 分支读取 `card.setBaseAnimResource` 的 `idle` 键，经 `data/resources.js` 的 `img`、`plist`、`framePrefix` 定位图集与待机帧。分支标识保留源码拼写。卡名优先取 `localization/locales/zh-tw` 与 `en` 中该分支使用的本地化键；缺失时使用代码中的字面名称或可读化的分支标识。能力与状态提示保留可读化的图片标识；具体战斗触发逻辑可查 `view/layers/game/GameLayer.js`。

**预览。** 373 张 `resources/icons` 图集均有配套 plist。371 张按注册的待机序列选择首个非透明帧；余下 2 张按 plist 帧名排序取首个非透明帧，`note` 记录实际帧名。依帧矩形、裁切偏移和原始画布尺寸还原透明 PNG。15 张提示图直接取运行时普通分辨率 PNG。

**覆盖和遗漏。** 收录 `app/resources/icons/` 全部 373 张运行时图集，以及 `app/resources/modifiers/` 的全部 15 张普通分辨率图像。`@2x`、激活动画各帧及 `app/original_resources/` 原始素材不另列；原始目录独有的 `original_resources/icons/generalspell_f3_windshroud.png` 亦在此范围之外。未扫描头像、单位精灵、战场特效、卡框、通用 UI、战斗日志等目录作为独立图标来源。无独立图像的机制和只在其他目录取图的卡牌也未收录。本目录适合按图查来源，条目数是独立图像数。
