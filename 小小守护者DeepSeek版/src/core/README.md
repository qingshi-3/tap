# 规则核心

`index.ts` 是唯一玩家动作入口；准备阶段的建筑拖动使用 `moveBuilding`，坐标规范到格中心，保留损伤、ID、冷却和金币，并按新位置失效流场缓存。`validateBuildingPlacement` 支持排除正在拖动建筑自身的占格。纯 TypeScript，不依赖浏览器或渲染。固定 30Hz；xorshift32 的状态保存在 `rng`；实体 ID 单调分配。每个回放动作包含逻辑 tick，回放封套同时检查规则版本、种子、地图与终止 tick。

`content.ts` 注册军团、二维阵型、各级格挡/穿透/范围机制、建筑、英雄及光环对象、效果卡、法术、敌人、地图和波次。不显式指定地图时，`chooseMapForSeed` 从注册的手工地图池按种子确定性抽取；存档和回放始终使用记录的地图 ID。新增内容须注册实际定义与地图供给，不能只增加类型枚举。`checkSupplyLegality` 拒绝敌人首次出场时仍没有已出售答案的地图。基础实体由供给起始波控制；晋升另受地图商店档次、经验与价格约束。

卡牌 `scope` 默认为军团；`global` 卡自动作用于玩家军团及对应玩家事件，无需挂载。空载体的普通卡保持待指派。事件依次处理全局卡和所属军团卡，各自按实例 ID 排序；死亡触发深度上限 8。医疗、死亡分裂与冲锋由敌人定义字段驱动；首批实际敌人仅为掠夺者、攻城弩、鸦骑及碎地者。

地面单位共享以核心为源的加权 Dijkstra；障碍不可走，可摧毁建筑可走但加上 HP / 20 秒的成本。路径取下一格时计入进入该格的成本；近战攻击选定路线上的阻挡建筑，攻城弩可射程内拆楼。流场按建筑 ID 和损伤档次缓存，建造、拆除、维修和损伤会失效。飞行单位直接朝核心移动。目标、塔攻击、范围伤害和软碰撞使用临时空间网格。

成员个体死亡后离场；波间存活军团满血补员，团灭永久丢失等级和烙印，回收卡回到待指派池。建筑伤害跨波保留。英雄倒下本波退场，波间重新分配身体并归队。每张地图声明战斗时限，时限耗尽判负，避免不可达地形或防守僵局无限运行。

原始数值来自 `C:/Users/qs/Downloads/README.md` 第 2 节：首批成员的 HP、伤害、攻击间隔、范围、速度、护甲、人数、晋升价，以及建筑/英雄/敌人/卡机制。攻击间隔换算为整数 tick。首批基础军团价格 42/48、初始金币 160、波间奖励 25 + 波数×5、波间经验 6、击杀经验 2、晋升经验 10/20、法术价格/治疗量/定身时长、30×20地图和各波构成是本次必要适配，原文未提供这些完整实现参数。不能把本次运行当作原文 200/400 局结论复现。

验证入口：`npx vitest run src/core/core.test.ts`。`npm run sim -- 20` 通过正式动作入口运行防守和空营地策略，每波核对回放哈希与波间存档读回；无金币/终局注入。实际证据在 `output/core-sim-20-seeds.json`。策略仅用于系统贯通，不代表已完成平衡或手机体验验收。
