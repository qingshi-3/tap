# 小小守护者 · DeepSeek 版

手机横屏、无固定路线的营地塔防，普通 H5，在 TapTap App 内运行。

这是《小小守护者》的**独立重制版**，与原版 `games/little-guardians-h5` 分开维护、互不影响：
保留已验收的确定性规则核心，**丢弃 PixiJS 与那套皮革金边 UI 皮肤**，改为
**自写 Canvas 2D 引擎 + 全部代码绘制的像素风界面**。

## 玩法

准备阶段没有倒计时。玩家从底部招募栏或商店**按住卡片拖进战场**落位，可以拖动场上已有军团与建筑重新摆放、
修理受损工事、用经验晋升军团、把效果卡挂到指定军团。按下开战后全自动战斗，玩家只剩次数制法术。

敌人不沿固定路线走：它们比较「绕路的长度」与「砸穿工事的成本」，自己选择便宜的一条。所以战场就是谜题
——用城墙、箭塔和站位把敌人引到你想让它走的地方。

## 技术栈与分工

| 层 | 位置 | 说明 |
|---|---|---|
| 规则核心 | `src/core/` | 固定 30Hz、单一种子随机、动作统一入口、加权流场寻路。沿用原版已验收实现，本版未改一行 |
| 渲染引擎 | `src/render/` | 自写 Canvas 2D，**零渲染库依赖**。契约见 [`docs/RENDERER-CONTRACT.md`](docs/RENDERER-CONTRACT.md) |
| 界面层 | `src/app.ts`、`src/style.css`、`src/index.html`、`src/ui/` | 全部由代码绘制：内联 SVG 图标、CSS 像素块、Canvas 肖像生成。**不含任何 UI 位图皮肤** |
| 素材 | `public/assets/` | 契约见 [`docs/ASSET-PIPELINE-SPEC.md`](docs/ASSET-PIPELINE-SPEC.md) |

## 视觉方向

三层各有身份，靠对比区分，而不是堆质感：

- **单位**：duelyst 原画帧，保留细节，不整体染色。敌我用脚下阵营环区分（我方青蓝、敌方橙红）。
- **地图**：MiniWorldSprites 16×16 真实地块拼贴。水域是**连通湖泊**（不是散点水洼），水陆交界用沙岸过渡，敌人走的走廊用土黄道路，草地有纯色/草丛两类变体按格坐标确定性分布（同一格每帧同一图，不闪烁）。
- **界面**：像素风硬边描边，冷色底、单一高亮色（青蓝）+ 琥珀金，零渐变、零模糊阴影。范围与警戒用**细虚线导引**，不用实心色块。

绘制单位纪律：世界坐标下 1 格 = `cell` 个设备像素，**像素宽度必须用 `cellPx(px, cell)` 换算**，不能再除以 `cell`。把像素当格用会让描边与填充被放大 `cell` 倍（曾导致范围环变成覆盖屏幕的直角色块）。

设计约束（长期有效）：

- 战场优先，常驻 HUD 只占四角；操作按需出现在选中对象附近，不用全宽面板盖住主城与战线。
- 触控目标至少 44px；手机横屏两向、568×320 短屏与方角都要验收。
- 滚轮、键盘、悬停都不是操作前提；手机单指可以拖动地图。

## 存档契约

本机固定键 `deepseek-guardians.run.v1`，局外档案 `deepseek-guardians.profile.v1`，与原版完全隔离。

准备阶段每次合法操作保存；战斗保留开波前检查点，重进可重新挑战本波；波结束与胜负保存。
未知版本、损坏结构与存储失败都**保留原件并返回错误**，不清空、不静默重置。显式新局先备份原字节，
备份失败就拒绝替换。已加载页检查旧值后发现其他页面改了进度，拒绝覆盖。

浏览器存储不是跨设备云存档，也不能提供跨标签页事务。本次不承诺与原版存档互通（键位与版本都不同）。
