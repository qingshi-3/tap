## 2026-10-20 行动回合（当前规则）

每单位每回合默认行动一次；每拍双方各选一名，先施法后普攻，普攻同时结算。一方本轮行动完就等待，双方都完成后，有额外行动的单位按站位进入下一轮；全部次数耗尽才进入新回合。立即攻击只执行普攻，不消耗常规行动；连击仍在一次攻击内结算。行动机会与单位自身行为解耦，唤亡祭师仍为本场三次施法后普攻，其余施法不统一限次。

寒意即时影响接下来的有效出手，按相关出手机会消耗，回合结束不清掉尚未生效的寒意。灼烧、主将计时与疲劳仍按拍。双方同时为施法者时保留原有我方先结算的顺序。

新增中立传令使：让攻击最高的其他友军本回合行动+1，每回合限成功授予一次；新增中立祭仪师：献祭身前最近友军，使其余最高攻的另一名友军本场+1/2/3攻，无合法祭品或获益者时普攻。已给予的行动不随来源死亡消失。战阵指挥官保留队首开战+2/3/4攻血，追加队首首回合行动+1；新增号令卷轴，同样给予队首首回合行动+1。

当前长期规则见 [DESIGN-v0.7-远征.md](DESIGN-v0.7-远征.md)，交付证据见 [TASK.md](TASK.md) 的行动回合条目。下方v0.6及更早章节保留为历史记录，不代表当前卡池、路线或测试结果。旧run/run-pools测试尚未适配章节路线、六阵营和现有字段，完整旧套件仍有失败；本次按实际行为验证行动规则、内容、回放和固定四战教程。
