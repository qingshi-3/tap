## 试玩与开发

- 双击 `阵列-双击打开.html`，无需服务。
- 当前开发预览 `http://127.0.0.1:8788/`。
- 分包版：本目录执行 `python -m http.server 8766`，打开 `http://127.0.0.1:8766/dist/`。
- 普通浏览器缺少 TapTap 广告 SDK，不能验证真实激励视频。

需要 Node.js 20.19+ 或 22.12+；以下命令在 `source/` 中运行：

```powershell
npm ci
npm run dev
npm test -- --maxWorkers=2
npx tsc --noEmit -p .
npm run build
npm run build:single
```

构建分别写 `source/dist/`、`source/dist-single/index.html`。交付时将分包版同步到根 `dist/`，单文件同步到 `阵列-双击打开.html`，更新 `MANIFEST.sha256` 并核对源/目标哈希。不要使用删除主工作区的通配脚本。

## 存档契约

固定存储键 `zl_expedition_v1`，结构版本仍为1。支持结构1的0.8.0至0.11.0档续玩；tacticsVersion=1采用新四将/战术规则，缺省沿用旧主将/晋升/商店；未知规则版本拒绝并保留原件。缺economyVersion的旧远征保留旧经济至结束，新远征使用economyVersion=2，不折算旧金币、不重发历史预算或成长。旧档缺 `pendingEggs` 按0。能力永久成长与可退款培养点分账，旧主将法强保留，不承诺跨战历史投入全部可退。实际0.8.0历史档、由旧源码生成的0.8.4冻结档和当前档均已验证交易、真实战斗、保存、重进及继续保存。不支持的结构或无效字段保留原档并提示不兼容，不静默重置。浏览器不同origin与单文件入口各自存档，本轮不实现跨设备同步。
