## 1. 平衡（当前最大问题）

### 1.1 开局太难（待拍板）
- 随机两张一阶卡打第 1 场，平均胜率 **25%**；主将差距大：kara 82%，vulkan/kaleos/kasiva ≈68%，其余 ≈25%。
- 候选：① 削弱第 1 场敌人（推荐，改动最小）；② 第 1 场给 3 张卡；③ 开局送固定起手单位。

### 1.2 决斗流（擂台点将）垫底（待拍板）
- S2 固定阵容 P17，对位胜率 0%；打 Boss 无解。
- 原因：「对手」取决于敌方谁出手，看不见也排不了；收益全是「击杀后自己变强」，互不联动；本体脆。
- 背刺者（s_backstab）与岚刃剑客（s_xyle）几乎同质。
- 推荐方向：决斗改为**固定对位**（我方第 N 格打敌方第 N 格），可与「对位」流派、蕾娃换位合并；加广播型联动收益（如「任一友军击败对手：全体友军本场 +1 攻」），遵守「不做留给特定单位消费的资源」；拉开背刺者（收割）/ 岚刃剑客（打硬前排）。

### 1.3 召唤流前期太弱（待拍板）
- 成型强（破壳献礼 P87），但前期单卡第 1 场胜率仅 **10–13%**（如沙嚎者蓄力 2 次才召 2 只 1/1）。
- 候选：① 召唤卡本体加血；② 开战先召唤一次，不等蓄力。

## 3. 规则 / 文本不一致（涉及规则，待定）

- 蓄力技、光誓、余韵**不算施法**：不触发「施法后」和「法涌」。要么改引擎，要么在说明里写明。
- 「本场最多 N 次」会被法涌、余韵叠破上限。
- 「命中」包含被格挡的攻击，但反击文本写「直接命中」。
- a_chanter、v_drake 1★「法强 +1」无效：群体技能按法强/2 向下取整。
- 「必定冻结」实际不保证。
- 主将法强与单位法强的关系没写清。
- 「复生」与「复活」混用；「轮换 / 轮转 / 换位」混用；「词条 / 关键词 / 标签」混用。
- 「友军」是否含自己不统一。
- 未定义词：压轴者、先机、星轨。
- 「成为队首时」开战时不触发。
- sp_revive / g_revive 跳过已有复生的单位；e_void 对已被拉过的单位无效——需在文本中说明或改行为。

## 4. 其他约定（不变）

- 不改 TapTap 应用名；不做排行榜；不上传/发布；广告不在范围内。
- 手机优先：不靠悬停、舞台字号 ≥18、说明框不挡目标；常驻动画只动 transform/opacity。
- 词条二选一：像素 icon 或「」彩色短词，不并用；数值标签用像素牌。
