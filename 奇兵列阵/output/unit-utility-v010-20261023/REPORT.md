# 全单位实用性与 SAP 对照（2026-10-23）

当前112张普通卡全部逐项审查，64张建议保留、46张调整、2张重做；40个特殊定义另有27保留、13调整。保留表示当前用途成立，不表示强度已校准；调整包含触发时机、卡面契约、阶级与配套，不等于46张统一加数值。本轮没有重做单位或修改嘲讽。

## 依据与边界

以 Super Auto Pets（SAP）成熟基础包 Turtle 为主要设计基准，缺少对应时再参考 Golden、Unicorn。使用 [Grounded SAP](https://groundedsap.co.uk/Pets.aspx) 的2026-10-22社区快照；补丁号未核实。239条引用逐条核对原文、阶级、包和名称，不猜测高星倍率、不混入未核实历史数值。快照与分类位于 ../archetype-density-20261022/sap/。

每张普通卡有职责、最小配合、五格占位与替代成本、重复度、建议、证据、置信度及SAP参照。当前DRAFT_POOL的112个ID与报告完全一致，全部UNITS的152个ID无遗漏、无重复；见coverage.json和verify.ts。特殊召唤物、旧将专属和敌人按真实来源与固定遭遇评估，不强行冒充SAP商店宠物。

SAP的前排碰撞、我方全队行动与轮换存在结构差异。直接照搬+1/+1不能得到同样强度：应比较在几次有效行动内触发、是否挤掉成熟战位、是否真的多活/多打一击、首次一星获得时剩余多少成长窗口。出售会退培养点和装备；不可退款的能力成长、副本净金币、位置与触发窗口才是换卡损失，不能把所有培养都算沉没成本。

## 收敛顺序

1. 先修“玩家做了正确动作却看不到收益”：培养契约/反馈、银盾与风刃时序、无实际法强收益对象筛选。
2. 召唤拆清楚三种职责：阵亡腾位的接力、可靠承伤/触发的工具、即时放大召唤的核心。噬焰与沙嚎的行动等待和满编收益要分别测；不因有召唤标签就算成型。
3. 重新审核5/6阶首次一星买入。圣铸、宗师、铁崖、熊猫、主母等不以三星或无限成长作免责；与已培养旧核心交换后，测当前战及剩余路线的净收益。
4. 刃影导师、永夜吟诵者优先重做：后期慢养回本与标签筛选失配。保留的相似卡也要按玩家决策差异看，不因内部事件名不同就判去同质；逐卡表的redundancy保留同质风险。
5. 上述方向需同预算替代与合法取得轨迹验证，再联合调整敌方。当前第二章首领控制/护盾/疲劳瓶颈及敌方采购能力失配仍未修，不用本轮小样本冒充全局平衡。
