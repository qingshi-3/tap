# 内容扩充 UI 证据索引

本目录是早期内容扩充的历史验收记录。其常驻四阵营块、额外单位工具栏和三份半进度已被用户后续要求撤销，不能作为当前UI或升星契约。

当前源码、控件回退、严格同星合成、品质分色和备战攻血的最终证据见 [ui-restoration/report.md](../ui-restoration/report.md)，逐项区分568/844触摸和1280鼠标。667×375仅为早期阶段验证，未冒充当前最终回退验收。

早期report-568.json确有一组568完整操作/广告替身验证；report.json确有一组1280记录。667/844早期检查的截图保留在本目录，终端执行输出曾记录通过，但未单独保留同等完整JSON日志，不宣称本目录有四尺寸完整最终报告。

备战台座复用材质与长三星技能触摸滚动的阶段证据见touch-report.json。历史CDP首次还原tap未验收，事件记录见touch-report-568-press100.json；原因未定位，不判定为工具问题。

拖动人物残留的新修复、修前/后第4拍截图、库存守恒及生命周期清理见 [ui-residue/report.md](../ui-residue/report.md)。实际TapTap宿主广告、手机实机与功耗不能由这些本地浏览器替身结果替代。
