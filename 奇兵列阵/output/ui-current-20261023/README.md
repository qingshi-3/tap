## 实际操作覆盖

新游戏、主将选择、图鉴各页、说明、设置和战绩；货架详情、拖拽购买、培养分配、同名合并与高阶奖励购买；主将目标选择、四场胜利、复盘；商店培养包和两张单位购买、限购0/2；战术三选一、普通路线、保存并继续。游戏未报告运行时异常。

## 范围限制

- 本次不是21战全通，不覆盖后续章节、精英奖励、失败和远征结束界面。
- 844×390和568×320为桌面浏览器触控视口模拟，不等于真机测试。
- 截图记录现状，不代表所有界面已完成视觉或可访问性验收；现有小字号、边框和密集信息保留供评审。
