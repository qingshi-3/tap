# 六阶经济首轮合法策略样本

260局，5076战的固定种子配对样本；最终运行13.476秒。13主将各10个合法开局seed，每seed各steady/synergy。前5校准、后5保留验证，版本0.9.0。无battle lookahead、force/ban passive、资源注入或重打挑结果。

## 口径与完整性

每次备战按真实货架买3、刷新1、锁定、星级卖价1/2/3；购买不自动刷新。buildBattle只预测一次，simulate只运行一次，再beginBattle/finishBattle真实提交成长。endPrep逐次比较预测与真实提交growth；失败交易核对金币不变。首四按路线战序统计，疲劳按实际伤害事件；获取时间按本局实际战斗尝试序号，含备战位和特殊商店，排除主将专属/召唤物。

本批fault、失败动作、负金币、非法金币增量、成长提交不一致均0。全部core与两个模拟脚本SHA256见sample-evidence.json，运行期间changedDuringRun为空。该审计证明脚本所用交易路径的一致性，不是对所有外部输入的穷举。

## 策略故障与校准入口

首轮v1有13次星角购卡拒绝，全部来自“卖出腾位→待领蛋立刻补位→按旧空格购买”。API拒绝后金币不变，没有非法收益；这是策略未重新读取公开阵容，不能当平衡缺陷。v1原始证据保留sample-v1-runs.json与sample-v1-evidence.json。已禁止待领蛋占位时按腾空假设卖卡，并在出售后重查unitDestination，最终批次失败动作0。校准/保留两组均只应用此事务正确性修复，未用保留组数字调卡。

初烟测另发现特殊商店8格满仍尝试购买，已补unitDestination前置检查；initial-smoke-runs.json保留原拒绝证据。

当前策略局限：steady/synergy皆为卡面身材/阶级/重复合成启发式，synergy叠主将与标签权重；场面高生命/嘲讽优先，没有搜索多卡组合、让出位置培养单一精英、主动买卖成长引擎或为特殊商店提前清位。growth已纳入评分和摆位，但不是长期收益规划器。因此召唤/成长体系可能被低估。

优先下一步：星角与赫克两策略都0/10通关，应先检查公开策略是否正确运用孵化/佣兵，再讨论改卡。赫克338战中61战带临时佣兵，不能简单说“完全没有雇佣”；例如steady seed1022003赢20场后连续3次在3-9失败，最终场前余额0/1/3，阵容v_bear/n_colossus/v_wyvern/a_void/s_panda。这是明确的后程样本入口，不足以证明资源预算或某卡必须上调。

没有执行进一步数值校准，等待主责选择产品层面改动或先改公开策略。
