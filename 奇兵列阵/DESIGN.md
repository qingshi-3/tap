# 《奇兵列阵》流派与主将重构 v0.8

> 状态：草案（2026-10-21），待评审，未改代码。数值都是初值，实现后再跑模拟粗调。
> 本稿取代 v0.7 第 7 节（主将）、第 9 节（卡池）和词条表。战斗调度沿用 2026-10-20 的回合/交锋/追击规则。
> 设计原则：
> - 收益只用三种形态：自给自足、广播、确定指定。
> - 主将改写的是通用动词，不绑定流派。
> - 玩家在玩组合，不是在玩单张卡。

## 1. 总览

| 项 | v0.7 | v0.8 |
|---|---|---|
| 流派 | 8 个，都有其他游戏的既视感，易伤的收益不可控 | 9 个，其中 3 个是本作独有：**车轮战、决斗、坚守蓄力** |
| 卡池 | 6×12 + 中立 14 = 86 | 6×16 + 中立 16 = **112**，另有召唤物 9 种，外加星角的龙系 |
| 每局阵营 | 4 个 | 4 个 + 中立，并保证主将所属阵营在内 |
| 主将 | 7 位，同一个模板（每 3 次交锋结束放一次技能） | **13 位**，各自改写一个通用动词 |
| 删除 | — | 易伤、护卫（改为嘲讽）、数值型溅射（改为布尔特性）、反击流派（只留针对卡） |
| 新增 | — | 轮换、决斗、蓄力、节拍、嘲讽、亡语，以及「召唤插入」规则 |

单阵营 12 张撑不起两个流派，加上中立配件后再加上跨阵营组合，卡数明显不够，所以扩到 16 张。每局只开 4 个阵营，实际卡池是 4×16+16 = 80 张，比现在的 86 张还略少，抽卡密度不会被稀释。

## 2. 关键词

### 2.1 新增

| 词 | 规则 |
|---|---|
| **轮换** | 特性。常规行动（普攻或施法）结束后，自己退到我方队尾，身后的友军整体前移一格。不增减行动次数。追击之后不轮换。 |
| **成为队首时** | 触发。无论原因（轮换、前排阵亡、换位、召唤插入），只要成为我方队首就触发。每个单位每次交锋最多触发一次。 |
| **在队尾时** | 触发。每次交锋结束时，如果自己在我方队尾就触发。 |
| **决斗** | 特性。普攻打本次交锋的**对手**，也就是同一次交锋中和自己同时出手的敌人；没有对手时打敌方队首。选目标的优先级：嘲讽 > 决斗/狙击 > 队首。 |
| **击败对手** | 触发。用普攻（包括追击）击杀本次交锋的对手。 |
| **蓄力 N** | 特性。每次常规行动照常进行，结束后 +1 蓄力；满 N 层后，下一次常规行动改为释放**蓄力技**，然后清零。被冻结跳过的行动不蓄力，追击也不蓄力。蓄力在整场战斗中保留，卡面上用小圆点显示进度。 |
| **节拍 N** | 特性。每 N 次交锋结束时触发一次，用于不出手的单位（方尖碑、蛋）。原来「每 3 次交锋」的写法全部改成节拍，和蓄力共用同一种圆点显示。 |
| **嘲讽** | 特性。敌方的普攻（包括默认的打队首）都改打嘲讽单位。施法、溅射、灼烧和群体效果不受影响。有多个嘲讽时只认最靠前的一个。 |
| **亡语** | 触发。阵亡时触发，取代旧的「阵亡时」写法。复生先结算，然后才结算亡语，所以亡语召唤出的单位会插到复生单位身后。 |
| **召唤** | 动作。见 2.3 节「插入规则」。 |
| **不行动** | 特性。从不进行常规行动，也不占用交锋（方尖碑、蛋、沙像）。 |

### 2.2 改写

| 词 | 改动 |
|---|---|
| 溅射 | 改成布尔特性：普攻时，目标身后一名敌人受到**本次攻击力的一半**伤害（向下取整，最少 1）。连击也只溅射一次。不吃也不触发反击。能给全队溅射的卡改为只给相邻友军。 |
| 法强 | 去掉对「易伤」的强化，其余不变。 |
| 放逐 | 被放逐者击杀的单位**不复生，亡语也不触发**。这是亡语流的正式克制。 |
| 反击 | 不再作为流派，只保留中立的棘背兽和装备荆棘甲，用来针对连击。 |
| 狙击 | 保留，作为配件。和决斗同属「指定目标」一类，都被嘲讽覆盖。 |

### 2.3 召唤插入规则（R1–R6）

- **R1 位置**：原位空着就放在原位；原位被占时插到来源身后，后面的友军依次后移。
- **R2 满员**：我方已有 5 个单位时，召唤失败，改为离来源最近的友军获得召唤物的攻击和生命，各取一半，本场有效。
- **R3 行动**：亡语召唤出的单位继承死者本回合**剩余的行动次数**。施法或开战时召唤的单位从下回合开始行动。特权卡（孵化看守）可以让召唤物当回合就行动。
- **R4 召唤物**：召唤物没有亡语，没有星级，不能出售，战后消失。
- **R5 防循环**：「亡语触发两次」效果不叠加。「全体 +攻」类的广播收益每回合有次数上限，卡面上写明。
- **R6 表现**：插入时，后方单位做 0.2 秒的位移动画（只动 transform），出手序号徽章同时刷新。

### 2.4 删除

**易伤、破绽、护卫**。原来带易伤的 17 张卡在第 4 节逐张重写；敌人「诅咒者」改成降低攻击。

### 3.2 克制关系（玩家能读懂的那几条）

| 克制方 | 被克制 | 原因 |
|---|---|---|
| 嘲讽 | 决斗、狙击 | 嘲讽优先于决斗和狙击选目标 |
| 寒意 | 蓄力 | 被冻结跳过的行动不蓄力 |
| 灼烧 | 格挡、护甲 | 灼烧无视两者 |
| 溅射、群体伤害 | 人口 | 召唤物又小又挤 |
| 放逐 | 亡语、复生 | 被放逐者击杀的单位亡语不触发 |
| 反击 | 连击 | 每段都会被反击 |
| 车轮战 | 灼烧、寒意 | 带状态的队首会被换走，灼烧打在后排，寒意等下一次出手才生效 |
| 决斗 | 车轮战 | 对手是确定的，你怎么轮换都会被盯住 |
| 人口 | 冻结、单体输出 | 尸体多 |

正好形成循环，只要卡池里有，就没有无解的阵容。

## 5. 主将

### 5.0 结构

- **一个核心技能**，改写一个通用动词，和流派无关。
- **4 个专属被动**，在晋升时出现（规则沿用：1 个专属 + 2 个通用），作用是**改变这个动词的方向**，而不是给数值。
- 主将法强（培养点）只强化主将技能中带「+法强」的数字。
- 开局 3 选 1，见第 7 节。

### 5.1 阿尔吉昂「亲征」（圣光）

**核心**：阿尔吉昂作为单位上场，占一个格子，不能出售。基础 3/8，每章 +1/+3，可以吃培养点和装备。每场第一次受到致命伤害时，保留 1 生命。

| 被动 | 效果 |
|---|---|
| 盾誓 | 阿尔吉昂获得嘲讽；每次被普攻后：身后的友军获得 1 层格挡 |
| 剑誓 | 阿尔吉昂获得决斗和连击；击败对手时：全体友军本场 +1 攻 |
| 光誓 | 阿尔吉昂的常规行动改为施法：全体友军恢复 2+法强 生命 |
| 王誓 | 阿尔吉昂获得轮换；他成为队首时：全体友军获得 1 层格挡 |

和不同流派的涌现：
- **坚守**：他是一个不会被秒的嘲讽。
- **决斗**：他是一个必定在场的决斗手。
- **车轮战**：他每一轮都触发一次全队格挡。
- **亡语**：「保留 1 生命」让他成为最后一个倒下的人，给亡语链收尾。

### 5.2 齐兰「轮番上阵」（圣光，新）

**核心**：每回合结束时，全队轮转一格：队首去队尾，其余前移。

| 被动 | 效果 |
|---|---|
| 回马枪 | 轮转前：离开队首的友军先追击一次，本次 +2 攻（10-22 替换原「逆轮」） |
| 接力 | 因轮转成为队首的友军，下回合 +2+法强 攻 |
| 换防 | 被轮转到队尾的友军恢复 3+法强 生命，并获得 1 层格挡 |
| 急转 | 改为每次交锋结束时都轮转（每回合最多 3 次） |

涌现：
- **车轮战**：每回合白送一次「成为队首时」。
- **嘲讽**：嘲讽位会转走，需要两个嘲讽（原「逆轮」已替换为回马枪）。
- **亡语**：残血单位被转到前排送死，提高阵亡频率。
- **蓄力**：每个人轮流站上前排吃伤害，后排安心充能。
- **冰霜**：寒冬守望者轮到队首时护甲最高。

### 5.3 卡雷奥斯「压轴」（暗影）

**核心**：每回合我方**最后一个**完成常规行动的友军，在行动后追击一次，本次攻击 +法强。

| 被动 | 效果 |
|---|---|
| 首发 | 改为每回合**第一个**出手的友军 |
| 余韵 | 压轴者如果是施法单位，改为再施法一次，不追击 |
| 双幕 | 倒数第二个出手的友军也追击，但伤害减半 |
| 影步 | 压轴者追击后和我方队首交换位置 |

涌现：
- **连击**：追击也能连击，所以队尾放连击手。
- **灼烧**：普攻带灼烧的单位追击时多挂一层。
- **决斗**：追击仍然打对手，等于对同一个人连打两次。
- **法强**：选余韵，队尾放大法师。
- **车轮战**：选影步，每回合额外制造一次「成为队首」。

站位决定谁是压轴，玩家每局都要重新想一遍。

### 5.4 蕾娃「调虎离山」（暗影，新）

**核心**：每场战斗开始前（在布阵界面），可以选两个敌人交换位置，每场一次。

| 被动 | 效果 |
|---|---|
| 二度 | 每场可以交换两次 |
| 惊扰 | 被你调动的敌人本场攻击 −(1+法强/2) |
| 抢拍 | 被你调到队首的敌人首回合最后出手 |
| 孤立 | 被你调到队尾的敌人本场不能被其友军治疗或增益 |

涌现：
- **决斗**：直接把敌方脆皮输出排到你决斗手的对位上。
- **狙击**：把敌方核心放到队尾。
- **溅射、灼烧**：把脆皮放到坦克身后，吃溅射。
- **寒意**：把敌方最高攻击换到队首，让它第一个被冻结。
- **亡语**：把敌方高攻单位换到你的嘲讽亡语单位对面，帮你加速死亡。

锚定符这类法术能防住它，反制关系是现成的。

### 5.5 莉莉丝「魂潮」（深渊）

**核心**：双方任一单位阵亡时，你获得 1 魂。每攒满 3 魂：全体友军本场 +1/+1（魂数显示在主将头像上）。

| 被动 | 效果 |
|---|---|
| 收割 | 改为每 3 魂：敌方队首受 4+法强 伤害 |
| 魂火 | 改为每 3 魂：在我方队尾召唤一个 2/2 暗影 |
| 噬魂 | 只有敌人阵亡才计魂，但每个计 2 |
| 冥约 | 每 3 魂：额外让第一个阵亡的友军以一半生命复活，插到队尾（每场最多 2 次） |

涌现：
- **亡语、人口**：自家召唤物也会死，魂攒得最快。
- **溅射、群体伤害**：杀敌方小怪也算。
- **决斗、连击**：击杀多。
- **坚守**：选收割，靠打伤害赢。

### 5.6 卡西瓦「血祭」（深渊，新）

**核心**：开战时，献祭我方**队尾**单位；其余友军平分它的攻击和生命（向下取整），本场有效。献祭会正常触发亡语和复生。

| 被动 | 效果 |
|---|---|
| 双祭 | 改为献祭队尾两个单位 |
| 哀悼 | 被献祭者的亡语触发两次（和深渊主母不叠加） |
| 血债 | 改为只把属性给队首，但给的是全额 |
| 余烬 | 被献祭者在第 2 回合开始时以一半生命回到队尾 |

涌现：
- **复生**：被献祭者带复生时，立刻原地复活，相当于白拿属性。
- **亡语**：开战就触发一次亡语。
- **人口**：把蛋或方尖碑放在队尾献祭，直接拿到召唤物。
- **车轮战**：队尾每场都会变，配合齐兰要提前想好谁在队尾。
- **决斗**：献祭后，双方的对位整体错开一格。

### 5.7 瓦尔坎「火山战场」（熔岩）

**核心**：每回合结束时，敌方队首获得 2+法强 层灼烧。

> 2026-10-21 修订：原方案烧双方，模拟显示「熔岩护体」成了必选（去掉后通关率 58%→20%）。改为只烧敌方；烧自己改由「浴火」主动选择。

| 被动 | 效果 |
|---|---|
| 浴火 | 我方队首也获得同样的灼烧；我方单位每次受到灼烧伤害后，本场 +1 攻 |
| 地裂 | 改为敌方队尾 |
| 余烬扩散 | 带灼烧的单位阵亡时，剩余灼烧转给它身后的单位 |
| 熔岩护体 | 每回合结束时：我方队首获得 1 层格挡 |

涌现：
- **灼烧**：给敌方额外加层数，配熔血巫兽一起叠。
- **车轮战 + 浴火**：我方队首每回合都换，灼烧被摊薄，攻击加成摊到全队。
- **嘲讽护甲**：熔岩护体让嘲讽坦克多扛一下。
- **亡语**：敌方队首被烧死时触发我方的击杀收益；浴火时我方队首被烧死触发亡语。
- **成长**：选浴火，让我方越烧越强。

### 5.8 星角「龙蛋」（熔岩，新）

**核心**：开局获得一颗龙蛋：0/6，不行动，占一个格子，可以出售。每场战斗统计 5 类事件（我方阵亡、敌人灼烧伤害、敌人被冻结、我方换位或轮换、我方召唤），场后累积。任意一类先满 12，龙蛋就孵化成对应的龙（永久单位，三阶强度，可以升星）。

| 主导事件 | 孵化 | 效果 |
|---|---|---|
| 阵亡 | 骨龙 5/10 | 亡语：召唤 3/3 骨龙幼体；友军阵亡时 +1 攻 |
| 灼烧 | 炎龙 5/9 | 溅射；普攻后目标获得 3 层灼烧 |
| 冻结 | 霜龙 4/11 | 任一敌人被冻结时：追击一次 |
| 换位 | 风龙 5/8 | 轮换；成为队首时：敌方队首受 3 伤害 |
| 召唤 | 群龙母 4/12 | 节拍 3：召唤 2/2 雏龙 |

| 被动 | 效果 |
|---|---|
| 早孵 | 阈值降为 8 |
| 双黄 | 孵化时再得一颗新蛋 |
| 龙血 | 龙本场 +法强/+法强×2 |
| 硬壳 | 龙蛋获得嘲讽和护甲 2 |

不管走哪条流派，都会孵出对应的龙。

### 5.9 法伊「先机」（冰霜，重做）

**核心**：第 1 回合，敌方全体推迟一个行动轮，我方先全部出手一遍，敌方再出手。从第 2 回合起恢复正常。

| 被动 | 效果 |
|---|---|
| 凝滞 | 先机期间被我方命中的敌人获得 2+法强 层寒意 |
| 长冬 | 先机延长到第 2 回合，但只推迟敌方的最后两个单位 |
| 后发 | 改为我方首回合后发，但我方本回合全体 +3 攻 |
| 冰封时刻 | 先机期间，我方蓄力单位每次行动多 +1 蓄力 |

涌现：
- **法强**：群体法术先手爆发。
- **蓄力**：选冰封时刻，开局就能放出蓄力技。
- **决斗**：敌人都没出手，没有对手，决斗手转打队首；选后发可以重新对齐对位。
- **连击追击**：抢在敌方嘲讽或格挡上来之前收割。
- **冻结**：选凝滞，敌人第一次出手就被冻住。

不再绑定冰冻流。

### 5.10 卡拉「棱镜」（冰霜，新）

**核心**：开战时，统计我方场上单位一共有几种不同的关键词。每种让全体友军本场 +1 生命；每满 3 种再 +1 攻（攻击最多 +3）。

| 被动 | 效果 |
|---|---|
| 纯色 | 改为：最多友军共有的关键词，带它的友军各 +X/+X（X=带它的友军数+3）（10-22 修订） |
| 折射 | 每种关键词改为让我方队首获得 1 层格挡（最多 3 层），其余收益不变 |
| 分光 | 关键词种类 ≥6 时，全体友军获得「法强 +1」 |
| 共鸣 | 改为统计双方的关键词种类，敌人种类越多你越强 |

涌现：鼓励玩家**跨流派混搭**，例如「嘲讽 + 蓄力 + 轮换 + 溅射 + 亡语」。选纯色则反过来奖励单一流派。

### 5.11 齐瑞克斯「星轨」（沙漠，重做）

**核心**：主将每次交锋结束时积 1 星能；满 4 时，交换敌方的队首和队尾，然后清零。

> 2026-10-21 修订：原方案双方都换，「单轨」（只换敌方）成了必选（去掉后 34%→4%）。改为只换敌方；换自己改由「内轨」主动选择。

| 被动 | 效果 |
|---|---|
| 星痕 | 被交换的敌人各获得 2+法强 层寒意 |
| 轨迹 | 双方每发生一次换位（星轨、轮换等都算）：全体友军本场 +1 攻（10-22 替换原「内轨」） |
| 引力 | 被交换的单位各受 3+法强 伤害 |
| 近轨 | 改为交换队首和第 2 位 |

涌现：
- **车轮战**：额外制造「成为队首」。
- **嘲讽**：把敌方嘲讽调走，让你的决斗或狙击重新生效。
- **亡语**：把残血亡语单位调到前排。
- **蓄力**：把蓄力已满的单位换到前面。
- **决斗**：对位整体改变。

### 5.12 萨吉「预备队」（沙漠，新）

**核心**：我方获得第 6 格**预备位**。预备位的单位不行动、不能被选中、不吃广播收益。我方出现空位时（阵亡后），预备单位立即补进空位，当回合可以行动。

| 被动 | 效果 |
|---|---|
| 待命 | 预备单位每次交锋 +1 蓄力；没有蓄力的单位改为每次交锋 +1 攻（最多 +3） |
| 援军 | 补位者入场时本场 +2+法强/+2+法强 |
| 双预备 | 预备位增加到 2 个，按顺序补位 |
| 收容 | 召唤因满员失败时，召唤物进入预备位（取代 R2 的属性转移） |

涌现：
- **亡语**：死一个补一个，阵亡数更多。
- **人口**：选收容，召唤物不会因为满员浪费掉。
- **蓄力**：选待命，蓄力单位在后台充满后再上场。
- **决斗**：补位后对位重新排列。

### 5.13 赫克「佣兵团」（中立）

**核心**：每场战斗前，商店额外出现 1 个**临时佣兵**：一张随机二阶单位，价格 1 金，只参加本场战斗，战后离队。每场胜利 +1 金。

| 被动 | 效果 |
|---|---|
| 长约 | 临时佣兵改为可以花 3 金转正 |
| 抚恤 | 临时佣兵阵亡时 +1 金 |
| 精锐合同 | 临时佣兵改为随机三阶单位 |
| 军需官 | 每场开战前额外获得 1 张随机一次性法术 |

涌现：临时佣兵来自本局所有阵营的卡池，相当于每场都能**试一张别的流派的卡**，最适合摸索阵容。

## 7. 开局与卡池规则

1. 新一局先随机出 **4 个阵营**。
2. 主将三选一：从这 4 个阵营的 8 位主将里随机抽 2 位，再加上赫克。
3. 选定后：
   - 主将所属阵营保证在池里（本来就在）。
   - 赫克不绑定阵营，4 个阵营保持随机。
4. 每局可用卡池为 4 阵营 × 16 + 中立 16 = **80 张**，敌人仍然从全部阵营里生成。
5. 阵营招募令只能选本局可用阵营。词条招募令的标签换成新流派标签：轮换、决斗、蓄力、嘲讽、亡语、召唤……
6. 刷卡推荐算法（v0.7 第 5 节）的流派权重表按第 3 节重建。

后续可选：高难度改成 5 个阵营。卡池变大会更难成型，正好作为难度维度。
