打包日期：2026-10-19（v0.14）

一、直接试玩
解压整个压缩包后，双击“阵列-双击打开.html”。此文件已内嵌运行所需素材。
当前为 v0.14：3 章 21 战、3 条命，标题页有“新手教程”和“图鉴”。规则见 DESIGN-v0.7-远征.md（v0.8 起的数值改动以源码为准）。
普通浏览器没有 TapTap 广告 SDK，广告不能播放或发奖。

二、静态站点
dist/ 是当前分包版本。
可在本目录执行：python -m http.server 8766
然后打开：http://127.0.0.1:8766/dist/
如果端口已被占用，请换一个可用端口。

三、编辑、测试与重新构建
安装 Node.js 20.19+ 或 22.12+，在 source/ 中依次执行：
  npm ci
  npm run dev

其他命令（均在 source/ 中执行）：
  npm test               运行规则测试（tests/ 尚未适配 v0.7，tsconfig 已排除）
  npm run build          生成 source/dist/ 分包版本
  npm run build:single   生成 source/dist-single/index.html 单文件版本
  npm run sim            运行模拟
新构建不会自动覆盖根目录 dist/ 或“阵列-双击打开.html”。
游戏使用的已导出素材均在 source/src/ 中；正常构建不需要外部源素材库。
美术重新导入脚本需要原始 Duelyst 素材库，浏览器验收脚本中的 Edge/Playwright 路径与端口需按运行机器调整。

八、v0.10 改动（相对 v0.9）
