# 单位特效方案（v0.12.1）

## 现状

- 战斗回放里没有任何按单位区分的特效。每个能力按事件类型走通用表现：伤害是红球，增益是绿色 +N/+N，护盾是金罩。
- 112 张普通卡的归类：
  - 匹配：72 张，通用表现和能力意思一致；
  - 太泛：15 张，只有数字或标签，看不出发生了什么；
  - 无表现：14 张，其中 11 张本来就只有备战效果；
  - 表现错误：11 张。
- 将军方面，13 个里只有阿尔吉昂、泽里克斯、汉克的所有标签都有专属表现。
- 触发提示只显示「亡语」「被动」这类通用标签，不显示能力本身。10 种触发类型是白色，没有颜色区分。

## 原则

1. **先修「看错」，再补「看不懂」，最后做「好看」。** 表现错误会误导决策，必须先修。
2. **一个动词一种形状，颜色跟阵营。** 形状说明发生了什么（伤害、削弱、授予、召唤），颜色说明是谁干的。玩家学一次就能读懂所有单位。
3. **因果要连线。** 凡是「A 让 B 怎么样」，都从 A 画到 B。现在召唤、传令、献祭、主母这几类都缺这条线。
4. **专属特效只给有辨识度的卡**，主要是 4–6 阶和流派核心。1–3 阶靠第 2 层的统一做法就够读。
5. 限制条件：
   - 常驻状态只用 transform/opacity；
   - 一次性特效控制在 600ms 以内，2× 速度下自动减半；
   - 手机上一次性粒子数 ≤ 24。

## 第 1 层：修表现错误（11 卡 + 1 将 + 1 敌）

| 问题 | 涉及 | 方案 |
|---|---|---|
| 削弱显示成绿色「+-N/+0」 | 灯笼狐、暗隙猎手、四风术士、咒沙者、蕾娃 | 新增 `debuff` 表现：暗红或紫色的下坠箭头，目标身上向下掉碎片，文字写「攻 -N」（红色）。弹道用阵营色的细线，不用绿球。 |
| 破甲显示成绿色 | 碎石兵 | 同上，护甲图标裂开，文字写「甲 -N」。 |
| 授予词条显示成「+0/+0」 | 曙光执政官（复生）、墓园守卫（复生）、献祭术士（法强）、永夜吟诵者（法强）、岚影宗主（对决）、炎鬃战兽（溅射）、棘背兽（荆棘） | 新增 `grant` 表现：源单位射出一枚该词条的像素图标或彩色「」短词（遵守二选一规则），落到目标头顶后停留 400ms，再缩进单位的词条栏，同时词条栏闪一下。 |
| 护甲增加只有图标 | 晨光盾卫、冰原巨犀 | 用 `grant` 的护甲图标版，文字写「甲 +N」。 |

引擎侧：`buff` 事件 atk/hp 都为 0 但 armor 或 kw 有变化时，播放层改走 grant；atk<0 时改走 debuff。需要在事件里带上 `kw` 字段（现在只同步了状态，没有带出来）。

## 第 2 层：通用动词统一（覆盖全部 1–3 阶）

| 动词 | 现在 | 改为 |
|---|---|---|
| 施法 | 所有阵营都是同一个紫色法阵 | 法阵颜色跟阵营（圣光金、影刃红、深渊紫、熔岩橙、寒冰青、沙域土黄、中立灰白），图案保持一样。 |
| 能力伤害弹道 | 红球 | 按元素分 4 种形状：<br>· 物理：短刃，旋转飞行；<br>· 暗影：拖尾的魂火；<br>· 火：火球加拖烟；<br>· 冰：冰锥。<br>单位只需要配一个元素字段，默认按阵营取。 |
| 冻结 vs 寒冷 | 只是数字大小不同 | 冻结额外让目标整体罩上冰壳（opacity 覆盖层），加「冻结」字样；寒冷保持现在的表现。 |
| 召唤 | 召唤圈只出现在出生点 | 从召唤者（ev.src）先飞一道阵营色光点到出生点，再开召唤圈。 |
| 获得行动 | 只有「行动 +N」的提示 | 目标脚下出现一个顺时针转一圈的箭头环，加「行动 +1」。传令使要从自己连线到目标。 |
| 触发标签 | 「亡语」「被动」 | 改成「单位名 · 能力关键词」，例如「誓约骑将 · 护盾被击破」。10 个白色触发类型补上颜色：亡语紫、节拍粉、成为队首浅蓝、在队尾浅蓝、召唤土黄、冻结青、蓄力黄、回合开始白金、复生金、Boss 红。 |
| 静默加成 | 碎骨武僧、岚刃剑客的额外伤害并进了数字 | 伤害数字后面跟一个小号「+N」，用该单位的阵营色，让玩家知道多出来的这部分来自能力。 |
| 召唤物继承加成 | 孵化看守、金焰方尖碑、沙域法老只有绿球 | 加上源标签，例如「孵化看守 · 召唤加成」。 |
| 连击 | 第二次冲锋没有标识 | 第二下冲锋时加「连击」短标签，残影偏移一点。 |

## 第 3 层：常驻状态（只用 transform/opacity）

| 状态 | 方案 |
|---|---|
| 蓄力 | 单位脚下一排小格，满了就亮。最后一格亮起时单位轻微上下浮动，表示下次就会放。释放时先有 250ms 蓄势：身体后仰并发光，再出招。 |
| 节拍倒计时 | 头顶一个小数字牌（3→2→1），归零时爆开。幼兽蛋用裂纹贴图分 3 档。 |
| 复生（未触发） | 脚下一圈淡金色光环，触发后消失。 |
| 嘲讽 | 单位前方一面半透明盾形轮廓，轻微呼吸。 |
| 深渊主母光环 | 所有带亡语的友军身上叠一个紫色小标记；亡语触发两次时，第二次标签写「主母 · 再次」。 |

## 第 4 层：专属特效（21 张卡 + 将军补全）

每个都按卡的实际逻辑来设计，只描述一次性表现。

### 圣光
| 卡 | 逻辑 | 专属表现 |
|---|---|---|
| 曙光执政官 | 开战时给友军复生，给前 3 名护盾 | 头顶降下一道金光，按顺序依次扫过友军，复生光环和护盾一个接一个点亮。 |
| 圣铸机兵 | 友军轮转后，新队首加攻/血 | 机兵胸口亮起，一条金色传动带一样的光线推到新队首，队首脚下出现齿轮形状的光环。 |
| 誓约骑将 | 友军护盾被击破时，该友军加攻/血 | 护盾碎片没有散开，而是被吸回该友军，化成攻击图标。 |
| 铁崖守护者 | 被普攻时自己加护盾，有上限 | 护盾层数用叠加的盾形轮廓显示，到上限时轮廓变实心。 |

### 影刃
| 卡 | 逻辑 | 专属表现 |
|---|---|---|
| 千刃宗师 | 累计 6 次攻击后，千刃齐发打全体 | 平时头顶显示 0/6 刀痕计数。触发时屏幕从左到右扫过 6 道刀光，所有敌人同时受击，红色闪屏只闪一次。 |
| 岚影宗主 | 开战时授予对决；友军击败对手时令其追击 | 授予时一道红色丝线连到目标；追击时丝线一拉，目标被拽着冲出去。 |
| 影舞者 | 施法令攻击最高的友军追击 | 影舞者化成影子，贴到目标背后，再和目标一起冲锋（残影叠加）。 |
| 熊猫武尊 | 击败对手时全体友军加攻/血 | 落地一记震地波纹，从熊猫向两侧推开，经过谁就给谁加数值。 |
| 连环忍者 | 击杀时获得行动 | 击杀后单位身上的残影绕一圈，「行动 +1」。 |

### 深渊

|---|---|---|

## 建议排期

| 批次 | 内容 | 预估 |
|---|---|---|
| A | 第 1 层（debuff、grant）+ 触发标签改名和补色 | 小，主要改 playback.ts，引擎补 kw 字段 |
| B | 第 2 层（阵营色法阵、元素弹道、冻结冰壳、召唤连线、行动环、静默加成、连击） | 中，主要改 fx.ts，加元素字段 |
| C | 第 3 层常驻状态（蓄力格、节拍牌、复生环、嘲讽盾、主母光环） | 中，改 board.ts，常驻部分只动 transform/opacity |
| D | 第 4 层专属（21 卡）+ 将军补全 | 大，可以按阵营分批 |

A 不改变玩法，只是让画面不再误导，建议立刻做。B 和 C 做完以后，所有卡至少都能读懂。D 可以按上线前的优先级再挑。
