# UI 交互审查（v0.12.1，基于 output/ui-current-20261023 的 48 张截图）

优先级：P0 = 影响上手或手机可用性；P1 = 明显别扭，容易误操作；P2 = 打磨。
括号里是截图编号。

## P0

1. **手机上字太小，两侧有黑边**（29/31/37/45/47/48）
   - 舞台固定 1280×720，整体等比缩放。844×390 时缩放约 0.54，设计稿 18px 的字实际只有约 10px；568×320 只有约 8px。
   - 左右各有约 75px 黑边，没有利用起来。
   - 高度是瓶颈，只把舞台加宽不会放大字。
   - 建议：短屏（高 ≤ 450）用紧凑布局，逻辑高度从 720 降到约 600，缩放提到 0.65（+20%）。具体做法：
     - 顶部路线条变窄；
     - 战斗日志面板从约 130px 压到约 70px；
     - 「开战 / 换防 / 整备」这一列和「刷新 / 下一页」挪到原来黑边的位置。
   - 单位数值、词条牌这类核心数字，紧凑布局下另外再放大一档。

2. **引导框挡住操作目标**（13/15）
   - 13 号「拖到左侧格位」的提示框正好压在我方 1–2 号格上，也就是要拖进去的位置。
   - 15 号的说明框盖住了我方 2–5 号格和刚放下的单位。
   - 建议：提示框贴着目标的反方向放（目标在左，框就放上方或右侧），并给目标加一圈脉冲高亮。15 号那段 5 行文字拆成两步。

3. **只能拖，不能点**（14）
   - 招募只能拖拽，详情弹层里只有「锁定商品」。
   - 建议：详情里加一个「招募」主按钮，点了就放进第一个空战位，没有空战位就放备战席。「锁定」降为次按钮。
   - 商店那边已经有「购买」按钮，两边交互也能统一。

4. **整备界面没有说明，敌人看不清**（16/23/24/30）
   - 资源只是左下角的小图标，没有一句「把资源拖 / 点到单位上」。
   - 16 号没有资源时整屏是空的，没有空态提示（比如「战斗胜利获得培养点」）。
   - 右上角的敌方预览只有约 30px，数值读不出。
   - 右侧 3 个「备战」格就在敌方站位上，和备战界面的布局对不上。
   - 建议：
     - 底部加一条资源托盘，每个图标下面写数量和效果，比如「攻击 +1」；
     - 选中资源后，提示从屏幕顶部（24 号 y=17 那行小字）移到托盘上方；
     - 敌方预览放大到和备战时同等尺寸，或者干脆去掉；
     - 备战席的位置和备战界面保持一致。

## P1

5. **按钮列位置会跳**（15→17）：「开战」在 2 个按钮和 3 个按钮的状态之间上下移动约 70px，容易点错。建议这一列固定 4 个槽位，状态变化只换内容。
6. **主将指定目标没有引导**（17）：「选择战位友军」是个长得像按钮的说明，可选的友军没有高亮。建议：可选单位加脉冲描边，其余单位压暗，说明放到舞台中线上方。
7. **选中卡时全场压暗过头**（26/27）：敌方单位和「狙击」词条也被压到看不清，正好是做决定时最需要看的信息。建议只压暗我方不相关的单位，敌方保持原样。
8. **战斗横幅挡住敌方特性**（20/28/32）：「交锋」大横幅长期停在顶部，把关卡特性那行（如 32 号「每次交锋结束受伤…」）遮住了。建议横幅 1 秒后缩成一枚小标签，或者整体下移，不要盖住特性条。
9. **战斗日志面板占地大、利用率低**（20/28/32）：大部分时间只有「交锋」两个字，却占了约 130px 高。建议压成一行「回合 / 交锋」加最近一条日志，空出来的高度给单位放大。
10. **商店卡面文字溢出**（33–41）：流沙方尖碑的「升星」压在稀有度点上。需要检查卡面文字区，第 3 行词条时要缩小或截断。
11. **商店购买没有去向反馈**（35/40）：
    - 买了培养包没有飞入整备的动画，也没有提示；
    - 买的单位进了备战席，但战位 4 是空的（40），不显眼。
    - 建议：商品飞向目标格；有空战位时优先放进战位，或者高亮那个空位。
12. **「新的游戏」和「继续游戏」一样醒目**（47）：两个都是金色主按钮。有存档时「新的游戏」应降为次按钮，点击后先确认会覆盖存档（需要确认当前是否已有二次确认）。
13. **战术选择太单薄**（43）：灰色平板卡片，没有图标和边框，和整体像素风格脱节；点一下就生效，误触无法挽回。建议沿用岔路卡的边框，加图标，并且选中后要按「确定」。
14. **「将军能力每场开战自动生效」与实际不符**（12）：齐兰要在备战时指定目标，蕾娃要在布阵界面手动换位。建议改成「将军能力会在每场战斗中生效」，或者删掉这行副标题。

## P2

15. 主菜单（01）：「新手教程」是绿色高亮，比主按钮「新的游戏」还抢眼。首次进入可以高亮教程，教程完成后改回普通样式。
16. 玩法说明 / 词条（02/03）：卡片底部文字被截断（「额外行动」那段），需要能滚动或给出渐隐提示。12 页偏长，可以把重要的放前面。
17. 战绩（09）：排行榜四项全是「待开通」，还出现了不在当前主将池里的「阿尔吉昂胜率」。建议在排行榜开通前隐藏这个页签，只保留成就。
18. 设置（11）：「重置提示」含义不清，建议改为「重新显示新手提示」；它紧挨着「清除全部数据」，两者应该拉开距离。
19. 图鉴（04–08）：搜索框占了约 64px 高，可以缩到页签行。单位详情的标签（前排 / 轮换 / 给格挡）是灰色文字，能力描述里却是彩色「」，标签可以去掉或者统一。
20. 岔路（44）：敌方特性描述写的是「开战」，统一成「开战时」。
21. 「x/5」人口计数压在敌方 5 号格附近（17/29/48）。在 844 宽度下，开战按钮列和敌方 5 号单位贴得很近，建议把计数挪进按钮列顶部。
22. 复盘（22）的备战席在左下，备战界面的在右下，位置统一一下。
