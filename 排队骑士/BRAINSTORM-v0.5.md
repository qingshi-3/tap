# 排队骑士 v0.5 发散：词条 / 装备 / 遗物 / 岔路 / 事件（未收敛，仅供挑选）

## 0. 为什么 PvE 可以放开
- 非对称：敌人可以有玩家没有的规则，玩家也可以拿到「破格」的东西，不需要对称公平。
- 兜底已经有了：Boss 底线 40% + 温度系统。单个系统强一点不会把整局打崩。
- 收敛时用的筛选标准（现在先不卡）：
  1. 和 ≥3 个引擎产生不同化学反应（主将原则）；
  2. 一个 icon 能表达（UI 少字）；
  3. 不做「留给特定单位消费」的资源；
  4. 补短板，不逼重组。

## 1. 核心想法：一套「战斗词条原子库」，装备 / 遗物 / 敌人词缀共用
先做原子，再决定挂在哪。同一个「吸血」，可以是装备、遗物的效果，也可以是精英敌人的词缀，玩家只需要学一次。

| 词条 | 效果（初拟） | 参考 | 和引擎的化学反应 |
|---|---|---|---|
| 斩杀 | 对半血以下敌人伤害 ×1.5 | LoL 收集者、Hades | 开战流先削血、受伤流反伤 chip，把敌人打进斩杀线 |
| 暴击 | 每第 3 次攻击伤害 ×2 | 各类 ARPG | 通用，配连击 |
| 吸血 | 造成伤害的 30% 回血 | LoL 饮血剑 | 受伤流：回血 = 多挨几下 = 多触发 |
| 不屈 | 首次致命伤锁 1 血，再坚持 2 次交锋才倒 | 烈娜塔、守护天使 | 受伤流多挨打；亡语流反协同（亡语被推迟），是取舍 |
| 收割 | 击杀回复 25% 最大血 | LoL、Hades | 前排滚雪球；对召唤海特别强 |
| 穿透 | 溢出伤害打下一个敌人 | 炉石酒馆超杀 | 打召唤海、配斩杀 |
| 护盾 | 开战获得 = 20% 最大血的护盾 | TFT 钢铁烈阳 | 和格挡互补（格挡挡次数，护盾挡数值） |
| 冲锋 | 首次交锋伤害 ×2 | 各类 | 速攻、开战流 |
| 连击 | 攻击 2 次，每次 60% | 各类 | 配暴击、配受伤流的敌人（让对面多触发也是风险） |
| 灼烧 | 被打的敌人每次交锋扣 2 血（叠层） | 杀戮尖塔中毒 | 对格挡墙、养成大哥 |
| 冰冻 | 被打的敌人下次交锋攻击 −50% | 各类 | 前排生存 |
| 战意 | 每次交锋后本场 +1 攻 | 各类 | 拖长期战、配不屈 / 吸血 |
| 回响 | 亡语 / 开战效果触发 2 次 | 炉石瑞文戴尔 | 已有身前额外释放（曙光执政官），可做成通用版 |

风险：吸血、不屈、收割在一条队伍逐个交锋的结构里非常强，前排可能永远不倒。必须封顶（每场次数 / 百分比上限），并接入校准。

## 1.1 强度控制原则（用户认同 2026-10-25）
逐个交锋 = 无脑对撞，任何「随攻击力线性放大的自我续航 / 自我成长」都会变成标准答案（大哥打 50 回 50）。规则：
- **不按攻击力比例结算续航**：回血用固定值或按最大血百分比，且挂在条件上（击杀、每场 N 次）。
- **每场次数上限**：自保类（吸血、不屈、收割、护盾刷新）都写死次数。
- **收益递减 / 不叠加**：同名词条不叠加，或第二层减半。
- **给对面留解法**：敌方形态里有克制它的（灼烧破续航、狙击队绕过前排、斩杀打残血）。

| 词条 | 失控方式 | 限制方向（候选） |
|---|---|---|
| 吸血 | 大哥打 50 回 50 | 改「击杀回血」；或每场 3 次、每次固定回 X；或只回本次伤害的 30% 且上限 = 最大血 20% |
| 不屈 | 前排拖死全场 | 每场 1 次，坚持 2 次交锋后必倒，期间不吃回血 |
| 收割 | 召唤海里无限回血 | 每场 3 次；回最大血 25% |
| 战意 | 长期战无上限 | 上限 +5 攻 |
| 穿透 | 一刀清场 | 只溢出到下一个，最多 1 次 |
| 回响 / 暴击 | 与高攻叠乘 | 不和同类叠；暴击固定 ×2、不能被放大 |
- 所有这些接入 calib：单个词条挂在任意引擎中档上，通关率提升不超过约 10 点；超过就砍。

## 2. 装备（从轻到重）
- **A. 补给附魔扩展（最轻，推荐首选）**：现在补给本来就能给永久附魔（SAP 式），把附魔池扩到 15 个左右，大部分用上面的词条。不加新界面。
- **B. 独立装备货架**：每 3 回合或 Boss 后出 3 选 1；一个单位一个装备槽；卖单位时装备退回包里；升星保留。
- **C. 诅咒装备**：强力带代价，比如「+5 攻，但开战自伤 3」。正好喂受伤流，对别的引擎是真代价，天然跨引擎。
- **D. 掠夺**：打赢精英，拿走它身上的装备（敌人带装备出场，玩家看得见、想抢）。和精英词缀共用一套。
- **E. TFT 散件合成**：深度最高，但手机上理解成本高，不建议首版做。

### 2.1 品质 + 开箱（用户提出 2026-10-25）
**品质分 4 档**，颜色走单位光效（不用外框圈），开箱时按品质给光柱和音效：

| 品质 | 定位 | 例子 |
|---|---|---|
| 普通（白） | 纯数值 | +3 攻；+5 血 |
| 精良（蓝） | 单个词条，带上限 | 击杀回血 25%（每场 3 次）；斩杀；护盾 |
| 史诗（紫） | 词条 + 联动 | 受伤时 +2 攻并反伤 2；亡语时把装备传给身后友军 |
| 传说（橙） | **出格，改写规则** | 见下 |

**传说装备：允许打破 §1.1 的常规上限，换来「这局爽了」的峰值**
- 冥魂王冠：亡语额外触发 1 次；攻击时也触发一次自己的亡语（每场 3 次）。
- 贯日之枪：攻击穿透全部敌人（每个敌人都吃满伤害）。
- 不灭圣杯：不屈每场 2 次，坚持期间仍能攻击、能触发受伤。
- 镜像戒指：开战时复制自己一个 1 血分身（带装备效果，不带戒指）。
- 风暴之心：每次交锋后，对所有敌人造成 1 伤害（喂所有「受伤时」）。
- 群星王冠：全队共享这个单位的词条。
- 收敛方式：不是削弱，而是**限获得**：每局最多 1 件传说；传说只出现在 Boss 宝箱或保底触发。破格本身就是奖励。

**获取 = 开箱环节**
- 来源：Boss 宝箱（必出紫以上，可能出橙）、精英掉落、事件、击杀计数器（累计击杀 N 个敌人开一个箱）。
- 形式两种候选：
  1. **翻 3 选 1**：一次翻开 3 件（各自抽品质），玩家选 1。有惊喜，也有选择，**推荐**。
  2. **转盘 / 抽一件**：纯运气，惊喜最强，但抽到没用的会挫败。
- **保底**：连续 N 次没出紫，下一次必紫；整局没出橙，最后一个 Boss 箱橙概率翻倍。
- **温度联动**：温度高（输得多）时品质概率上调一档；顺风时不调，避免越滚越大。

**装备规则**
- 一个单位 1 个装备槽；可以拖到别的单位上换装（白给自由度，避免装错就废）；卖单位时装备退回背包。
- 升星保留装备；合星时取品质最高的那件，另一件退回背包。
- 敌人精英也可以带同一套装备（配合 D 掠夺：看到敌人身上的橙装，想抢）。

**风险**
- 传说装备在 calib 里单独看：挂在任意引擎中档上，通关率提升 15–25 点可以接受（它就是峰值），但必须**不改变** 40% Boss 底线以外的东西；不进温度的「正常难度」计算。
- 开箱节奏：一局开箱 4–6 次为宜，太多就不惊喜了。

## 3. 遗物（全队被动，Boss / 精英奖励，每局 3–4 个）
### 改写通用动作类
- 受伤：全队第一次受伤获得 1 层格挡；全队累计受伤 5 次，全队本场 +1 攻。
- 阵亡：友军阵亡时，新队首获得它一半的攻击（传承）。
- 补给：每回合第一份补给同时作用于相邻单位。
- 开战：开战时随机敌人受到 = 我方人数的伤害。
- 交锋：每第 3 次交锋，队首暴击。

### 规则改写类（Balatro 小丑牌的味道，最有记忆点）
- 「独行」：队伍只剩 1 人时，它 +10/+10 并获得不屈。
- 「少即是多」：上场 ≤3 人时全员 +3/+3。
- 「后卫反击」：队尾每次交锋也打敌方队尾 2（后排也能动手，非对称专属）。
- 「重装」：队首血量 ×1.5，其余单位攻击 −1。
- 「车轮战」：每个友军阵亡，下一个上场的友军首次攻击 ×2。

### Boss 遗物（杀戮尖塔式，带代价）
- 货架 +1 格，但刷新 +1 金。
- 全队 +2/+2，但最大心数 −2。
- 每场开战全队获得护盾，但补给货架只剩 1 格。

## 4. 岔路
- **敌阵预览二选一（推荐，成本最低）**：每 2–3 场，给两个敌阵预览让玩家挑一个打。和形态系统天然契合，让「看懂形态 → 用阵容挑对手」变成有用的决策；也是温度系统的天然出口（暖时两个都偏好打）。
- **精英战**：带词缀的敌人；赢了拿遗物 / 装备 / 掠夺，输了扣 2 心。
- **简化路线图（杀戮尖塔式）**：普通 / 精英 / 商人（只卖装备补给）/ 营火（免费合星或回 1 心）/ 事件。比二选一重，但肉鸽感最强。

## 5. 事件（杀戮尖塔问号房 / Hades 混沌门）
- 赌徒：付 1 心，换一个随机 6 阶单位。
- 铁匠：一个单位升 1 星，但随机拿走另一个单位。
- 训练营：一个单位永久 +3/+3，或学会一个词条。
- 祭坛：献上一个 3 星单位，换一个遗物。
- 变形：一个单位变成同阶、同标签的另一张卡。
- 雇佣兵：免费借一个高阶单位，3 回合后离队。
- 双生：复制一个单位，但两个都降到 1 星。
- 混沌契约：接下来 3 场都是困难，之后拿一个遗物。
- 商队：本回合补给半价。

## 6. 敌人侧（非对称的真正红利）
- **精英词缀**（暗黑 / PoE）：狂暴、坚韧、分裂、吸血、护盾、召唤者……8 形态 × 词缀 = 多样性爆炸，制作成本低（复用原子库）。
- **Boss 阶段**：半血时变身或换技能。
- **敌人带装备**：配合掠夺。

## 7. 局外（仍不做数值养成）
- 图鉴、成就、每日挑战种子（固定生态 + 固定遗物池，大家打同一局）。不影响平衡。

## 我的倾向（只是倾向）
- 骨架：**词条原子库** → 首批挂在「补给附魔扩展 + 遗物 + 精英词缀」三处，复用最大。
- 岔路先做「敌阵预览二选一 + 精英」，路线图以后再说。
- 最有特色、值得试的：规则改写类遗物、诅咒装备、掠夺。
