# 排队骑士 · 设计稿 v0.1（已确认 · 原型已出：排队骑士.html）

> 一队互相起反应的小兵越滚越强，排着队把对面碾过去。

和奇兵列阵是两个项目：奇兵列阵不改，排队骑士从零写规则，美术和界面框架复用。

---

## 1. 碰撞规则（整个战斗就这几条）

1. 双方各排一列，**队首对队首**。
2. **交锋**：两个队首同时打对方，伤害 = 自己的攻击。双方都死就一起移除。
3. 队首阵亡后，后面的单位自动**上前**，成为新队首。
4. 后排不攻击，只通过**事件技能**参与。共 7 个事件：开战、交锋、受伤、阵亡、上前、退后、召唤。
5. 一方清空就判负。双方同时清空，或交锋满 30 次，算**平局**。
6. 结算顺序：
   - 开战技能：我方 1 号、敌方 1 号、我方 2 号……交替结算；
   - 同一事件触发多个技能时，按队列从前往后结算。

### 招牌机制：轮换

- 带「轮换」的单位交锋后如果还活着，就**退到队尾**，身后的友军**上前**。
- 这一次换位会同时产生两个事件：
  - 退后：被换下来的单位；
  - 上前：接替它的单位。
- 前排的血就这样摊给全队，「上前时」「退后时」类技能也能反复触发。
- 只有轮换会让单位离开队首。阵亡、召唤、技能都不会。

### 唯一的防御资源：格挡

- 1 层格挡完整挡住 1 次伤害，然后消失，可以叠层。
- 只由自己或广播型技能给出，不做「留给特定单位消费」的资源。

## 2. 经济（沿用奇兵列阵 SAP 版）

| 项 | 数值 |
|---|---|
| 每轮金币 | 10，不结转 |
| 买卡 / 刷新 / 出售 | 3 / 1 / +1（每星多 +1） |
| 队列上限 | 5 格，**没有备战席** |
| 货架 | 按备战次数（输了重打也算一次）：第 1–2 次 3 张；第 3–5 次 4 张；第 6 次起 5 张。阶层同理：第 3 次开 2 阶，第 5 次开 3 阶 |
| 阶层解锁 | 1 阶从第 1 轮开始；2 阶第 3 轮；3 阶第 5 轮 |
| 升星 | 同名卡拖到场上的同名单位上合并，3 份升 ★2、6 份升 ★3；每合并 1 份 +1/+1 |
| 升星奖励 | 升到 ★2 或 ★3 时，**立刻**在货架末尾出现 1 张高一阶的免费卡 |
| 锁定 | 可以锁定货架上的卡留到下一轮 |

技能数值写作 `[★1, ★2, ★3]`。

### 预期能成型的几套

- **轮换车轮**：银盾/守誓 + 换位术士 + 风刃学徒 + 圣铸机兵 + 战地医师。前排轮流挨打，每次换位都在滚雪球。
- **送死流**：残魂小鬼 + 墓园守卫 + 灵魂收割者 + 唤亡祭师 + 孵化看守。死得越多，队伍越长、越强。
- **站位流**：铁甲卫士在最前，身后放飞镖手、影舞者、原始萨满。一个肉盾，后面一串输出。
- **混搭**：背刺者、战阵指挥官对上前、阵亡、召唤都有反应，能把两条线粘在一起。

## 4. 全局生命与路线

- **3 条命**。只有打输扣命，单位阵亡不扣；平局不扣。
- 原型是**线性 10 场**，敌方阵容都是写死的：

| 场次 | 敌方 | 测什么 |
|---|---|---|
| 1–2 | 3 个 1 阶白板兵 | 学会交锋 |
| 3 | 1 个高血肉盾 + 2 个小兵 | 需要输出 |
| 4 | 5 个 1/1 | 需要溅射或耐打 |
| 5 | **小 Boss**：一个 8/12 | 需要轮换摊伤，或者送死流 |
| 6–7 | 混合阵容，有格挡 | 打出来的强度够不够 |
| 8 | 后排有飞镖手式输出 | 前排要扛得住 |
| 9 | 镜像流派：敌方也轮换 | 认识自己的机制 |
| 10 | **大 Boss**：前排 2 个格挡肉盾，后排一个成长核心 | 综合检验 |

- 10 场打完就通关。命用光，本局结束。
