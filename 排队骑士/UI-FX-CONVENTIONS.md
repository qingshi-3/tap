# 排队骑士 · 视觉/交互/特效约定（从奇兵列阵继承）

来源：奇兵列阵打磨期的反馈（会话 19faee33）。排队骑士默认全部遵守。
标注：**[复用]** 直接拷奇兵列阵代码改；**[简化]** 碰撞制下改小；**[暂缓]** 原型不做。

## 1. 硬约束

- **手机横屏优先**
  - 不靠悬停；
  - 舞台字号 ≥ 18；
  - 点击区 ≥ 44px；
  - 出售用拖动（拖到底部出售区）。
- **性能**
  - 常驻补间只动 transform/opacity；精灵逐帧切图例外：在固定窗口内按素材帧率切换背景位置，不改布局、不另起 JS 计时循环；
  - 教学轮询只在状态变化时改 DOM；
  - 一次性特效 ≤ 600ms，2 倍速下减半；
  - 一次的粒子数 ≤ 24。
- **少字**
  - 词条只放标识，解释统一放「玩法说明 → 词条」页；
  - 补给传承通用规则只在图鉴规则页解释；单位详情只列自身记录数量、补给和实际出售预览，商店/图鉴静态卡不显示空记录；
  - 文案短、具体，不写抽象长句。
- **词条二选一**：能表意的做像素 icon，不能表意的用彩色「」短词，两种不并用。数值标签统一用像素牌。
- **正面数值**（格挡等）居中显示在单位脚下。

## 2. 单位与阶层 [复用]

- 立绘用 duelyst 单位帧图，按 defId 和奇兵列阵同名单位共用（`unitArt.ts` + `duelyst-units.css`）。
- idle 使用单一固定窗口，选中只换描边图、不重启时间轴；不额外叠加整身 bob。`idle-anchors.css` 仅抵消经过逐帧配准确认的8种整幅竖向位移，保留局部动作；新增素材不得按包围盒统一强行对齐。
- 阶层靠**单位光效和颜色**区分，不用外框圈：
  - 用由下往上的光点；不用旋转光环；
  - 各阶层要一眼分得清；
  - 除场上战斗单位外，凡是出现单位立绘的地方都加光效；
  - 阶层图标要有美术设计，不要生硬的徽章。
- 机制词条要有像炉石那样有质感的装饰特效，不用线框嘲讽框，也不用丑的黄盾：
  - 格挡：叠起来的半透明盾片；
  - 复生：脚下一圈淡金色光环；
  - 轮换：脚下一个循环箭头；
  - 溅射：身后有火星。
- 星级进度条放在单位头顶，要有清楚的边框。

## 3. 商店 [复用 SAP 经济代码]

- 货架 3 张起，不翻页（3→5 张逐步加）。
- 买卡时不播刷新特效。
- 总金币放左下；按钮上方不再标每张卡的价格。
- 广告刷新按钮写「广告刷新」，字要放得进框。
- 锁定或解锁卡时，关闭单位详情弹窗。
- 备战界面：
  - 我方单位大、在左；敌方预览小、在右；
  - 能升星受益的单位要高亮，样式和教学圈区分开。

## 4. 战斗表现 [简化]

- 布局：两列相对，横着排，队首在中线两侧。交锋就是两个队首对撞。
- 中线显示交锋数，大数字写当前次数（以前的 m/n 可以去掉）。
- 攻击和受击接帧图动画。普攻和施法要区分：施法 = 自定义光效 + 帧动作。
- 保留：
  - 追击用的残影（这里用在轮换的位移上）；
  - 目标指示线的发光；
  - 动态准星（不用斧头图标）。
- 因果要连线：凡是「A 让 B 怎么样」，都从 A 画到 B（飞镖手→敌方队首、医师→退后者、指挥官→队首）。
- 一个动词一种形状，颜色跟阵营。削弱用红色并往下掉，授予用图标落下。
- 触发标签写「单位名 · 能力」，比如「圣铸机兵 · 友军上前」，不写通用的「被动」。
- 飘字：
  - 不加框，要活泼不要死板；
  - 失败、金币不够用红叉，不用绿色。

## 5. 教学与图鉴 [复用，暂缓到核心可玩之后]

- 讲解词条时圈出触发它的单位或元素（包括结果框），镜头推近并平移过去：
  - 按画面自适应缩放，不要推得太近，画面要完整；
  - 不在屏幕中央弹气泡。
- 图鉴里的演示是用代码配置的实时小战斗，和正式战斗共用数据：
  - 底部常驻说明文字；
  - 关键时刻慢放、暂停、框出单位，配一个小气泡（如「上前时」），然后继续。
- 图鉴：
  - 复用游戏内的卡面；
  - 战斗内和主菜单两个入口统一；
  - 传说卡的玻璃效果不被裁掉；
  - 阶层标不重复显示。
- 卡面上的词条排版不能歪；有空间就把卡面放大。
- 跳过教学的按钮做小，放左上角，离操作热区远。

## 6. 产品体验 [复用]

- 教学结束后、第一局结束后各弹一次反馈。
- 反馈按钮显示 QQ 群（群号待定，占位写 `QQ_GROUP_TBD`）。
- 设置里放「清除本地数据重开」，存档出 bug 也不会卡死。
- 进入备战时，关掉所有弹窗。

## 7. 复用计划（省资源）

| 模块 | 做法 |
|---|---|
| 工程 | 拷奇兵列阵的 `vite.config.ts`、`package.json`、单文件打包脚本；产物是单文件 HTML，双击就能玩 |
| 美术 | `unitArt.ts`、`duelyst-units.css`、像素字体、`pixel.css`、阶层光效 CSS（`card-tiers.css` 里光点那部分），只拷要用到的单位图 |
| 界面 | `dom.ts`、`tip.ts`、`kwtext.ts`、`icons.ts`、`audio.ts`、卡面 `card.ts`（删掉装备和修炼的字段） |
| 商店 | 照搬 run.ts 里 SAP 经济部分（货架、刷新、锁定、合并升星、升星奖励），去掉备战席和装备 |
| 战斗 | **重写**引擎（碰撞制规则简单得多，大约 300 行），事件格式尽量对齐奇兵列阵，方便复用 `playback.ts`、`fx.ts` 的表现函数 |
| 存档 | 参考 run.ts 的版本号和校验做法；新 key，和奇兵列阵存档互不影响 |
| 暂缓 | 教学镜头、图鉴演示、将军特效、Boss 规则界面，等核心好玩了再拷 |

原型的验收只看一件事：打 10 场，能不能感觉到「我这队越滚越强」。
