# 排队骑士 · 逐单位价值审计

状态：已完成本次离线规则与价值实验；未改玩法、数值、存档、幽灵库或既有界面。

覆盖 60/60 单位；637 条行为契约，其中 1 条失败；配对比较 12,002,304 场模拟；固定面板升星/副本 181,248 场；生命周期 74,592 场；随机状态 10,000 组；正常局辅助 4500 局（含消融 316,077 场）。



## 审查结论

**60张牌都已逐项审查。多数能解释清楚为什么值得占位；优先风险集中在召唤容量、重复不叠加、星级收益停档和通用成长挤压，而不是卡牌数量不足。**

本轮记录 12,878,909 场离线战斗调用，包含同身材消融、同阶共同壳替换、固定面板升星、第二副本、生命周期、随机不变量与 4500 条自然商店轨迹（1条在20回合上限截停）。重复固定随机流不等于同数量独立样本，也不代表人类游玩时长。

行为检查 637 条，失败 1 条，涉及 黑沙巨虫；随机不变量 10000 组、失败 0 条，实抽覆盖 60/60 单位、180/180 单位星级组合。失败没有通过修改玩法或降低断言来消除。

### 优先处理的设计问题

1. **霜冠执政官的强度优先复核**：通用受控环境中原生能力平均边际 +40.8个百分点，共同壳相对岚影宗主 +24.3个百分点。这是很强的即时战斗信号，应优先用更接近实战的获取与阵容测试核验；不是把未计入成长的经济牌直接排在其后。
2. **白鬃猎龙、熔岩巨蜥、驮岩兽、熔岩巨像的容量门槛**：技能正确执行与流派好用是两回事。开战召唤满编失效；非致命受伤召唤还要有空位；巨像死亡常只能召一块。少带正式单位的代价必须由实战收益补偿。
3. **重复与升星不总是线性收益**：方尖碑首张耗尽余金，法老取最高，宗主取最高，执政官最多额外结算2次；执政官1→2星没有技能增益。报告单列第二副本和固定面板升星，避免把复制身材误认成技能升级。
4. **经济牌必须按生命周期衡量**：16张牌走同状态、有/无能力轨迹，比较属性、bank、收入、支出和最终战斗。沙丘额外钱未自动购买战力，方尖碑支出是机会成本；“支出差0”绝不表示买牌、刷新和补给免费。
5. **黑沙巨虫的舍入契约**：一星本体7/7、50%向4名友军平分时，当前实际总发4/4，超过3.5/3.5的百分比预算。至少应明确这是保底赠送还是平分；报告保留失败，不擅自改数值。
6. **熔血巫兽的生命语义**：当前按施法者当前hp取比例，受伤会降低新召唤物生命。该行为已记录，但卡面“自己攻血”不够明确，需决定意图后再把它判为bug或正常取舍。

### 证据边界

- 纯战斗比较剥离历史商店成长；高星和固定加成是受控情境，非正常获取保证。自然局另行采样，但bot不识别全部连锁，因此不把出场率或通关槽位当强度因果证据。
- 跨环境共用固定种子，n是配对次数，不是独立样本量。未制造独立置信区间或用显著性包装微小分差。
- “触发次数/失败次数”辅助统计只覆盖开战初始实例，复生新UID的后继不计入；完整战斗胜负和消融包含所有复生、召唤和连锁。
- 相同攻血预算不等于相同机制强度；敌方8种机制等权是实验选择。同阶对比每一对共享条件，不同对不能串成全局排行榜。
- 这轮验证离线规则与策略作用，没有证明人类觉得好玩，也没有替代逐单位视觉/输入验收。

## 如何阅读

“边际”是同身材同队伍中，保留/移除该单位原生技能与关键词的配对胜平积分差（胜1、平0.5、负0），不是单位单独胜率。商店成长牌的历史收益不在当场消融中，必须连同成长测量一起看。

## 生命周期方法

- 默认16个受控种子；每条row的n为种子样本数，所有Delta均为样本均值。
- 高星与初始Owned、金币、位置由脚本控制；每轮金币重置为10，不跨回合累加，轨迹用于归因而非模拟正常淘汰流程。
- 空能力对照临时替换CARD[id]为同面板、无ab/kws/v/u克隆；每次在finally恢复，不修改CARDS或SHOP_POOL。
- 回合结束能力走endTurn；回合开始、战斗永久写回走settleBattle(draw)；控制轨迹固定turn=3以进入固定wall Boss，不读取幽灵对手。
- 最终价值使用8组固定无技能敌阵；同一固定种子分别把待测阵容放左右两侧，以simulate纯函数计win=1/draw=0.5/lose=0。
- 额外金币不自动购买战力；goldEarned与goldSpent独立记录。金焰方尖碑的余金消耗与属性收益同列，支出表示机会成本。
- statGainDelta只计最终Owned面板攻血；bankDelta单列。scoreDelta捕获蛋孵化、附魔/战斗能力及永久成长带来的最终战斗差异。
- 出售型单位持有到末轮并只出售一次；购买价作为沉没成本写入notes，不伪造每轮重生或把毛返还当净收益。

升星对比固定同一面板，只变技能等级，不计额外2/3份复制的身材；经济收益看商店测量。第二张对比固定双张面板，清空第二张技能作对照，并扫描所有其余位。使用独立种子与候选有利壳，非全局最优。

## 复跑与复核

`cd 排队骑士/source` 后执行 `npm run audit:units`。快速检查可加 `-- --seeds=1 --limit=1 --games=10`，快速结果不代替全量验收。

详细行为观测在 `source/output/value-audit/contracts.json`；情境与同阶替换全部汇总在 `comparison.json`；每单位自然局证据、源码SHA256、参数在 `results.json`。固定种子保证同代码可复跑，不代表样本独立或统计置信区间。

- 环境等权是实验选择，不代表真实对手分布。
- 同种子在触发次数不同后随机抽样可能分叉；它降低噪声但不是逐次随机命中的精确反事实。
- 按卡阶限制支持单位；支持位在可用池中循环，满编与四人壳分别记录。
- 成型高星与固定成长是受控上限，不代表自然商店可获得。
- 同阶替换测整卡即时战斗性价比，不包含此前/未来经济作用；不能用该局部结果宣称全局严格压制。
- margin仅用于胜负不变时的剩余生命辅助信号，不计格挡与未兑现成长。

边界：本轮是离线机制/策略价值审计；未进行玩家盲测、留存测试或逐单位视觉/操作验收，不能据此宣称真实玩家觉得好玩。没有修改玩法来消除测试发现。
