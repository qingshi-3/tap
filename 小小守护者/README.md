# 小小守护者

普通手机横屏 H5 营地塔防，在 TapTap App 内运行。玩家在无倒计时的准备阶段部署军团、建造、修理、晋升、选择并指派效果；开战后自动战斗，只能使用已购买的次数制法术。敌人比较绕路与摧毁工事的成本，七波结束结算。

准备阶段从招募栏或商店拖出军团、建筑，拖动时显示真实对象与蓝色半透明警戒/作用范围，合法松手落位；已有军团与建筑可直接拖动重新摆放。取消、障碍格、占用格和HUD区域不会购买或移动。建筑移动保留已有损伤。战中治疗与全场定身仍需明确施放，不使用冷却次数替代库存。

## 存档与回放契约

本机检查点固定存储于 `little-guardians-h5.run.v1`，档案于 `little-guardians-h5.profile.v1`，与其他游戏隔离。准备阶段每次合法操作保存；战斗保留开战前检查点，重进可重新挑战本波；波结束与胜负保存。不会承诺战斗任意时刻断点续战。

当前只支持封套version1、schemaVersion1、匹配rulesVersion的完整合法存档。未知版本、损坏结构和存储失败保留原件并返回错误。显式新局先备份原字节；备份失败拒绝替换。已加载页面检查旧值后保存，发现其他页面进度变化拒绝覆盖。浏览器存储不是跨设备云存档，也不能提供跨标签页数据库事务。

回放包含规则版本、地图、种子、动作和最终tick，使用相同规则入口重现至终点；不匹配版本与非法动作拒绝。回放观看不保存战局、不记档案结果。同设备更新必须保留上述固定键，并在打包时通过读档继续保存及回放回归；修改规则版本时需明确迁移或拒绝，不能静默重置。
