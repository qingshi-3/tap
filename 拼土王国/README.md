# 拼土王国 v3

六年海岛王国生存：每季买一块多格土地拼到领土边缘，把多格建筑摆进地形里吃邻接加成；每年冬天交年贡，秋天挡蛮族。纯 ES Module H5，无依赖。面向手机 App：**横屏**（竖屏提示旋转），触屏优先。

```bash
npm run preview          # http://localhost:4198/
npm test                 # 规则 + 存档单测
npm run build            # 打包成单文件 release/拼土王国.html，双击即玩
node tools/sim.mjs 12 smart   # 平衡机器人（smart / lazy）
node tools/qa.mjs 6      # 浏览器四个横屏视口点通流程 + 竖屏旋转提示，截图到 /tmp/pt-qa/（需先 preview）
```

## 输赢
- **胜**：6 年年贡全部交齐（15/30/50/80/120/170 金）。按声望、金币、人口、建筑结算 1–3 星。
- **负**：任一年冬末金币不够交年贡。
- 压力源：第 2 年起每年夏天标记边境威胁格，秋末结算；守卫覆盖到则声望+，没覆盖到则掠夺金币并损坏该格建筑（要修）。粮食不足会饥荒，税收减半。

## 一季流程
1. 买地（每季 1 块，三选一，可付费换一批）：多格异形，拖到领土边缘；地块形成同地形连片后，达到规模就有声望和金币奖励，带宝箱的地块额外送金币。
2. 选卡（三选一，进背包，最多 4 张）：解锁特殊建筑。常备卡（民居/农田/伐木场/哨塔）不需要选卡。
3. 建造：拖或点卡片，旋转，放下。建筑占多格，有地形限制、工人消耗和邻接效果。
4. 下一季：结算产出 → 夏标威胁 → 秋挡袭击 → 冬交年贡。

## 横屏布局与操作
- 顶栏：季节、资源、图鉴、菜单；左栏：常备 4 卡 + 背包 4 格；右栏：买地 / 选卡 / 下一季，放置时换成放置面板（信息、旋转、取消、确认）。
- 卡片/地块：按住拖到地图，或点一下自动找位；**长按看图鉴**。放置中**点虚影旋转**；单指拖地图、双指缩放。
- 触感反馈走 `tap.vibrateShort`（无则 `navigator.vibrate`）；切后台自动存档。

## 教学与图鉴
- 首次「新王国」进入固定种子教学（13 步，`dist/tutorial.js` 的 Spotlight：SVG 镂空蒙版 + 输入锁，只放行高亮区域；说明框避开高亮、左右栏与虚影）。可跳过，菜单可重玩。
- 一次性情境提示：蛮族红旗、冬季年贡、饥荒、新卡解锁。
- 图鉴（顶栏 / 菜单 / 长按卡片 / 建筑详情）：建筑（造价、人手、占地、地形、效果、升级、解锁年份）、地形、规则。

## 文件
| 文件 | 职责 |
|---|---|
| dist/rules.js | 纯规则：种子随机、地块/建筑放置、预览、季结算、袭击、年贡、计分、存档校验 |
| dist/art.js | 全部素材程序化 canvas 绘制（地形、多格建筑、图标） |
| dist/app.js | 画布地图（静态缓存 + 动态层）、HUD、左右栏、买地/选卡面板、放置交互、弹窗、图鉴、教学脚本 |
| dist/tutorial.js | 蒙版聚焦教学组件 Spotlight（仿奇兵列阵） |
| dist/storage.js | v3 存档（损坏不覆盖、开新局自动备份）与战绩 |
| tools/ | serve、build 单文件打包、sim 平衡机器人、qa 浏览器验收（`QA_URL=file://…` 可测打包版）、art-gallery 素材预览 |

旧 v1/v2 沙盒版的存档键保留不动；v3 使用 `patchwork-kingdom.v3`。
