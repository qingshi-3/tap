# 拼土王国

背包拼装式土地扩张 + 城市模拟经营的本地可玩版。普通 HTML / JavaScript H5，无运行时框架和远程服务，手机触控优先，支持横竖屏与桌面。

## 开始试玩

在本目录运行 `npm run preview`，打开 http://localhost:4198/ 。静态入口为 `dist/index.html`，需通过 HTTP 服务访问 ES modules。

- 地图铺满屏幕，不再分成地图和固定工作台。每季自动弹出三选一土地；购地或选择“先建造”后推送三选一建筑。弹窗可收起，角落按钮可重新打开。
- 从卡片拖出3–5格土地或建筑，预览自动吸附到格子，合法位置松手才扣款；非法位置、拖回界面或中断手势均退回。地块可先旋转，必须沿边连接领土且不能重叠。手指上方显示预览，拖到屏幕边缘自动平移。
- 建筑候选优先提供当前有适配空地的类型，未解锁建筑不推送。每次成功建造换一批，可同季继续建；土地和建筑的刷新分别递增5金币，下季重置。收起重开或重载不会免费改变同批候选。
- 点建筑才弹出升级/拆除详情，王城不可拆除，最多三级。保留“点卡片—点地图—确认”作为键盘和非拖动替代路径。
- 拖动地图查看全境，使用缩放/居中按钮。地图支持方向键和回车操作。
- 下一季结算产出、人口、粮食消耗与维护费。春秋农田增产、冬季减产；渔场在夏季增产。年度事件影响资源和幸福，兵营降低风暴损失。

## 内容与经营规则

14×14领土上有草地、森林、水域、山地、沃土。王城、民居、农田、伐木场、矿场、渔场、集市、学堂、医馆、兵营共10类建筑，具有地形限制、独立功能与邻接加成。

金币用于购地、建造与升级，木材用于升级，粮食支持人口；学识与人口共同解锁村落→乡镇→城邦→公国→王国。安居/均衡/商贸政策影响收益。缺粮会压低幸福并停止人口增长，不会删除居民；每季最低4金币用于避免不可恢复破产。达到王国后可继续经营。

初始150金币、30粮食、12木材、8人口和9格领土。具体数值唯一来源是 `dist/rules.js`，目前为本作原型数值，没有宣称复刻任何成熟游戏平衡。当前不是完整商业版本，尚无战争、外交、道路/物流模拟或跨设备同步。

## 存档契约

- 固定本地键不变：`patchwork-kingdom.save.v1`；当前schema version 2，新增建筑抽选进度。每次成功操作后保存，重新加载后可继续操作和保存。
- 不支持的版本或损坏数据拒绝载入，禁止静默重置；普通自动保存不能覆盖坏档。显式建立新王国/导入前，将原件写入 `patchwork-kingdom.save.v1.backup`，备份失败时不替换原件。
- 支持JSON导出/导入。导入先验证，再由玩家确认替换。保存失败显示“未保存”，不声称成功。
- 支持完整校验后的v1迁移到v2，以及当前v2；未知格式不猜测修复。真实旧样本冻结在 `tests/fixtures/save-v1-before-drafts.json`，验证迁移、继续游玩、保存、重载和再次保存。`localhost` 与 `127.0.0.1` 是不同存储来源，试玩入口固定使用 `localhost:4198`。换浏览器/端口前先导出。

## 文件与验证

- `dist/rules.js`：确定性玩法与存档验证；`dist/storage.js`：本地持久化；`dist/app.js`：界面与输入。
- `dist/art.js`、`dist/assets/generated/`：使用本游戏通过内置 image_gen 新生成的彩绘模型图集（10建筑、5地形及净地版本、7资源图标），不再引用本地素材库。完整提示词见 `dist/assets/generated/prompts.json`，图集与裁切记录见 `dist/assets/SOURCES.md`。
- `npm test`：规则与保存失败路径行为检查。
- `node tools/browser-qa.mjs` 或 `node tools/popup-qa.mjs`：当前弹窗/拖放、非法退回、边缘平移、自动推送、四种视口、键盘及v1迁移重进检查。
- `node tools/storage-ui-qa.mjs`：导出导入、重开备份、拆除以及坏档/存储拒绝路径。
- 当前验收记录和截图位于 `output/qa-popup/`；`output/qa/`仅保留上一版历史证据；持续任务见 `TASK.md`。
