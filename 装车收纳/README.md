# 装车收纳

手机竖屏普通 HTML/JavaScript H5，目标运行环境为 TapTap App，桌面浏览器用于预览。原生 ES modules、Canvas 场景、DOM 实体按钮，无运行时第三方依赖。

## 玩法与内容

拖货入车 → 旋转与重排 → 关门出发 → 点货卸车 → 领取首通运费 → 购买下一辆车。拖到空地落地，拖到结实箱子上自动预览上层，最多两层。

25个手工订单逐步教学，每个新规则先单独练习，再与前面的规则组合：

| 订单 | 规则 |
| --- | --- |
| 1–4 | 单站平面拼图，只需把形状装进去；不检查卸货通道 |
| 5–7 | 两层叠放：完整支撑的小件可放在纸箱/收纳箱上 |
| 8–10 | 陶瓶等易碎品可以放箱上，但不能承受上方货物 |
| 11–14 | 重货落地靠前，长件贴壁固定 |
| 15–18 | 多站卸货顺序，包含先搬上层再搬下层 |
| 19–25 | 窄门、轮罩、叠放和多站的组合 |

- 叠放：只有纸箱和收纳箱能承重；上层限不超过两格的非重货，整个占格都必须被下层承重箱支撑。不能悬空、压易碎品或叠第三层。下层承重时不可抽走或移动到让上层悬空的位置。
- 重货前置：开启后，重物只能落地，全部占格须在前 `ceil(车厢高度/2)` 排。
- 长件固定：开启后，指定长件的长边须沿侧壁或前壁贴齐，以绑带显示固定；无需额外点按钮。
- 卸货：前14单允许直接搬出，但仍先上后下；15单起按站检查。上层可提起搬出，下层保持朝向平移走尾门，不能提前移走后站货物给前站让路。
- 即时恢复：超界、重叠、支撑不足、压易碎或违反已教学的摆放规则，立即拒绝并保留原位置；出发前检查多站通道。可继续重排，无倒计时、随机倒塌、资源罚款。
- 星级与经济沿用原契约：无提示且调整不超过货物数三倍为三星，提示不超过一次为二星，其余一星。每单首通奖励为基础运费加星级×10；重接只提升最高星级。完成5/10/15/20单解锁下一辆，基础收入可购买必要车辆。
- 第25单主线收官后可重接。`CONTRACTS` 保留为未开放的验证布局，不计入可玩内容。

鼠标/触摸拖动均可；也可点货再点车厢放下。键盘选货后进入车厢，方向键移动预览、R旋转、回车放置、Delete拿出。按钮有可见焦点，动效遵循系统减少动效设置。上层用抬高投影、露出的承重箱与选中行的“上层”状态表达。

## 存档契约

固定主键 `cargo-packer.save.v1`（不随包版本变化），当前 schema 2。支持 schema 1 → 2 显式升级：先按冻结的 `js/content-v1.js` 验证原档，正在进行的旧订单标记 `contentVersion:1` 并继续原规则；完成后下一单使用新版 `contentVersion:2`。已完成星级、运费与车辆保留。新坐标可含 `z:0|1`，未填视为地板。

读取迁移不会覆盖原文；首次正常保存先把旧原文放入 `.backup`，备份失败停止主档写入。支持旧/新格式同设备加载→继续玩→保存→重进→继续保存，包含两层位置、站次、已卸货、首通回执和购车。

未知版本、坏JSON、未知内容版本/货物/订单、悬空或冲突位置及不一致阶段均拒绝，原件保留，不自动回退或猜测修复。界面提供导出与重新读取；此版本没有导入和跨设备同步。检测到别的页面更新则停止写入，本地乐观检查不是跨页面原子事务保证。不支持把新版存档交回旧版程序继续玩。
