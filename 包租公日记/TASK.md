# 包租公日记：首版活动任务

## 目标与授权

依据用户引用的 ChatGPT 会话「小游戏类型分析」（6acf5eee-5a9c-83ee-a30a-82ec89df01d4）实现可玩的手机 H5 包租公模拟器，并创建独立 TapTap 游戏应用。已授权本地实现、必要浏览器验证、创建应用；未授权上传、绑定、提审、发布或签约。

首版循环：幸福里402室 → 装修 → 招租 → 月结收租 → 租客选择事件 → 购买403室；加入同一城市不同地区的住宅市场。暂不做商业地产、多城市、复杂人口模拟、联网、广告或真实云存档。

## 约束与接口

- 普通 H5，Vue 3 / TypeScript / Vite / Pinia。独立目录 `games/landlord-diary`，竖屏手机优先，兼容短屏和横屏滚动。
- 现有 master 工作区直接开发；不新建分支、worktree，不提交、推送，不覆盖其他游戏。
- 配置驱动房产、租客、装修、事件；纯规则核心与 Vue 状态、存储、界面分离。
- 月份从0表示2029年1月。月结一次推进一个月；待处理事件须先决策。装修完成当月不收租。
- 本地固定存储 `landlord-diary.save.v1`；坏档、未知版本、读写失败必须说明，保留原件，禁止静默新档覆盖。
- 会话中的原始经济缺少首套扩张资金渠道；首版采用公开配置的首付贷款作为必要适配，同时保留全款购房。具体数值属于原型适配，不宣称成熟商业平衡。
