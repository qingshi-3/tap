# 包租公日记

手机竖屏普通 H5 包租公模拟器。依据用户引用的「小游戏类型分析」会话，实现从幸福里402室起步的住宅经营：装修、选租客、月度收租、处理邻里与租客事件，再买下403室，扩展到大学城与科技园。

cd games/landlord-diary

## 首版范围

- 2029年1月，现金20000元，一套待装修的幸福里402室。
- 装修需1至2个月，施工期间不能招租，不收租；完成后恢复房况。
- 每套房有3个独立租位，每位租客只占一个租位。先看地区/装修/房况形成的每租位市场参考，再自行挂牌、改价或撤牌；调价使用±10/±100/±1000实体按钮，无数字输入。首次挂牌默认基准，改过后从当前挂牌价继续调整，只有“恢复基准价”重置；高价可能砍价或无人愿看，参考价不保证成交。
- 看房者可原价或低价报价，玩家接受、还价签约或谢绝；普通报价仅本月有效。新租约固定6个月，房况、市场和预算变化不自动改合同金额，到期后逐户谈续租或结束租约，待决期间沿用旧价。
- 挂牌可入住空房有免费上门客，人物出现在楼下；首次合理挂牌可接待，后续频率受需求影响，每房每月最多一人。中介每次200元，最多推荐两位实际可用候选，无候选时不收费。15名租客全局去重。
- 城市地图显示房价/需求的中文档位与自有房标记，单指拖动浏览；点击小区进入俯视小区地图，查看楼栋档位、市场基准与自有房/空位，再点楼栋进入楼栋场景，点房间购入或管理。小区行情、项目与统计从“小区信息”按需弹窗查看，不常驻展开表单。统计包括套数、空租位、合同收入、预计结余、看房/续租/维修/施工待办。装修档影响租金与需求，当前出售估值以实际房源和区域行情为准，不虚构装修升值。
- 地铁、新校区、研发中心经历传闻、公告、施工、延期/取消或投用。阶段实际影响估值、市场参考与需求；新游戏的城市种子持久化，重进不重抽结果。幸福里基础房初期便宜冷清，可承担空置与维护等待配套发展。
- 月结扣除维护与月供，城市消息与区域行情给出可见反馈。
- 全款或25%首付购房；贷款使用公开配置的年利率与期限，出售时结清剩余本金。
- 同一城市的住宅经营原型；商业地产、多城市、复杂人口模拟与联网暂不实现。

引用会话并非经过验证的成品数值体系。首付贷款、起始现金、地区涨幅与成长节奏属于为可玩闭环加入的原型适配，不宣称复刻真实地产市场或已完成商业平衡。

## 时间与找租通知

所有地区的上门、中介和续租候选出现在左侧人物通知栏；点击直接进入该租客的接待弹窗，处理后通知随持久候选消失，结果弹窗保留，支持接待下一位。楼下人物入口仍可用。通知不另建存档字段，重进从现有候选恢复。

前台空闲时每60秒推进一个月，日期按当月实际天数和月内进度展示。月底仍使用同一月结规则，结算或事件弹窗打开后暂停；接待、议价、装修、购房、账本、小区信息弹窗、城市拖动、存储故障以及页面隐藏时均暂停；城市、小区和楼栋空闲浏览时继续走时。可手动暂停/继续或直接推进月份，月结失败暂停并保留当前月份，不重复扣款。不计算离线收益；月内视觉进度不落档，重进从已保存月份的第一天开始。

通知与时钟验收入口：`node --import tsx tools/notifications-clock-qa.mjs`；通过 `QA_URL` 指定本地预览。五视口真实接待与短屏地图点击、前台真实计时及浏览器虚拟时间月末检查通过，证据在 `output/qa/notifications-clock-report.json`、`notifications-clock-followup.json`、`notifications-map-final.json`。实际系统后台尚未验收，可见性事件暂停路径使用隔离浏览器受控验证。

## 代码与资源

规则与公开内容在 `src/game/`，Vue场景与操作在 `src/components/` 和 `src/App.vue`，Pinia封装命令与存储。主场景使用工程内矢量实体造型，房屋与家具随状态变化；未修改用户源素材库或其他游戏。

按用户最新要求先交付画面结构与功能原型：租客用圆头、实体躯干、固定衣色及配件表现，实际出现在候选队列、房间和事件中；不是文字替代人物。房窗显示空床、施工工人/材料或入住住户。正式插画已生成保留，`src/presentation.ts` 中 `USE_ILLUSTRATED_ART=false` 暂不启用；素材与生成说明见 [assets/SOURCES.md](public/assets/SOURCES.md)。
