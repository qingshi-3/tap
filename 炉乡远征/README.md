# GitHub 源码说明

此目录为《炉乡远征》2026-10-19的本地源码快照，当前包版本为0.4.5。

- `dist/js/`：可编辑的JavaScript游戏源码；`dist/*.css`和`dist/index.html`：样式与页面源码。
- `dist/assets/`与`dist/vendor/`：完整运行素材和第三方库；素材来源见`dist/assets/SOURCES.md`。
- `tools/`：验证、素材处理和打包工具；`tools/fixtures/`保留历史存档兼容样本。
- `TASK.md`与下方原项目记录保留开发背景。历史截图、运行日志、平台回执和旧ZIP未上传，对应历史证据链接仅在原工作区有效。

## 运行与打包

安装Node.js 22或更新的LTS版本，在本目录执行：

```sh
npm run dev
```

浏览器打开 http://127.0.0.1:4179/ 。运行与默认打包只使用Node.js标准库，无需安装npm依赖。请通过本地服务访问，勿直接双击HTML。

```sh
npm run check:save-compatibility
npm run package
```

打包先执行脚本中全部35项强制检查，成功后生成`build/duelyst-h5-0.4.5.zip`与清单；不会上传或发布到TapTap。

浏览器UI测试工具仍保留原开发机的Playwright/Edge路径；资源重生成工具依赖原始素材库或字体工具，换电脑使用这些开发工具前需调整路径和依赖。已导出的资源齐全，普通运行和默认打包不需要原始素材库。广告、云存档、排行榜和成就的真实能力需要TapTap宿主。

## 奖励与正式招募

招募表现使用独立弹窗与原Duelyst开包宝珠/粒子：单抽约2秒蓄光、翻面及随从亮相，十抽约2.95秒逐张揭晓；广告翻倍保存成功后以金色柔光、×2印记和实际新增奖励呈现，合成新随从进一步强化。可跳过或继续，减少动态效果模式保留静态奖励确认。动画只消费已提交回执，不发奖、不扣珠；取消/失败/重复回调不播成功，重试保存成功可正常呈现。关闭、重进和快速替换会清理动画与旧回调。旧保底附加奖励独立横滑显示。两档横屏真实输入、动画阶段截图与design-slop修复复查见`output/recruitment-presentation-ui/`；宿主广告与实体手机效果待复测。

账号首次完成节点领取首通金币及共享中立；其他阵营首次完成同节点领取重打金币和本阵营卡，各阵营首次完成一章另加60金币。失败与试炼不发奖励，同runId幂等。账号节点、阵营节点、阵营章末分别去重，不能把六阵营奖励一次全部发给当前阵营。

首条路线金币合计5970（初始80加奖励5890），后续每条完整路线2070；六线基础金币合计16320。首线基础宝珠额度40，后续每线10，六线90，初始宝珠为0；重复通关不发宝珠。此为奖励额度，并非任何玩家最终余额：消费会减少余额，全收集后的未来宝珠会转成补偿金币，上述金币合计不含补偿。

随机招募无需通关前置条件，有足够宝珠即可抽取。候选目录为24种专属随从（原6+新18），实际奖池逐抽排除已拥有单位（包括初始或历史已获单位），普通关卡单位不进入奖池，不扩展主将来源。每抽消耗1宝珠，支持单抽和十抽；全部收集后停止招募，十连中途集齐则停止剩余抽并退回未抽宝珠，已保存结果的广告翻倍仍可按原回执领取；每抽必得单位碎片，1片88%、2片11%、5片1%，剩余未拥有单位等概率，另固定获得20金币。没有金币独占结果、首次12片或新的十抽角色保证。初始概率按“1为主、2较少且明显高于5、5极小”配置，平均1.15片/抽；20金币沿用此前2片重复奖励折算20金币的量级，作为稳定伴随奖励。这些是项目配置，未经长期真人经济测试，不声称来自参考手游原始概率。

30片自动合成永久卡种，不改牌组；已拥有单位仍积累碎片，不转金币。单抽或十抽的扣珠、奖励、合成和计数一次保存，失败不改资产，同页面重试复用冻结结果并锁住其他资产修改；未成功扣费的失败抽取刷新后可以重新开始。结果回执保存后可从“上次结果”恢复。

每次完整观看广告仅翻倍选中的一抽，补发该抽全部碎片与金币；十抽需逐份选择，全部翻倍需10次广告。每日最多10次成功翻倍，北京时间零点刷新，独立于每日金币/宝珠各1次。取消/失败不发奖、不扣成功次数；预约时冻结结果与日期，跨零点归预约日。重复回调幂等；广告成功先保存与预约绑定的本地凭据，到账保存失败可免重播重试并在重载后恢复。所有本地存储写入均失效时只能保留内存凭据，强退无法保证恢复。不在试炼结果提供翻倍广告。

历史权益按schema12迁移：旧碎片数变为ceil(旧数×30/12)，不降低已取得的合成进度；已拥有单位、金币、宝珠与已结算账本保留。旧定向保底仍按原剩余抽数兑现，原2/12片进度对应5/30片；已有付费随机抽取保留一次旧10抽内新单位权益，到期独立补发单位，不产生12片新奖励；此历史单位补发不参加广告翻倍。未抽过的旧档不发免费首抽角色。

全24种在开战时已经拥有，未来本局宝珠额度按每珠20金币转换。首次保存新局时，battleRewards与活动战斗同事务冻结奖励及claim状态；旧6目标全拥有时冻结的历史奖励保留，不因扩池重新计算。已有宝珠仍可抽取，历史碎片、已领取和待领取凭据不追溯改写。每日广告宝珠独立于关卡奖励。

每日广告入口位于主菜单资源页、招募宝珠按钮和胜利结果金币按钮，共用账号的`dailyAds`账本。金币与宝珠各每天1次，北京时间零点刷新；无通关前置条件。界面固定显示100～1000金币、1～5宝珠，不显示余额或胜利来源。权重配置见`daily-ad-rewards.js`：金币100/200/500/1000分别40%/35%/20%/5%，宝珠1/2/3/5分别50%/30%/15%/5%；每次均值260金币、1.8宝珠。该产出尚未经长期真人经济测试。

首次预约即冻结当日随机金额，取消重试不能重抽；完整播放后金币或宝珠与领取次数同事务保存，失败不扣次数。跨零点广告按预约日计次，旧日期领取后当天仍可领取。旧已付广告保持幂等，历史pending保留但不能据此免看广告领新奖励。日期与额度依赖本机时钟和存档，拒绝回拨至已领取日前的再领取，不是服务端防作弊或跨设备限次。招募每抽必给碎片并伴随金币；培养仍只用金币。
