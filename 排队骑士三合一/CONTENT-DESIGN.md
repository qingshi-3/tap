## 1. 战斗文档评审

### 1.1 总体评价

战斗文档已经是一份合格的引擎规格，可以作为内容设计的地基：

- **五节点管线**（攻击前 → 攻击 → 受击 → 受伤 → 死亡）清楚，每个机制都能挂到确定的节点上。
- **攻击 / 施法两条管线**让格挡、护甲和施法天然互相克制，是牌池"有解"的基础。
- **三条安全锁**（同步快照、先进先出 + 防重入、位移后先刷光环）提前封住了自动战斗最常见的结算争议和死循环。
- **技能语法**"四维筛选 + 时机 → 效果"使新卡可以用统一句式描述，也方便后续做卡面模板。
- **英雄 90% / 10% 分工**（常规技能调动运行时数据，破格只开放给奥义、高阶解锁、传说遗物）给了英雄设计清晰的边界。
- **舍弃卡牌系统、由英雄承担战中介入**的取舍正确，避免了战斗、构筑、经营之间来回切换。

不足集中在三类：若干结算边界没有写死；缺少一组驱动所有数值的目标参数；只定义了"零件"，没有定义"零件如何组成牌池"。第三类由本文件后续章节解决，前两类见下。

## 2. 设计目标与支柱

### 2.1 一句话

在杀戮尖塔式的分叉路线上，经营一支 5 格队列，靠站位和连锁让队伍自动打出组合，再用英雄在交锋间隙做 2～3 次关键调度。

### 2.2 四根支柱

1. **站位即构筑**：同一批单位，排法不同，结果不同。每张卡都要声明它想站哪里。
2. **连锁可读**：组合来自"事件的制造者 × 事件的监听者"，玩家看得懂为什么会连起来。
3. **英雄是手**：自动战斗里唯一由玩家精确指定目标的手段，每场提供 2～3 次真正的转折。
4. **有题有解**：敌人出题（机制），玩家有解（流派、中立技术卡、英雄、站位）。

### 2.3 玩家决策类型

每个系统都要回答它让玩家做哪类决策。

| 编号 | 决策 | 主要承载系统 |
| --- | --- | --- |
| A | 构筑方向：走哪个流派、要不要转型 | 流派、酒馆、遗物 |
| B | 经济分配：钱花在升阶、刷新、招募还是保留 | 酒馆 |
| C | 阵容取舍：谁留下、谁卖掉 | 酒馆、5 格容量 |
| D | 站位：谁在前、谁在后、谁和谁相邻 | 单位技能、障碍物、巨型 |
| E | 单位打磨：经验喂给谁 | 经验、营火 |
| F | 路线与风险：走哪条路、打不打精英 | 地图、生命 |
| G | 应对敌人：看到下一场敌人后怎么调整 | 敌人预告、中立技术卡、英雄 |
| H | 战中调度：何时、对谁用英雄技能 | 英雄 |
| I | 局外目标：为什么还想开下一局 | 熟练度、难度阶梯、解锁 |

## 3. 主流程架构

### 3.1 一局的结构

| 项 | 设计 |
| --- | --- |
| 幕数 | 3 幕 |
| 每幕 | 分叉路线 6 层 + 幕末 Boss |
| 战斗场数 | 每局约 13～15 场（含 3 场 Boss） |
| 单局时长目标 | 30～40 分钟 |
| 生命 | 普通难度 4 颗心；战斗失败扣 1 颗（Boss 战扣 2 颗），扣完结束本局；平局不扣 |
| 失败处理 | 输掉普通战和精英战后照常前进（不重打），只失去该场的胜利奖励 |

采用"生命制 + 失败可前进"，而不是杀戮尖塔的"一败即止"：自动战斗的玩家可控性低于手动卡牌，需要容错。

### 3.2 节点类型

| 节点 | 内容 | 每幕约 |
| --- | --- | --- |
| 普通战 | 敌人用玩家流派的卡组成阵容 | 3 |
| 精英战 | 更强数值 + 1 个精英词缀；胜利给遗物 | 1～2（可选路线） |
| 酒馆 | 额外一次完整的整备（刷新免费 1 次、商品打折） | 1 |
| 营火 | 三选一：强化 / 休整 / 准备（第 12.2 节） | 1（每幕必经） |
| 事件 | 取舍型选项（第 12.3 节） | 1～2 |
| 宝藏 | 遗物或稀有单位发现 | 0～1 |
| Boss | 机制型首领 | 1 |

### 3.3 单个战斗节点的流程

```
地图选点 → 敌阵预告（看到下一场敌人的阵容与词缀）
        → 整备（酒馆：买卖、刷新、升阶酒馆、调整站位、分配经验）
        → 【战备结束时】→ 对峙 → 自动交锋（英雄在交锋后窗口介入）
        → 结算（金币、经验、掉落）→ 返回地图
```

- **整备在战斗之前**，并且能看到敌阵预告。这是"应对敌人"（G）成立的前提。
- 酒馆每次整备都开放（战斗文档开篇："地图战斗节点结束后可以刷新酒馆、购买单位"），酒馆节点只是给一次额外的、更便宜的整备。

### 3.4 一局的节奏目标

| 阶段 | 玩家状态 | 设计意图 |
| --- | --- | --- |
| 第一幕前半 | 低阶单位、选流派 | 快速看到第一个组合，第 2～3 场出现第一次"连起来了" |
| 第一幕 Boss | 流派雏形 | 考站位基础（第 11 章） |
| 第二幕 | 成型、第一个 3 级单位、英雄第一个分支 | 精英词缀开始考反制 |
| 第三幕 | 终端卡 / 巨型开放、完整构筑 | 考完成度；多部位 Boss 考英雄调度 |

### 4.3 单位升级：同名合入与全局经验合一（D5 已定）

战斗文档 7.2 写的是"用全局经验让单位阶梯升阶"，游戏名"三合一"又意味着同名合成。两条线并存会互相重叠，本文件将它们合成一条：

- 每个单位有 **1～3 级**。升到 2 级需要 2 点经验，升到 3 级再需要 3 点。
- **同名合入**：把同名单位拖到已有单位上，合入 1 点经验（三张同名 = 一个 2 级单位，与"三合一"的直觉一致）。
- **全局经验**：每场战斗结算发 1～2 点经验，由玩家自由分配给任意单位。营火和事件也给经验。
- **升级内容**：2 级身材 ×1.5；3 级身材 ×2，并**升级技能**（见 5.3）。技能升级是升级的主要价值，身材是次要。

理由：只靠同名三连，升级由商店运气决定，核心卡刷不到第二张时会卡手；只靠全局经验，重复卡没有用，商店决策变薄。合一后，同名合入是商店运气的奖励，全局经验是玩家可控的保底。全局经验要保持少量（每场 1～2 点），避免压过追同名卡。

技能折算参考（一个触发器的大致价值）：

| 效果 | 折算点数 |
| --- | --- |
| 1 层格挡（每场 1 次） | 2 |
| 护甲 1（常驻） | 3 |
| 每场 1 次施法 2 点 | 2 |
| 召唤一个 1/1 | 2 |

| "身后所有""全体"范围 | 单体价值 × 2 |

### 5.3 3 级技能升级的原则

优先级从高到低：

1. **范围**：一个目标 → 两个；身后一名 → 身后所有。
2. **频率**：每场 2 次 → 3 次；冷却 3 → 2。
3. **新条款**：补一个本流派语言里的小效果。
4. **数值**：只用于终端卡和资源产出卡。

**可感知原则**：频率类升级要在战斗演出里有可见反馈（3 级多出的那次触发显示金色），否则玩家感觉不到。

### 5.4 巨型

战斗文档第六章的规则全部沿用，补充：

- **巨型是通用的终端形态**：每个流派各有一张巨型终端卡（5 阶），熔岩流派专精巨型（聚变、部位升阶）。
- 每队最多上阵 1 个巨型（战斗文档 6.4）。
- 预算：2 格巨型 = 5 阶预算 × 1.6，3 格 = × 2.2（R10）。
- 横扫 N 格是巨型的天然收益，计入预算。
- 弱点：范围伤害按格计算（战斗文档 6.2），所以顺劈、横扫、群体施法是巨型的天然克制。
- 部位升阶（6.4"把经验分配给选定部位"）**只对熔岩的巨型开放**，其他巨型按普通单位升级。

### 5.5 卡牌角色模板

每个流派 10 张卡：

| 角色 | 数量 | 阶层 | 职责 |
| --- | --- | --- | --- |
| 启动 | 2 | 1 | 单独上场就有用，同时把玩家引向本流派 |

### 6.2 事件的制造者与消费者

组合来自"制造事件 × 监听事件"。要求每个事件至少有 2 种制造方式和 3 种消费方式。

| 事件 | 主要制造方式 | 主要消费者 |
| --- | --- | --- |
| 【战备结束时】 | 每场固定 | 熔岩聚变、深渊吞噬、永久成长 |
| 【开战时】 | 每场固定 | 各流派启动卡、霜境召唤、冰冻 |
| 【攻击前】 | 每轮固定 | 熔岩窃取、圣盾加防 |
| 【受击时】 | 被攻击；墙、圣盾主动顶前排 | 圣盾格挡链、冰墙冰冻、方尖碑 |
| 【受伤后】 | 被攻击、自伤、灼烧、疲劳 | 熔岩成长、影刃撤退换位、圣盾治疗 |
| 【死亡（亡语）时】 | 阵亡、吞噬、送葬者献祭 | 深渊全线、霜境召唤 |
| 【补位时】 | 阵亡、换位、击退、拉拽、插队（R3） | 影刃全线、调度者被动 |
| 【交锋后】 | 每轮固定 | 蓄力推进、霜境延长冷却、治疗 |
| 【战斗结束时】 | 每场固定 | 临时转永久 |

## 7. 流派

### 7.1 总览

六个流派与 Duelyst 六个阵营一一对应：颜色即流派，玩家看图就知道打法。阵营是美术与题材的默认归属，不是机制的硬约束（扩展见第 15 章）。

| 流派 | 阵营 | 核心零件（≤3） | 成长形态 | 主站位模式 | 怕什么 |
| --- | --- | --- | --- | --- | --- |
| 圣盾 | 曦光 f1 | 格挡链、援护、伤害分摊 | 防御层越叠越厚 | 前排扛线，后排给前邻上防御 | 施法、碎盾、破盾、疲劳 |
| 影刃 | 宋海 f2 | 换位 / 击退、插队、连击 | 行动次数越来越多 | 不断换人上队首，吃【补位时】 | 稳固、眩晕、援护 |
| 沙阵 | 维特鲁 f3 | 障碍物、蓄力、顺劈 / 贯穿 | 单次爆发越来越大 | 墙在前，炮台在后 | 拉拽、延长冷却、无视稳固 |
| 深渊 | 深渊 f4 | 亡语 / 共鸣、吞噬、复活 / 传功 | 场内越死越强 | 祭品在前，继承者在后 | 沉默、放逐、压制上限 |
| 熔岩 | 岩浆 f5 | 巨型 / 聚变、复生、过量伤害 | 资源集中到一个核心 | 巨型 + 2～3 名护卫 | 范围伤害、放逐、沉默 |
| 霜境 | 冰原 f6 | 冰冻、延长冷却、召唤 / 扩编 | 往宽长：更多单位 | 小兵铺满，控制敌方节奏 | 顺劈、横扫、压制上限 |

**桥接环**：每个流派与左右两个流派各有一张桥接卡，靠共享事件连接。

```
        圣盾 ── 受伤后 ── 熔岩
       /                    \
  插队/援护              吞噬/复生
     /                        \
  影刃                        深渊
     \                        /
  换位送队尾             召唤/溢出
       \                    /
        沙阵 ── 控制/墙 ── 霜境
```

**流派分型**（每局开放时保证分布）：

| 分型 | 流派 | 说明 |
| --- | --- | --- |
| 战前型 | 熔岩、深渊 | 主要收益在【战备结束时】【开战时】或跨场成长 |
| 交锋型 | 圣盾、影刃、霜境 | 收益在每轮交锋中 |
| 蓄势型 | 沙阵 | 收益在若干轮后爆发 |

每局开放 6 个流派中的 **4 个**，加全部中立单位（约 52 张）（D4 已定）。开放时至少有 2 组相邻（有桥接）的流派。

（2026-11-27 四流派数值调平：圣盾、影刃、深渊、霜境各幕对其他三家的平均胜率调到 46～54%。共改 18 张卡的身材和铁崖守护者的技能，卡表已是调后数值，改动清单和数据见 prototype/README.md 第 11 节。）

## 9. 英雄

### 9.1 定位

- 英雄是战斗中唯一由玩家**手动精确指定目标**的手段（战斗文档 7.4），也是唯一的战中介入手段（7.2 已取消卡牌系统）。
- 英雄与流派**正交**：每名英雄有一个核心动词，任何流派都能用；靠"动词 × 流派"产生组合（D3 已定）。
- 规模控制：首批 6 名英雄，每名 5 个技能槽 + 分支，合计约 30 个技能和 30 个分支变体。
- 不做法强一类的独立数值培养。

### 9.2 技能组模板

| 槽位 | 形态 | 耗能 / 次数 | 作用 |
| --- | --- | --- | --- |
| 被动 | 常驻 | — | 规定额外能量来源，与核心动词联动 |
| 主动 A | 可反复使用 | 2 能量 | 核心动词，每场约 1～2 次 |
| 主动 B | 可反复使用 | 3～4 能量 | 第二个动词，与 A 配合 |
| 奥义 | 单场限 1 次 | 充满 6 能量后可用，消耗全部 | 破格技能（10% 权限，战斗文档 7.4(1)） |
| 整局技 | 整局限用 2 次 | 不耗能量 | 跨场权衡，例如关键 Boss 战前保留 |

**能量规则**：开战时 0 点；每轮【交锋后】+1；上限 6；英雄被动提供额外来源。按"均势战斗 6～9 轮"计，一场能放 2～3 次主动技能，或 1 次奥义加 1 次主动技能。

**操作规则**沿用战斗文档 7.3：只在【交锋后】窗口释放；没有可用技能或合法目标时自动跳过；可以预输入，到时复核，目标失效不扣能量。

**分支**：每个技能有 2～3 个变体，局外按熟练度解锁（第 13 章），局内在第一、二幕 Boss 后各从已解锁的分支里随机给 2 个选 1，事件中也可以进化。分支改变方向，不加数值。

| 被动 | 共感 | 任意单位获得或失去格挡、护盾、灼烧时，能量 +1（每轮最多 +1） |
| 主动 A | 移转（2） | 把一个单位的全部格挡、临时护盾或灼烧转给另一个单位（敌我皆可） |
| 主动 B | 换血（3） | 交换两名友军的当前血量（不超过各自上限） |
| 奥义 | 反转 | 对一个目标攻血反转（零件 31） |
| 整局技 | 封存 | 放逐一名敌人 2 轮 |

分支示例：移转时层数 +1；换血改为一名友军与一名敌人交换；反转作用于己方巨型时同时恢复满血。
契合理由：把圣盾的格挡集中到关键位置，把灼烧转给敌人，给熔岩巨型续命，帮深渊调控谁先死。

#### 送葬者　动词：献祭友军

| 槽位 | 技能 | 效果 |
| --- | --- | --- |
| 被动 | 魂火 | 友军每阵亡一名，能量 +1 |
| 主动 A | 献祭（2） | 消灭一名友军，立即触发其亡语 |
| 主动 B | 归魂（4） | 从坟场以一半血量复活一名友军到队尾 |
| 奥义 | 万魂齐鸣 | 立即触发一次全队所有友军的亡语（不阵亡） |
| 整局技 | 殉道 | 本场第一名阵亡的友军，把全部伤害与血量传给后邻 |

分支示例：献祭时被献祭者的一半身材传给后邻；归魂改为复活到 1 号位；献祭可以作用于障碍物，并触发碎墙效果。
契合理由：深渊主动制造亡语，熔岩用献祭为巨型腾格子，沙阵献祭方尖碑触发碎墙。

### 9.5 设计禁区

- 不把"获得格挡"和"造成伤害"简单拼成一个技能（战斗文档 7.4）。
- 英雄技能不直接加永久属性。
- 每个主动技能必须能撬动至少 3 类接口（位置、状态、计数器、事件、容量中的任意 3 类）。

## 11. 敌人、精英与 Boss

### 11.1 原则

- **数值做底，机制点缀**：普通战靠数值缩放撑量，精英靠词缀出题，Boss 靠手工设计考察。
- **敌人用玩家的牌池**：6 个流派本身就是 6 套敌人模板，敌人阵容由流派卡按"敌人预算"组成。
- **敌人的数值曲线对齐玩家的预期强度曲线**：由第 5.2 节身材预算推出玩家每层的期望总身材，敌人按比例设定。

### 11.2 普通战

| 项 | 设计 |
| --- | --- |
| 阵容 | 从一个流派模板取 3～5 个单位，第二幕起混入第二流派 |
| 数值 | 敌方总预算 = 玩家该层期望总预算 × 难度系数（普通 0.85～1.0） |
| 预告 | 战前完整可见（阵容、技能、站位） |

**原型标定（2026-11-27，prototype/README.md 第 12 节）**：机制遭遇用"遭遇数值系数"控制难度（乘在整支遭遇队伍的血量、伤害、施法伤害上），目标是玩家看着敌阵排好站位、不用英雄时胜率约 30%。标定结果：第一幕 0.85～1.5，第二幕 1.0～1.4；第三幕血量 2.25～2.5、伤害 1.31～1.38（伤害只吃血量增幅的 25%，否则伤害一起翻倍，战斗只打 4～5 轮；见第 13 节）。系数要按"排好站位的玩家"来定：按粗排站位定的难度，玩家排好站位后胜率会到 50～98%。

### 11.3 精英词缀（8 个）

精英 = 流派模板 + 数值 ×1.25 + 1 个词缀。8 词缀 × 6 模板 = 48 种组合。

| 词缀 | 效果 | 考什么 |
| --- | --- | --- |
| 沉默者 | 开战时沉默玩家 2 号位 | 不过度依赖单个引擎 |
| 压制者 | 玩家容量 −1 | 召唤流、满编流 |
| 碎甲者 | 攻击附带碎盾和破甲 1 | 圣盾 |
| 腐蚀者 | 攻击附带重伤 | 治疗、吸血 |
| 疾令者 | 敌方冷却每轮额外 −1 | 速度压制，考打断 |
| 放逐者 | 开战时放逐玩家队尾 2 轮 | 后排蓄力、深渊 |
| 磐石 | 全体稳固（免疫位移） | 影刃、推阵者 |
| 不死 | 全体复生（1 血） | 考过量伤害、范围伤害 |

### 11.4 各幕主题与 Boss

| 幕 | 主题 | 考察 | Boss 候选 |

## 12. 节点内容

### 12.1 酒馆节点

一次额外整备：免费刷新 1 次，本次购买价格 −1，可以用 5 金把一个单位直接升 1 级。

### 12.2 营火（每幕必经）

| 路线 | 效果 | 适合 |
| --- | --- | --- |
| 强化 | 获得 3 点经验，或一个单位直接升 1 级 | 构筑成型中 |
| 休整 | 恢复 1 颗心，并削弱下一场普通战（敌方 −20%） | 残血 |
| 准备 | 查看本幕 Boss 的完整阵容，并从 3 张针对它的中立卡里选 1 张 | 为 Boss 准备答案 |

### 12.3 事件方向

每个事件的选项要朝不同方向走，而不是同一方向比大小。

| 方向 | 决策 | 例 |
| --- | --- | --- |
| 节奏 vs 长期 | 现在拿还是以后拿 | 现在 +6 金，或下一幕每场 +1 金 |
| 安全 vs 风险 | 读阵容强度和剩余生命 | 下一场敌人 +30%，赢了得遗物、输了多扣一颗心 |
| 流派承诺 | 是否押注方向 | 选一个流派，本幕该流派出现率翻倍、其他减半 |
| 交换与牺牲 | 哪个单位已经没用 | 卖掉一个单位，另一个单位获得它的一个技能 |
| 信息与控制 | 让后面的选择更准 | 查看本幕 Boss，或重排下两层节点 |
| 资源转换 | 哪种资源当前最不值钱 | 1 颗心换 8 金；3 点经验换一件遗物 |
| 英雄进化 | 英雄方向 | 从已解锁分支中选一个进化 |

按幕分布：第一幕偏流派承诺、节奏 vs 长期；第二幕偏交换与牺牲、安全 vs 风险；第三幕偏信息与控制、英雄进化。首批约 15 个事件。

### 12.4 宝藏

三选一：一件遗物 / 一个 4 阶以上单位的发现 / 4 点经验。

## 13. 局外养成

### 13.1 原则

以**横向解锁**为主，不做加攻血、加开局金币之类的纯数值成长。平衡不必按养成档位分别校准；复杂度随熟练度逐步增加。

### 13.2 英雄熟练度

每名英雄单独计熟练度，每局按进度给经验（到达层数、击败 Boss 数，难度越高倍率越高），输了也有进度。

| 等级 | 解锁 |
| --- | --- |
| 1 | 被动 + 主动 A + 主动 B，每个技能 1 个分支 |
| 2 | 奥义 |
| 3 | 每个技能第 2 个分支 |
| 4 | 整局技 |
| 5 | 每个技能第 3 个分支 |
| 6 | 外观（立绘皮肤、称号）+ 专属挑战 |

### 13.3 其他局外内容

- **英雄解锁**：首局固定调度者；通关第一幕解锁第 2 名，之后每次通关解锁 1 名。
- **流派解锁**：首局固定开放 4 个流派（圣盾、影刃、深渊、霜境）；沙阵、熔岩在累计游玩若干局后加入随机池。
- **难度阶梯**：用某名英雄通关后，解锁该英雄的下一级。
- **成就与图鉴**：单位、遗物、Boss 收集。
- **广告**：只加速熟练度或解锁皮肤，不换取实力。

## 15. 扩展路线

1.0 的结构为扩展预留了空间：

| 方向 | 做法 | 素材储备 |
| --- | --- | --- |
| 中立系列流派 | 机甲（集齐 5 个部件聚变成巨型）、魔像（稳固与护甲）、佣兵（经济流）、野兽 | mechaz0r 5 张、golem 8 张、merc 约 30 张、beast / monster 约 20 张 |
| 阵营第二流派 | 每个阵营再分出一条线，如深渊的"暗影蔓延"、冰原的"冰龙" | 各阵营剩余 4～14 张 |
| 跨阵营标签流派 | 一个标签（如"部族"）横跨多个阵营，按标签计数 | 不需要新素材 |
| 储备零件 | 状态传染、更多传说遗物、战前命令 | — |
| 更多英雄 | 新动词：预备位（第 6 格替补）、出手顺序、商店规则 | — |

扩展规矩：

1. 新机制必须用战斗文档的现有语法表达（挂在现有事件和接口上），不改引擎规则。
2. 每个流派的核心零件不超过 3 个；扩展加的是变体，不是继续堆词。
3. 新流派必须进入第 6.1 节克制表和第 6.2 节事件表，并找到至少一个桥接邻居。
