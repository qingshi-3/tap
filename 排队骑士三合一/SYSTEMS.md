# 系统架构与分工

本文件定义游戏由哪些系统组成、每个系统负责玩家的哪类决策，以及 2026-11-16 定下的架构决定。各系统的内容填充（具体有哪些事件、英雄、装备……）在此框架下逐项设计。规则细节仍以源码为准。

## 1. 玩家决策类型

每个系统都应回答：它让玩家做哪一类决策。

| 编号 | 决策 | 玩家在想什么 |
| --- | --- | --- |
| A | 构筑方向 | 走哪个流派、要不要转型 |
| B | 经济分配 | 钱花在升本、刷新、招募还是补给 |
| C | 阵容取舍 | 谁留下、谁卖掉、谁被接替 |
| D | 站位 | 谁站前面、谁躲后面 |
| E | 单位打磨 | 资源喂给谁、怎么喂 |
| F | 路线与风险 | 走哪条路、要不要打精英 |
| G | 应对敌人 | 看到下一场敌人后怎么调整 |
| H | 局外目标 | 这局打完，为什么还想开下一局 |

2026-11-16 盘点结论：E 被补给、法术、装备、篝火、英雄技能和多个事件同时占据（"养大哥"成为主流的结构原因）；G 偏弱（敌人可见但很少出题，终局只比总身材）；英雄影响太小；H 缺失。

## 2. 架构决定（2026-11-16）

1. **局外成长进入 1.0。** 先做最轻的版本：英雄解锁、难度阶梯、成就，具体见后续设计。
2. **英雄做大，作为本作特色重点设计。** 见 §4。
3. **补给、法术、装备按 §3 重新分工。** 现有 22 种补给、20 种法术、29 件装备按新职责逐项归类和改造。
4. **敌人做成"出题"系统。** 每幕一个主题，Boss 考察流派完成度和站位，而不是总身材。
5. **金色的主要价值是技能升级，身材是次要。** 低阶金色的身材翻倍要削弱；技能升级需要逐卡设计，工作量在这里。

这些决定扩大了 README §1 冻结的 1.0 范围，README 已同步。

## 3. 系统分工

| 系统 | 职责 | 主要服务 | 相对现状的变化 |
| --- | --- | --- | --- |
| 单位 / 流派 | 决定你在构筑什么，是核心身份 | A、D | 不变 |
| 三连 / 金色 | 技能升级 + 发现；身材翻倍降为次要 | A、E | 低阶金色削弱；篝火"+2 份"等白送份数的来源收紧 |
| 补给 | 流派引擎的燃料：效果挂到流派机制上（喂蓄能、召唤、传承……） | E | 通用加攻血的补给减少、性价比降低 |
| 法术 | 操控：复制、变形、移动、标记等一次性操作 | C、D、G | 去掉纯数值效果 |
| 装备 | 词条载体：给单位一个角色（斩杀、护盾、穿透……），与精英敌人共用词条层 | E、G | 从加数值转向给词条 |
| 接替 | 换人不亏本，服务"在流派内部升级" | C | 继承比例按流派区分（同流派全额、跨流派减半，待定） |
| 遗物 | 改写整局规则，强化流派方向 | A | 不变；与英雄分工见 §4 |
| 英雄 | 整局玩法倾向：改写一个通用动作，随整局成长 | A、D、G | 重做，见 §4 |
| 事件 | 取舍：选项朝不同方向走 | 混合 | 重做，见 §5 |
| 地图 | 路线风险和资源类型的选择 | F | 节点差异拉开 |
| 敌人 / Boss | 出题：每幕主题，Boss 考察流派与站位 | G | 重做 |
| 生命 / 难度 | 容错与挑战梯度 | F、H | 难度阶梯并入局外成长 |
| 局外 | 解锁、难度阶梯、成就 | H | 新增 |

新内容按职责设计：例如设计新装备先问"它给单位什么角色"，而不是"加多少攻血"。

## 4. 英雄

### 4.1 历史版本

| 版本 | 做法 | 结果 |
| --- | --- | --- |
| 奇兵列阵 v0.8（`奇兵列阵/DESIGN.md` §5、§13） | 13 名主将，每人**改写一个通用动作**（占位、轮转、出手顺序、敌方站位、阵亡计数、献祭、补位……），各带 4 个专属被动在晋升时出现，用来改变这个动作的方向；另有主将法强培养 | 决策差异大、和流派交叉产生大量组合；但 13 × 4 = 52 个被动加法强培养，规则交互多、修边界的契约很长，强度难以对齐 |
| 奇兵列阵 v0.10（同文件"机制收敛"） | 收敛为 4 名主将随机 3 选 1，"主将提供战术工具，单位决定构筑"；取消法强培养；改为每章一次共享战术三选一 | 复杂度下降，但主将特色变弱 |
| 三合一 v0.8 至今（`docs/archive/DESIGN-v0.8.md` §4.2） | 6 名英雄开局 2 选 1（首局固定老兵队长），沿用"改写通用动作、和流派正交"的说法，但实际是小被动或 2 金小主动 | 影响太小；军需官"永久 +1/+2"还在强化"养大哥" |

### 4.2 方向（待定稿）

- 保留奇兵列阵最好的部分：**每名英雄改写一个通用动作，与流派正交**，靠和流派交叉产生组合。
- 吸取收敛的教训：英雄数量和分支数量都要控制；不做独立培养数值（法强）。
- 英雄随整局成长：在固定节点（例如第一、二幕 Boss 后）从该英雄的分支里二选一，既改变动作方向，也给后期提供决策点。
- 与遗物分工：英雄改写"怎么玩"（动作），遗物改写"打多大"（规则和数值，偏流派）。
- 英雄解锁作为局外成长的第一条主线。

候选动作（适配本作的排队、商店循环）：敌方站位（换位，直接服务 G）、出手顺序（首位或末位追加行动）、预备位（第 6 格替补）、阵亡计数（魂）、献祭、商店规则（刷新、出售、接替）、三连与金色（金色时二选一技能升级，服务决定 5）、路线（预知、改节点）。

## 5. 事件方向

每个事件的选项要朝不同方向走，而不是同一方向比大小。

| 方向 | 决策 | 例 |
| --- | --- | --- |
| 节奏 vs 长期 | 现在拿还是以后拿 | 现在 +6 金，或下一幕每回合 +1 金 |
| 安全 vs 风险 | 读阵容强度和剩余生命 | 下一场敌人更强，赢了得遗物、输了多扣心 |
| 流派承诺 | 是否在此时押注方向 | 选一个流派，本幕该流派出现率翻倍、其他减半 |
| 交换与牺牲 | 哪个单位已经没用 | 卖掉一个单位，让另一个获得它的技能 |
| 信息与控制 | 让后面的选择更准 | 查看本幕 Boss 阵容，或重排下两层节点 |
| 资源转换 | 哪种资源当前最不值钱 | 装备换刷新，或 1 心换 8 金 |
| 队伍结构 | 重新思考站位 | 交换两个单位的永久加成 |

按幕分布：第一幕偏流派承诺、节奏 vs 长期；第二幕偏交换与牺牲、安全 vs 风险；第三幕偏信息与控制、队伍结构。

篝火是每幕必经节点，改为三条路线：强化（+1 份，不再直接送金色）、休整（回心并削弱下一场普通战）、准备（看本幕 Boss 并获得针对它的发现）。
