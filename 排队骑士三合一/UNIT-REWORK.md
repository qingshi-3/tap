# 单位流派重构

此次目录新增 94 张可获得单位。车轮、蓄势、薪火、兽巢、血契、行商、咒印、并肩、猎标、军阵和补给各占八张。另有六张通用单位。每个流派都有两张启动、三张引擎、一张补短板、一张终端和一张桥接。全量单位定义保留旧 ID，旧候选带有 `legacy` 标记，供敌阵和历史演示继续解析。单位重构首版使用 v4 存档，当前支援系统版本使用独立 v5，旧版进度保留在原键。

开局固定开放补给，再从其余十套抽五套，另投放六张通用单位。普通商店仍受酒馆等级约束，终端从第三幕开放。玩家可以在不卖出老队员的情况下把新同名单位单独放在邻位，也可以把它叠到原卡上。

## 规则及兼容

`archetypes.ts` 定义身份、角色和两种规则。规则的普通与金色值保存在同一处，卡面通过索引读取相同数值。新卡在 `reworkCatalog.ts` 声明，使用精灵素材 ID 解析阵营。老字段 `line` 与 `tag2` 继续提供旧版标签接口。每张桥接卡的 `bridge` 指向可合作的第二流派。

| 分派位置 | 目标和触发 | 效果 |
| --- | --- | --- |
| 战斗事件 `engine.ts` | 开战、登场、攻击后、交锋结束、受伤、阵亡、队友阵亡、召唤。目标包括指定猎物、同名邻居、敌尾和事件单位 | 本场增益、格挡、伤害、轮转、充能、释放、传承、召唤、加标、引爆 |
| 战斗被动 `engine.ts` | 在变动发生时读取存活来源和实际邻接；保命在致命伤结算时检查 | 合巢、队首承伤、邻位承伤、并肩应援、濒死保命 |
| 经营规则 `run.ts` | 自己买入、自己卖出、单位买卖、直接进食、施法、回合开始或结束、主动献血 | 永久增益、下场格挡、金币、临时法术、口粮、首攻封印 |

经营触发使用独立次数账本。全队每回合额外金币上限 4、生成临时法术上限 2、生成免费口粮上限 2；详情和六派面板显示剩余额度。购买效果按新购普通副本计算，施法的第二／第四次等奖励使用整回合序号。出售传餐只结算传入补给本身，自身直接进食规则另行记录。战斗规则可按每场次数、每隔若干次事件、生命阈值、在后排或同名邻接等条件发动。圈数以开战人数为分母，成功召唤数与圈数的伤害或身材倍率从一倍起算。遗言传承只复制首项可传阵亡规则，同源不会重复录入。护卫仅分担交锋伤害。符印记录伤害值，回声法座按施法计数打群伤。

本目录优先实现十一套可以操作的卡组。通用战后成长换算、第三幕敌阵预算和各流派同种子胜率属于单独的平衡问题。当前卡面数值为首轮参数。


## 补给、装备与遗物

新目录有 23 种补给（22 种可自然刷新，牛奶由指定效果生成）、29 件可投放装备、24 件可选遗物。原有 20 种法术单列。补给以金币换下一战的准备或一名队员的永久成长；装备占用一名队员唯一的装备位，随持有者触发；遗物持续整局，可以把一名队员的行动收益交给另一名。带两个流派标签的支援品在任一标签开放时进入候选，拿到后由卡面条件决定实际受益者。

| 流派 | 补给怎么用 | 装备交给谁 | 遗物怎样改变排列或资源流 |
| --- | --- | --- | --- |
| 车轮 | 接力彩带给实际轮转的骑手，换首后给新队首一次格挡 | 折返马刺让每次成功轮转给骑手 +1/+2，每场三次 | 接棒钟强化新队首。不同骑手轮转共用三次额度 |
| 蓄势 | 预装弹包花 2 金给有释放技能的炮手预装两点，让它也可以打头阵 | 回压弹膛给已具备释放的炮手，成功开火时向身后递两点蓄能 | 联膛管让全队前两次有接收者的成功开火为下一位装弹，要保留炮手身后的释放位 |
| 薪火 | 守火蜡给承接者，实际收到传承时额外 +2/+3 一次 | 封存遗嘱为牺牲位附上一次 30% 身材传承，承火搭扣则保护接手者 | 守烬誓约给继承人再下一位送格挡，三段队列能把同一次传承分给两人 |
| 兽巢 | 幼兽饲粮给能活到召唤发生的饲养位，新来的两只小兵各 +1/+2 | 孵兽背篮占一个装备位，阵亡时在队首召唤 2/2 幼兽。幼兽护面用于保护新生小兵 | 育兽名册让登场者保护身后队员，成功召唤越多，后续登场送出的生命越多；全队共三次 |
| 血契 | 苦胆酒花 1 金换三点开战伤势和一层格挡，起始生命至少为一 | 倒刺短刃给能承受一击的斗士，受伤存活且半血以下时反刺敌首 | 共血契书让每回合首次主动献血给队首一层下场格挡，献血者和承伤者可以分开 |
| 行商 | 压箱金饼让持有者首次登场按余金攻击敌尾。购物后留款可换伤害 | 收银腰链把出售其他单位转成持有者的首攻封印，每回合两次 | 周转账簿把每回合第二次出售转为一份免费面包，队首须在场，使用现有口粮生成额度 |
| 咒印 | 蘸印墨直接给指定单位三点首攻封印，用于确定能出手的前排 | 双声印笔给后方的持有者，本回合第二、第四次施法分别给身后队友封印三点 | 叠印石砚把第二次施法收益固定给队首，施法前可先调出战顺序 |
| 并肩 | 对半饼给同名相邻的一名成员，开战时给搭档一层格挡 | 镜刃要求持有者出手后同名仍相邻，方可保护搭档并打敌尾 | 双生队旗让每个有同名邻居的队员向一个同名搭档给 +2/+1；三连同名的中间成员优先给身前搭档 |
| 猎标 | 寻踪香盐把开战标记落在备战选好的猎物上 | 套索准星开战挂标，交给炮手还可在有效释放后再加标；收网重锤适合靠后登场引爆 | 合猎令在全队前三次攻击后按猎物当前层数造成额外伤害，保留层数。开战贴标可用足三次射击 |
| 军阵 | 列阵浓汤在持有者首次登场时，按当时仍完整的原始邻接边增加生命 | 护邻肩甲为实际相邻友军分担至多两点交锋伤害，每场四次 | 连营地钉把开战阵形的完整邻接边换成全队生命。五人完整队列有四条边，也会占满召唤空间 |
| 补给 | 行军干粮花 1 金永久加两点生命，补给单位出售时可传出这份进食记录 | 野炊饭盒让持有者的首次直接进食转为格挡。开饭铃改为奖励其他队员进食 | 轮餐铜钟每两次直接进食就给第二位食客两点首攻封印，每回合两次。分配进食次序决定持印者 |

支援规则使用固定数值。战斗引擎为单位、装备、补给和遗物记录各自来源；成功退到队尾、清空非空蓄能和收到有效传承分别触发对应规则。传承可携带原生单位遗言，补给和装备的附加规则随持有者结算。同种临战食谱在同一友军身上只挂一份，预装、封印和格挡等数值资源可以继续累积。预演使用出战副本，正式战斗结算清除本场资源。

遗物卡面标明全队或每人各自的次数。装备经营规则绑定持有者与装备 ID，遗物经营规则全队按规则独立记账。幼兽占用常规五个队列格；只有原有合巢单位能在队满时把新小兵的身材合入已有小兵，合流沿用原来的召唤计数。每个品质有通用装备，行军臼炮给单人提供完整的后排装填和登场释放循环，可用来承接队友送来的蓄能。

新道具定义位于 `source/src/core/supportCatalog.ts`。定向资源和支援规则同时供运行时与卡面取数；`support.ts` 提供开放流派筛选和经典投放清单，`data.ts` 汇总自然候选与按旧 ID 查询的完整目录。面包、牛奶、锁子甲等经典物品保留原有效果。v5 的购买、持有和存档校验共用本局开放目录，历史战斗演示仍可按旧 ID 解析。新局使用独立的 v5 存档键，v4 进度保存在原键。
