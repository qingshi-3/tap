# 排队骑士三合一 · UI 与交互评审报告（UI-REVIEW）

> 评审基准：UI 交接包全部 **62 张**运行截图（1280×720 / 844×390 / 720×360）+ 仓库现行 `UI-FX-CONVENTIONS.md` 与 `master` 源码核实。  
> 最终视觉方向：**保留暗夜紫金基底，全面统一为高辨识度纯像素切角与铸铁/黄铜材质**。

## 总诊断

项目已具备扎实的 Duelyst 像素单位精灵与肉鸽卡牌玩法骨架，但交接基线的 UI 整体观感像「将冷灰网页后台管理系统缝在像素精灵上」：全站存在至少三套互相冲突的弹窗皮肤、多处布局穿模与截断、战斗主屏浪费近一半画幅、手机横屏挤压严重，且卡牌与战斗交互缺少肉鸽卡牌应有的焦点控制与操作手感。

---

## 一、逐屏 / 分模块锐评（UI 设计 + 交互设计）

### 1. 标题、开局与地图（`01-title`、`02-settings`、`03-difficulty`、`04-hero-pick`、`05-map-first`、`23-map-progress`、`52-title-continue`）
- **像素场景与模糊矢量字割裂（`01-title`、`52-title-continue`）**：夜空、月亮与巡逻骑士均为锐利像素风，但正中央主标题「排队骑士」使用重度高斯模糊光晕的平滑无衬线渐变字，与背景明显脱离。
- **主次按钮权重倒置（`01-title`）**：右上角「新手教程」使用高饱和荧光绿与强发光，视觉重心压过中间主入口「新的游戏 ▶」。
- **开局选人/难度偏表单化（`03-difficulty`、`04-hero-pick`）**：选难度为三条横排纯文字框；选英雄在 1280×720 硕大弹窗中仅孤零零展示一张卡片，四周大面积死黑留白，缺乏职业气场。
- **地图氛围偏平、操作跨屏分散（`05-map-first`、`23-map-progress`）**：像素节点图标素质良好，但底板为扁平灰蓝 + 机械虚线，左下角节点说明与右下角「前往/返回」间距过宽。

### 2. 备战主屏与手机横屏适配（`06-prep-first`、`07-tutorial`、`08-prep-full` 三视口、`12-placement`、`44-rehearsal`）
- **全站幽灵空框与顶栏穿模（`06`/`08`/`13`~`22`/`25`~`30`/`39`/`53`~`54`）**：顶部中央反复渲染带灰蓝描边的空矩形框盖住幕次标题；下方 `施法 / 买卖 / 喂食` 计数压在金色虚线分割线上。
- **手牌区裁切与互遮（`08-prep-full` 全视口）**：底部手牌被屏幕下沿截断，相邻手牌重度遮挡右半边数值与技能文本，且紧贴上方商店卡底边。
- **手机横屏挤压（`08-prep-full-844x390`、`08-prep-full-720x360`）**：左上角英雄费用角标压住 5 号位补给角标，单位头顶星级条/皇冠顶到上分割线，商店卡文字缩到极小。
- **新手教学层叠事故（`07-tutorial`）**：开战前阶段横幅直接叠在教学遮罩与引导弹窗正上方，压暗教学正文、打断引导焦点。
- **局部状态条遮挡 HUD（`32-reward-pending`、`44-rehearsal`）**：「待领 1」与演练模式「返回结算 / 看广告重打」直接覆盖左上角英雄头像与血心。

### 3. 卡牌详情、关键词与目标选择（`09-unit-detail`、`10-gold-preview`、`11-keyword`、`14-shop-detail`、`15-supply-detail`、`16-spell-target`、`18-equipment`、`20-enemy-detail`、`22-hero-detail`、`49/50-long-detail`）
- **商店详情技能截断（`14-shop-detail`）**：「绕阵快骑」技能文本被下方「招募 3 金 / 锁定」按钮彻底裁切。
- **长详情信息墙与溢出（`49/50-long-detail-844x390`）**：
  - `8/10` 血量文本直接溢出圆形生命徽章；
  - `补给传承 5/5` 将相同的「面包 +1/+1」重复罗列 5 行而未合并为 `面包 ×5`；
  - 缺少滚动渐隐提示，移动端难以察觉下方仍有「当前站位」与「出售传给」信息。
- **选目标弹窗缺少实战数值（`16-spell-target`）**：使用指向性补给/法术时弹出全屏灰窗遮挡战场，且每个候选单位卡片不显示当前攻/血与金色状态，玩家只能盲选。
- **英雄详情无独立容器（`22-hero-detail`）**：文本直接裸漂在半透明商店卡上方，缺乏独立像素面板底板。
- **禁用态低对比度与原生焦点框（`11-keyword-844x390`、`20-enemy-detail`、`32-reward-pending`）**：「当前猎物」「领取」禁用态文字几乎不可辨认；点击关键词时暴露浏览器原生黄色 focus 框。

### 4. 材质分裂与信息冗余（`25-relic-pick`、`26`~`31`、`33`~`38` 图鉴、`53/54-morph`）
- **三套皮肤同屏混用**：直角金紫像素框（地图/遗物/图鉴/结算）vs 大圆角紫灰渐变卡片（宝箱/篝火/事件/委托/商人）vs 冷灰后台弹窗（详情/选目标/菜单）。
- **像素与矢量混拼（`27-fire`）**：篝火选项中光滑矢量红心、光滑圆角小方块与像素攻血菱形并排混用。
- **发现页信息双重重复（`31-discover`）**：单位卡面内部已展示完整技能，下方又挂 `.disc-desc` 重复复述一遍，且未选中卡压暗过重影响横向对比。
- **稀疏图鉴留白与变形文案（`35/36-codex`、`54-morph-preview`）**：补给/装备右侧大框超 85% 面积空黑；变形预览仅 1 个候选时仍提示「以下 1 个候选随机其一」，缺少 `原单位 → 目标` 对照。

### 5. 战斗主屏、结算与战报（`39-battle`、`40-battle-result`、`41`~`43` 战报、`45-trial-result`、`46/47-ending`、`48-records`）
- **战斗主屏空间浪费与控件穿模（`39-battle`）**：开战后单位仍偏上、下方大片空白；备战左下角背包未隐藏直接压住战斗日志，上方触发条撞击金色分割线。
- **结算按钮无主次（`40-battle-result`、`45-trial-result`）**：「复盘」「重打」「继续 ▶」全部使用同色高亮金按钮，缺乏主/次/重置三级区分。
- **战报柱状图比例尺错乱与缺图例（`41/42-report`）**：`.br-row.foe` 遗漏 `.br-rail { order: 2 }`，导致敌方输出条被挤压进 `54px` 第一列，出现「敌方 18 伤害条比我方 7 伤害条短一半」的视觉错乱；分段颜色缺少图例。
- **粒子定时泄漏（`47-ending-win` → `48-records`）**：通关烟花 `setTimeout` 切屏未清理，导致烟花残留到历史战绩页正中央。

## 三、暗夜紫金像素风视觉规范建议

- **配色体系**：主背景暗夜紫黑 `#09071A`~`#120E1D`，面板紫蓝梯度 `#221C4A`→`#110D29`，黄铜像素描边 `#D9B066` / 顶亮 `#FFE2A0`，暖金唯一主 CTA `#FFD36B`→`#EFAE45`（深棕字 `#2A1600`），次操作靛紫 `#43397A`，危险猩红 `#E3394F`，禁用态 `#35314D` 底配高可读 `#C6C0DC` 字。
- **字体与像素对齐**：主标题、结算大字与大数字采用硬边像素块投影（禁止 `blur > 0` 光晕）；所有精灵、血心、道具图标强制 `image-rendering: pixelated`；事件页彻底替换矢量图标。
- **框体与三级按钮**：全站废除 `border-radius: 6px~20px`，统一采用 `border-radius: 0` + 9-slice 铸铁/黄铜像素框或四向 2px 缺角描边；按钮严格分主操作（厚底暖金）、次操作（厚底靛紫）、危险操作（厚底暗红），统一带 2~3px 物理按压位移。
- **图层与清理契约**：切屏（备战→战斗、结局→战绩/标题）必须清空定时特效与上阶段专用控件，防止跨状态污染。
