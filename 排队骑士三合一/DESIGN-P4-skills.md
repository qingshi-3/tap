## 1. 为什么一直在换人

| 现象 | 根因 |
|---|---|
| 低阶卡拿到就是过渡，升本后卖掉 | 价值 ≈ 阶层白值；低阶技能不随时间变强，50 上限还把高低阶压到同一天花板 |
| 一回合里没什么可做 | 商店动词只有 买/卖/排位；技能大多是 **本场** 加成，打完归零，不留痕迹 |
| 凑不凑引擎差别不大 | 缺少「让低阶卡变核心」的关键卡（炉石的布莱恩/瑞文戴尔）；同引擎卡之间只是 1+1 |
| 站位思考有限 | 大部分技能是随机目标或全队，排位只影响前排谁先挨打 |

**目标**：卡因为「养起来了」「是引擎零件」而被留下，而不是因为阶层被换掉。每回合至少有一个「把增益给谁」的决策。

## 2. 四个新机制（全局）

### 2.1 入场（战吼）＋ 指定目标
- 从商店/手牌放上场时触发一次，**拖到哪个友军身上就给谁**（不拖到人身上则给自己或无效，卡上写明）。
- 这让手牌有了意义：先囤着，等合适的目标/时机再放。三连金色时入场效果 ×2。
- 符合「确定指定」原则：效果当场兑现，不存需要特定单位消费的资源。

### 2.2 复仇（N）：战斗里攒，局外兑现
- 「本场有 N 个友军阵亡后：……**永久**……」，每场最多触发一次。
- 让战斗过程影响养成：死得有价值。亡语引擎的主要永久成长来源。

### 2.3 引擎计数（本局全局加成，HUD 常驻一个小牌）
| 计数 | 谁加 | 作用 |
|---|---|---|
| 🐉 召唤加成 | 召唤引擎的卡 | 本局所有召唤物 +X/+X（包括之后才买的卡召出来的） |
| 🗡 锋芒 | 开战引擎的卡 | 本局所有「开战时造成 N 伤害」+X |
| 🍞 补给加成 | 补给引擎的卡 | 本局所有补给额外 +X/+X |

计数是**广播型**的，低阶卡贡献过计数后，就算卖掉，贡献也还在。所以早期拿它们不亏，后期找到关键卡就能起飞。

### 2.4 每个引擎一张「双触发」关键卡（5–6 阶）
| 引擎 | 关键卡 | 效果 |
|---|---|---|
| 受伤 | 风暴剑圣 | 友军的「受伤时」技能触发 2 次 |
| 开战 | 岚影宗主 | 友军的「开战时」技能触发 2 次 |
| 亡语 | 深渊主母 | 友军的「阵亡时」技能触发 2 次 |
| 召唤 | 火山之心 | 召唤效果多召唤 1 个 |
| 成长 | 沙域法老 | 友军的「回合结束时」技能触发 2 次 |
| 补给/入场 | 霜冠执政官 | 友军的「入场」效果触发 2 次 |

关键卡越强，1–2 阶的引擎零件越值得留着，金色零件更是核心。这是减少换人的主要手段。

## 3. 去上限后的护栏
- 续航一律固定值、限次数（沿用「排队骑士续航限强」）：收割回血、重装铠等改成「最多 +20」这类上限。**已改**：重装铠最多 +20。
- 百分比伤害（千刃宗师失去 33% 血）保留，用来克制「堆血大哥」。新增 1–2 张百分比克制卡，防止单核无限堆成唯一答案。
- 数值显示：3 位数字号自动缩小，4 位继续缩（**已改**）。

## 5. 一回合里多出来的决策
1. 入场卡：现在放还是囤手牌？给谁？
2. 关键卡出现前：引擎零件是留着等，还是先换高阶白值？
3. 复仇卡放哪：前排早死触发复仇，还是后排保它的技能？
4. 计数卡：前期花钱买 1 阶「计数零件」，还是攒钱升本？
